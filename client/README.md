# 动作样板：移动、普攻、近战对抗与扩散剑气

Creator 3.8.8。v0.6 源码切片包含固定房间、图形占位战士、摇杆、四阶段普攻、单怪/三怪近战对抗和扩散圆弧剑气。Web Mobile H5 已构建，用户确认手机浏览器可打开并操作；用户认为当前人物与动作表现较差，尚未通过手感验收。编辑器预览页面与 Web Mobile 构建是两种入口，旧预览画面不能代表手机已打开的 H5。范围斩、突进、登录和云调用仍未实现。完整目标见 [动作原型规格](../docs/action-prototype.md)。

## 打开与预览

在 Cocos Dashboard 导入本目录 `client`，使用 Creator 3.8.8 打开。资源导入完成后，双击 `assets/scenes/Prototype.scene`，使用编辑器顶部浏览器预览按钮运行。首次导入可能生成 `.meta`，应随对应资源保留。

- 桌面：WASD / 方向键移动，空格点按或按住普攻，Q 释放剑气，1/3 切换单怪或三怪，R 重置遭遇。
- 触控：左下固定摇杆，右下普攻键，普攻键左上方为剑气键。X 按力度变速，Y 越过死区后定速。
- 普攻：左砍、右砍、上挑、双刀交叉横扫四段；动作结束后 300ms 内续点接下一段；超时重开，按住循环。
- 剑气：双刀快速交替横挥两次后，生成一道向前扩散的弧形剑气。每只怪物在一次剑气中最多受击一次，剑气不因命中怪物而消失。当前本地调试值为 300ms 连挥、720ms 扩散、175 逻辑像素最大半径、20 点法力和 2.5 秒冷却；这些数值仅用于本轮体验，不是最终规格。
- 对抗：怪物靠近后以红色区域预警并锁定攻击位置；走出区域可躲避。普攻命中会让怪物闪白、僵直和击退；受击会扣血、打断连段并造成击退，短时间内有受击保护。
- 当前调试生命值：玩家 100 点，每次受击 22 点；怪物 3 点，每次有效普攻命中 1 点。死亡或清场后 2.2 秒自动重开，也可按 R 立即重开。

世界按 480×270 构图、2 倍逻辑缩放。根据首轮试玩反馈，v0.2 人物显示比例增加约 20%（人物节点额外 1.2 倍，待机本体约等效 44 个源像素），地面坐标和移动速度不变。UI 使用独立节点，当前固定构图留边；微信安全区与完整宽屏适配需后续真机验证。

v0.2 用程序化关键姿态替换简单摆刀：身体重心、肩部扭转、前后手臂和双刀配合，区分左右砍、上挑、双刀交叉横扫的蓄力/出刀/收势；按实际刀刃位置绘制短暂刀光轨迹。动作间从当前姿态过渡，空闲时平滑回到待机。仍为程序化占位动作，不是生产像素资源，也未复用 Codex 宠物内部代码或 skill。空挥改善不代表受击与命中手感已通过。

## 无安装的逻辑检查

v0.4 针对“第四段收招过快”反馈，将第四段从 460ms 调到 760ms：快速交叉、短停、反向展开、展开姿态停留、缓慢回收。两次横扫仍保持快出刀，增加的时间主要用于停顿与收势；300ms 衔接窗口在完整动作结束后开始。回收时刀刃角度沿较短路径过渡，避免绕转。其他三段和移动速度保持原值。这些为本轮调试值，手感待用户复评。

用户指定《三国战纪》张辽为节奏参考；已找到[张辽基础连招演示](https://www.bilibili.com/video/BV19s4y1n79j/)，但视频访问受限，尚未观看或逐帧测量，因此本轮调整不声称复现该角色的具体动作时序。

v0.3 将第四段改为双刀交叉横扫：左手向右、右手向左同时交叉，再分别向左、向右展开后收势。两刀均有刀光；整个动作仍是一段，持续时间与 300ms 连段衔接规则不变。该调整只涉及表现，不代表已经增加双段伤害判定。

在仓库根目录执行（引擎路径按实际安装位置替换）：

```powershell
node client/tools/check-model.cjs 'C:\ProgramData\cocos\editors\Creator\3.8.8'
```

检查依赖编辑器随附 TypeScript，不需要 npm install。它验证连段和移动逻辑，不代替 Cocos 运行或 Note20 Ultra 真机验收。

`tools/prepare-scene.cjs` 是从官方 2D 场景模板初始化入口的一次性工具，已执行，请勿对现有场景重复运行。

检查记录：Cocos 浏览器运行时已验证近战场景显示、单次普攻命中、摇杆横向跑动及走出红色预警区；手机浏览器 H5 已由用户确认可打开并操作。v0.6 剑气源码的严格类型检查和逻辑检查通过；双刀连挥、扩散波动画、多怪穿透与主观打击感仍需专项验收。手机浏览器 H5 不是微信小游戏构建，不代表 Note20 Ultra 微信真机性能已验收。

已有 Web Mobile 构建产物时，可在仓库根目录运行 `node client/tools/serve.cjs`，默认读取 `client/build/web-mobile-001` 并在 `http://127.0.0.1:8765` 提供桌面本机预览；也可把相对 `client/build/` 的输出目录名作为参数传入。此帮助服务只监听本机，不供手机连接。手机测试需使用可从手机访问的 H5 主机地址和端口；构建刷新需在 Creator 3.8.8 中打开 `client` 并重新构建 Web Mobile。
