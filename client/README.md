# 动作样板：双刀普攻、近战对抗与战士四技能

Creator 3.8.8。当前源码切片包含固定房间、像素风战士图集、摇杆、四阶段双刀普攻、单怪/三怪近战对抗，以及十字斩、崩山击、拔刀斩、崩山裂地斩。普攻现接入一份六帧像素动作草稿，角色其他状态先保持同一张守势帧；移动和技能专用动作帧尚未制作。代码改动待重新构建并由用户手机复评。编辑器预览页面与 Web Mobile 构建是两种入口。通用正面范围斩、独立短突进与扩散剑气不在当前技能组内。完整目标见 [动作原型规格](../action-prototype.md)。

## 打开与预览

在 Cocos Dashboard 导入本目录 `client`，使用 Creator 3.8.8 打开。资源导入完成后，双击 `assets/scenes/Prototype.scene`，使用编辑器顶部浏览器预览按钮运行。首次导入可能生成 `.meta`，应随对应资源保留。

- 桌面：WASD / 方向键移动，空格点按或按住普攻，E 十字斩、F 崩山击、Q 拔刀斩、G 崩山裂地斩；1/3 切换单怪或三怪，R 重置遭遇。
- 触控：左下固定摇杆，右下普攻键，其上排列四个技能键。X 按力度变速，Y 越过死区后定速。
- 普攻：四阶段输入节奏和约 300ms 衔接窗口暂时保留；动作重做为更连贯的双刀交替斩击，参考狂战士二刀流和剑魂里鬼的连续挥砍，不复制 DNF 素材或 hit 数。按住循环，松开停止续招。
- 六帧图集：`assets/resources/warrior-dual-slash-sprite-draft-v1.png` 已由脚本异步加载并切帧，角色全程保持像素风外观；当前四段普攻暂时共用它，原有命中事件不变。没有导入 Cocos 项目时不需要手工拖节点。图集还是评审草稿，走跑与技能专用动作帧尚未制作，暂时显示像素守势帧。
- 技能：十字斩是快速交叉近身斩；崩山击跃起后向前短距离落地重击；拔刀斩是短暂收势后快速横向宽斩，不再扩散剑气；崩山裂地斩为大范围落地重击。伤害、冷却、范围、法力和动作时长都只是本地调试值。
- 对抗：怪物靠近后以红色区域预警并锁定攻击位置；走出区域可躲避。普攻命中会让怪物闪白、僵直和击退；受击会扣血、打断连段并造成击退，短时间内有受击保护。
- 当前调试生命值：玩家 100 点，每次受击 22 点；怪物 3 点，每次有效普攻命中 1 点。死亡或清场后 2.2 秒自动重开，也可按 R 立即重开。

世界按 480×270 构图、2 倍逻辑缩放。根据首轮试玩反馈，v0.2 人物显示比例增加约 20%（人物节点额外 1.2 倍，待机本体约等效 44 个源像素），地面坐标和移动速度不变。UI 使用独立节点，当前固定构图留边；微信安全区与完整宽屏适配需后续真机验证。

v0.2 用程序化关键姿态替换简单摆刀：身体重心、肩部扭转、前后手臂和双刀配合，按实际刀刃位置绘制短暂刀光轨迹。动作间从当前姿态过渡，空闲时平滑回到待机。仍为程序化占位动作，不是生产像素资源，也未复用 Codex 宠物内部代码或 skill。空挥改善不代表受击与命中手感已通过。

当前动作改版保留四段输入节奏和一次命中判定/阶段：前三段表现为前后手交替的两次短斩，分别强化换手、反手和上挑；第四段仍是双手交叉后反向展开并放慢收势。动作读感参考狂战士双刀和剑魂里鬼节拍，未照搬 DNF 旧版段数。四技能已有临时程序姿势。以上仍待新 H5 和手机复评。

## 无安装的逻辑检查

v0.4 针对“第四段收招过快”反馈，将第四段从 460ms 调到 760ms：快速交叉、短停、反向展开、展开姿态停留、缓慢回收。两次横扫仍保持快出刀，增加的时间主要用于停顿与收势；300ms 衔接窗口在完整动作结束后开始。回收时刀刃角度沿较短路径过渡，避免绕转。其他三段和移动速度保持原值。这些为本轮调试值，手感待用户复评。

用户指定《三国战纪》张辽为节奏参考；已找到[张辽基础连招演示](https://www.bilibili.com/video/BV19s4y1n79j/)，但视频访问受限，尚未观看或逐帧测量，因此本轮调整不声称复现该角色的具体动作时序。

v0.3 将第四段改为双刀交叉横扫：左手向右、右手向左同时交叉，再分别向左、向右展开后收势。两刀均有刀光；整个动作仍是一段，持续时间与 300ms 连段衔接规则不变。该调整只涉及表现，不代表已经增加双段伤害判定。

在仓库根目录执行（引擎路径按实际安装位置替换）：

```powershell
node client/tools/check-model.cjs 'C:\ProgramData\cocos\editors\Creator\3.8.8'
```

检查依赖编辑器随附 TypeScript，不需要 npm install。它验证连段和移动逻辑，不代替 Cocos 运行或 Note20 Ultra 真机验收。

`tools/prepare-scene.cjs` 是从官方 2D 场景模板初始化入口的一次性工具，已执行，请勿对现有场景重复运行。

## 尚未验证

检查记录：此前的 v0.6 Cocos 浏览器运行时验证了近战场景显示、单次普攻命中、摇杆横向跑动和走出红色预警区；用户确认该版 H5 可在手机浏览器打开操作。六帧普攻图集的代码与资源已完成，逻辑检查和 TypeScript 编译通过；这次变更尚未由 Creator 重建，需重建 Web Mobile 并在 Note20 Ultra 复评。手机浏览器 H5 不是微信小游戏构建，不代表微信真机性能已验收。

已有 Web Mobile 构建产物时，可在仓库根目录运行 `node client/tools/serve.cjs`，默认读取 `client/build/web-mobile-001` 并在 `http://127.0.0.1:8765` 提供桌面本机预览。参数依次为构建目录名、监听地址和端口；手机与电脑在同一局域网时，把监听地址设为电脑当前 WLAN IPv4（例如 `node client/tools/serve.cjs web-mobile-001 10.200.4.231 8766`），再在手机打开该 IP 和端口（`http://10.200.4.231:8766/`）。服务只绑定指定接口；测试结束后关闭服务。构建刷新需在 Creator 3.8.8 中打开 `client` 并重新构建 Web Mobile。

微信开发者工具路径：`D:\Program Files (x86)\Tencent\微信web开发者工具`。微信构建、AppID 配置、真机多点触摸、刘海/胶囊安全区和 60 FPS 均不能由逻辑检查证明。暂不编造 AppID 或创建云环境。
