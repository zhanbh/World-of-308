# World of 308 — 308世界

面向微信小游戏的原创 2.5D 像素风横版动作 RPG。采用**单人手动战斗 + 在线异步服务**，由一个主开发配合 AI 工具推进。

## 当前状态

整体玩法与架构方向已完成讨论，正在进入文档审阅和模块设计阶段。当前仓库没有可运行的 Cocos 工程或游戏后端；文档不是已实现功能的声明。

本次规划落档日期：2026-10-15。文档标注「已确认」「待设计」「建议」；后两者不视为最终决定。

## 下一步

先审阅文档并设计动作原型，确定引擎版本、画面规格及真机验收条件，再创建最小 Cocos 工程。MVP 最终包含战士和猎人，原型允许只验证一个职业。

当前没有安装、运行或部署命令。后续建立工程时再加入经过验证的操作说明。
