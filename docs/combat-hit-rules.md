# 通用受击、倒地与死亡规则

> 2026-10-19正式基线已改为每个敌人自出现/起身后跨普攻与技能累计直接伤害，起身清零，DOT不计入；手动/免费复活清职业CD，回城清全部技能/道具CD。下文按施放累计及本地重试描述是现有原型行为，尚待迁移，不代表新机制已实现。 见[基线摘要](wayfinder/core-rules-v2/SUMMARY.md)。

2026-10-16。用户确认：适用于所有职业的攻击/技能对敌人的受击处理。状态：通用按施放/目标/伤害段统计的倒地判定已接入当前多段技能；白色剪影死亡表现已接入。四技能2/3/1/4段时序已接入，待视觉验收。职业专属附加状态仍由对应技能定义。

## 受击处理优先级

| 伤害结算后的情况 | 结果 |
| --- | --- |
| 生命值已归零 | 立即判定死亡，播放短暂白色剪影消失；不进入新的倒地/起身流程 |
| 仍存活，但目标配置为不可倒地 | 不进入倒地；按目标类型及技能规则表现其他受击反馈 |
| 仍存活且允许倒地，当前伤害段带特殊击倒 | 不要求达到普通倒地阈值，直接按技能规则击倒 |
| 仍存活，普通伤害达到倒地阈值 | 触发通用倒地 |
| 仍存活，未达到倒地条件 | 沿用该伤害段的短僵直、小幅后退等受击反馈 |

“受到一定伤害才倒地”不表示每次受伤立即倒地。2026-10-16用户进一步确认：阈值由数据系统配置，暂定按怪物生命值百分比；采用“单次技能实例内，各段结算伤害合计”的口径，每次技能独立计算。

## 单次技能的倒地阈值

| 目标类别 | 暂定阈值 | 数据与设计边界 |
| --- | --- | --- |
| 小怪 | 最大生命值的30% | 比例由数据配置，不写死在职业技能里 |
| 精英怪 | 最大生命值的20% | 同上，后续可调 |
| Boss | 按Boss类型分别设计 | 不默认套用小怪/精英比例；可设置为不可倒地 |

使用最大生命值作为百分比基准，避免血越少阈值越小。例：最大生命100的小怪阈值30，最大生命200的精英怪阈值40。这里是原型暂定比例，不代表正式数值冻结。

- 按“技能实例＋目标”记录本次各段实际结算的直接伤害；不是把角色连续释放的不同技能累加，也不是敌人从出生/上次起身以来的总受伤。
- 任何一段命中后，本次技能对该目标的伤害合计达到或超过阈值，且目标仍存活、允许倒地，即可触发普通倒地；不用强等整招全部结束。三段技能按同一次施放合计，十字2段、拔刀1段、大崩4段也遵循这个口径。
- 一次技能对同一目标跨越阈值只触发一次普通倒地，不因剩余段继续伤害而反复重置普通倒地。下次施放建立新记录，不继承本次累计值。
- 已发射十字与技能独立地面后续段仍属于原施放实例，即使角色已收招，也要保留对应累计记录至其结束。各目标分别统计，不汇总成打多只怪的总伤害。
- 生命归零仍先走死亡规则；特殊击倒段按允许倒地/免疫策略优先处理，不受普通百分比阈值限制。
- Boss倒地比例、免疫、特殊击倒互动后续按Boss类型定义；不可倒地作为显式配置，不能用阈值0表示。
- 流血DOT是否计入本次技能阈值、倒地期间累计如何处理、普攻连段的统计单位留待后续设计，不从“技能各段直接结算合计”自动扩展。

此前候选的“起身后累计”“连续受伤窗口”“仅单次重伤”已由本次用户选择覆盖，不再作为待选问题。该阈值机制已接入当前多段技能；同次施放多段累计的模型边界已通过测试，实际多段时序已接入。

## 与战士技能的衔接

- 十字斩两段与拔刀斩一段默认是普通伤害段，命中先表现短僵直/小后退；达到通用阈值时可倒地。
- 小崩前两段不自带特殊强制击倒，仍适用通用伤害阈值；终段是特殊击倒段。此前“终段之前绝不倒地”修订为“只有终段自带强制击倒”，避免与最新的全职业通用规则冲突。
- 大崩拍地第1段是特殊击倒段，后3段爆发继续伤害倒地目标，起身等待本次全部特效结束。后续每段不重新加一整轮大崩倒地时长。
- 特殊击倒不能覆盖死亡优先级：致死命中直接进入死亡表现，不让零血怪物先倒地再起身。
- 同一目标每个技能段最多结算一次，不改变此前2/3/1/4段规则与5秒刷新、不叠加的流血规则。

## 死亡与消失表现

用户方向：生命归零时，身体短暂、平缓地泛白成为剪影，然后消失。先保留当前朝向和姿势轮廓，提升白色强度，再降低透明度；不采用多次高频白闪，不延长为站起后再消失。

具体时长待视觉调试，用户尚未给定毫秒值。白色剪影属于死亡状态的表现阶段：

- 从生命归零开始停止AI、移动和攻击，不再被技能后续段或流血继续结算伤害；不能因为尚可见而继续充当活目标。
- 清理活体流血红色脉冲、受击白闪和起身计划，避免覆盖死亡剪影或死后重新站起。
- 身体与脚底阴影一同平缓消退，血条退出，消失结束后移除表现。
- 死亡判定及未来经验/掉落结算只触发一次，不依赖白影淡出完成；视觉播放不重复触发奖励。
- 房间重置/离场立即清理残留；若未来恢复或重播死亡状态，不得再次发放死亡奖励。

## 验收项目

小怪30%/精英20%边界；多段在同一技能内累计，跨技能/跨目标不混算；角色收招后的十字/地面段归属不丢失；同一实例不重复触发普通倒地；特殊击倒绕过普通阈值但遵循目标免疫；致死优先死亡；普通/多段/流血致死使用同一死亡入口；死亡白影期间无攻击、无再受伤、无起身和奖励重复；淡出后无身体、红影或脚底阴影残留。

## 本次实现与验证

通用判定器由一次施放持有，按目标与伤害段去重；普通30%、精英20%、Boss默认免疫作为原型数据。死亡立即退出战斗，保留死亡前倒地姿势，暂用180ms泛白＋320ms淡出，均为可调试参数。游戏与技能预览共用死亡模型；预览和游戏渲染都已接入淡出。

模型验证覆盖阈值相等边界、分段累计/去重、跨技能/跨目标隔离、单次触发、Boss强制击倒免疫与死亡姿势/淡出。尚未进行手机视觉验收；四技能已接入多段时序，流血仍只有表现，持续扣血数值待定。
