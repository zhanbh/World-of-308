# 通用受击、倒地与死亡规则

2026-10-16。用户确认：适用于所有职业的攻击/技能对敌人的受击处理。状态：规格已记录；普通倒地阈值与白色剪影死亡表现尚未接入当前代码/预览。职业专属附加状态仍由对应技能定义。

## 受击处理优先级

| 伤害结算后的情况 | 结果 |
| --- | --- |
| 生命值已归零 | 立即判定死亡，播放短暂白色剪影消失；不进入新的倒地/起身流程 |
| 仍存活，当前伤害段带特殊击倒 | 不要求达到普通倒地阈值，直接按技能规则击倒 |
| 仍存活，普通伤害达到倒地阈值 | 触发通用倒地 |
| 仍存活，未达到倒地条件 | 沿用该伤害段的短僵直、小幅后退等受击反馈 |

“受到一定伤害才倒地”是普通攻击的通用触发条件，不表示每次受伤立即倒地。阈值数值留待数值阶段确定，不能自行用生命值百分比或旧临时伤害值代替。

**阈值累计方式待用户选择：** 从上次起身后累计、短时间内连续受伤累计、或单次重伤触发。已发起单项澄清，当前不锁定其中一种。阈值的具体量、不同敌人的配置，以及流血DOT是否计入阈值、倒地期间伤害如何处理，后续在数值/状态模型阶段明确。

## 与战士技能的衔接

- 十字斩两段与拔刀斩一段默认是普通伤害段，命中先表现短僵直/小后退；达到通用阈值时可倒地。
- 小崩前两段不自带特殊强制击倒，仍适用通用伤害阈值；终段是特殊击倒段。此前“终段之前绝不倒地”修订为“只有终段自带强制击倒”，避免与最新的全职业通用规则冲突。
- 大崩拍地第1段是特殊击倒段，后3段爆发继续伤害倒地目标，起身等待本次全部特效结束。后续每段不重新加一整轮大崩倒地时长。
- 特殊击倒不能覆盖死亡优先级：致死命中直接进入死亡表现，不让零血怪物先倒地再起身。
- 同一目标每个技能段最多结算一次，不改变此前2/3/1/4段规则与5秒刷新、不叠加的流血规则。

## 死亡与消失表现

用户方向：生命归零时，身体短暂、平缓地泛白成为剪影，然后消失。先保留当前朝向和姿势轮廓，提升白色强度，再降低透明度；不采用多次高频白闪，不延长为站起后再消失。

具体时长待视觉调试，用户尚未给定毫秒值。白色剪影属于死亡状态的表现阶段：

- 从生命归零开始停止AI、移动和攻击，不再被技能后续段或流血继续结算伤害；不能因为尚可见而继续充当活目标。
- 清理活体流血红色脉冲、受击白闪和起身计划，避免覆盖死亡剪影或死后重新站起。
- 身体与脚底阴影一同平缓消退，血条退出，消失结束后移除表现。
- 死亡判定及未来经验/掉落结算只触发一次，不依赖白影淡出完成；视觉播放不重复触发奖励。
- 房间重置/离场立即清理残留；若未来恢复或重播死亡状态，不得再次发放死亡奖励。

## 待接入验收

阈值以下不误倒地；跨阈值后只触发一次倒地；特殊击倒不受阈值限制；同次命中同时达到阈值和生命归零时死亡优先；普通/多段/流血致死使用同一死亡入口；死亡白影期间无攻击、无再受伤、无起身和奖励重复；淡出后无身体、红影或脚底阴影残留。
