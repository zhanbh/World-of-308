## 已确认规则与代码边界

- 怪物死亡生成地面掉落（材料堆叠 `stack` 或装备 `equipment`），带有空间坐标与拾取判定半径（32px 内）。
- 玩家靠近触发拾取（`drop.collect`）：材料同模板同绑定优先合并入现有堆叠（1~20），装备占用 1 个空格；成功入包才将掉落物原子标记为已拾取（`collected = true`）并物化装备实例。
- 背包满时拒绝拾取（返回 `BAG_FULL`），掉落物安全保留在地面（满包留地）；场景关闭或切房时地面未拾取物自然失效，已成功入包资产绝对不可撤销。
- 最终 Boss 生命值归零立即将挑战置为已通关（`result = 'completed'`）；同房间剩余存活小怪被动清场，其掉落与击杀经验完整结算，不因 Boss 先死而丢失。
- 若玩家在首领死亡同刻阵亡，先记录死亡事实，随后立即触发通关免费复活（`lifeState = 'alive'`，满血满蓝，清除死亡倒计时，不扣纹章，不计入付费复活次数）。
- 末房武器耐久磨损至 0 时正常扣损，但绝不撤销通关结果，不翻盘判败。
- 首领击杀结算在同一笔原子事务内完成：即时金币、击杀经验、升级判断、跨级节点邮件、通关专属装备分流、体力最终沉降与副本解锁。
- 专属装备 direct / pending 路由分流：背包未满走 direct 路由直接入包；背包已满走 pending 路由创建 pending 实例（`location = pending{grantId}`）并生成永久待领凭证 `rewardGrant`；两路均写入 `clearReceipt` 固化交付路由，永不重映射。
- 跨级礼包邮件：经验升级若跨越等级节点（如 5/10/15 级），同笔生成确定键邮件（`mailId`），检查不存在性，单来源绝不重发。

## 01 房间怪物掉落生成、拾取入包与满包留地

无本包前置。交付：怪物死亡生成地面掉落物，接收 `drop.collect` 拾取指令，完成材料合堆或装备物化入包，满包时保留地面并阻断。

- 怪物击杀在房间内生成带坐标与唯一 `dropId` 的掉落物（`templateId`, `quantity`, `quality`, `itemLevel`, `x`, `y`, `collected: false`）。
- 服务端校验玩家坐标与掉落物距离（<= 32px）；超距拒绝 `NOT_FOUND_OR_FORBIDDEN`。
- 空间检查与物化：
  - 材料：优先寻找同模板且同绑定未满堆叠合堆；无则占新空格；
  - 装备：检查背包空位，成功拾取物化唯一实例 `id = H(sourceKey, ordinal)` 并放入背包；
  - 满包阻断：无可用空格返回 `BAG_FULL`，掉落物状态保持 `collected: false` 留在地面。
- 掉落物生命周期：切房或副本关闭未拾取物失效；已拾取物生成 assetJournal 审计流水与 assetOp 凭据。

## 02 首领击杀即刻通关、剩余怪物结算与免费复活

依赖 01。交付：战斗内核与挑战服务在首领生命归零时即刻判定通关，清场剩余小怪并汇总收益，处理同刻死亡免纹章复活与末房磨损保护。

- 首领 HP<=0 时即刻将挑战标记为通关（`result = 'completed'`）。
- 同房间存活小怪被动触发清场，击杀经验与常规掉落完整结算进挑战上下文。
- 同刻死亡判定：若玩家与首领同刻死亡，先记录死亡事实，立即触发免费复活（`lifeState = 'alive'`, 满血满蓝, 清除倒计时, 不扣纹章, 不计入 `paidRevives`）。
- 末房武器耐久磨损保护：扣减耐久至 0 耐久时仅更新武器状态，绝不翻盘判败。
- 纯内核规则与服务状态机测试覆盖：即刻通关、剩怪经验掉落汇总、同刻免死复活、0耐久通关保护。

## 03 终局原子事务：金币/经验/跨级礼包/通关装备路由

依赖 02。交付：首领通关单笔原子提交事务，完成金币经验累加、升级跨级礼包邮件、通关专属装备 direct/pending 路由与体力结清。

- 即时金币与经验汇总结算至钱包 `account.wallet` 与角色 `character.xp`。
- 升级与跨级节点检测：跨越等级节点（5/10/15/20/25/30 级）生成确定性邮件（`mailId = mail:${characterId}:level-${node}`），检查不存在性，单来源绝不重发。
- 通关专属装备路由分流：
  - 生成一件固定通关装备 `itemId = H(challengeId, 'clear-equipment')`；
  - 背包有空位：走 direct 路由，写入背包 slot；
  - 背包已满：走 pending 路由，创建 pending 实例（`location = pending{grantId}`）并生成 `rewardGrant`；
  - 两路均写入 `clearReceipt` 固化路由与结果。
- 体力结算：锁定体力标记为 `staminaSettlement: 'settled'`，解锁下一难度。
- 写入单笔有界 `assetJournal`（<= 128KB）与 `assetOp` 幂等凭据。
