# ST14 五项垂直切片提案

2026-10-28，待一次粒度/依赖及测试边界确认。依赖 01→02→03→04→05；外部真实依赖 ST04背包/道具、ST05装备、ST06商店/货币、ST10开房/换房/场景、ST11战士技能、ST12怪物与首领战斗及 ST13战斗补给/CD。

## 已确认规则与代码边界

- 角色生命值（HP）归零权威判定为死亡（`lifeState = 'dead'`），以真实事件物理时钟为锚点开启严格 10 秒复活倒计时（`deathDeadline = deathAt + 10_000`），不以收到网络响应时刻延长。
- 死亡状态下禁止普通动作、位移、职业技能与消耗品使用；停止自然生命/魔法回复。
- 角色处于死亡状态时若因场上怪物被杀获得经验升级，依然保持死亡状态，不通过升级自动回血复活。
- 死亡后场上飞行的投射物、地面已布置的残留范围伤害及已有流血 DOT 继续按物理时钟推进判定；若最终 Boss 在玩家处于死亡窗口中被残留伤害击杀，触发免纹章通关自动复活（`freeRevived = true`，清除倒计时，不扣纹章，不计入付费复活次数，状态转为 alive）。
- 手动复活消耗背包内 1 枚复活纹章（`resurrection-emblem`），遵循角色绑定→账号绑定→未绑定的顺序扣除；无纹章拒绝复活（`EMBLEM_NOT_ENOUGH`）。
- 特殊副本整局累计最多手动复活 3 次（换房不重置，达到上限拒绝 `REVIVE_LIMIT_REACHED`）；普通升级副本无额外次数上限。
- 复活状态原子重置：恢复满 HP/MP、赋予 2.0 秒无敌受击保护、重置战士 4 个职业技能冷却时间；严禁重置战斗药水与主动饰品的 CD。
- 倒计时恰到结束或超时拒绝复活（`DEADLINE_EXPIRED`）且零扣款；主动放弃或超时进入不可逆的失败终态（`result: 'failed'`, `sceneState: 'closed'`）。
- 在线退出挑战返回对应副本的城镇传送门入口；断线重登则落在个人旅店空间，不将关闭程序视为续关手段。

## 01 权威死亡判定与物理10秒倒计时锚定

无本包前置。交付：战斗内核在玩家 HP 归零时生成权威死亡事件，设置 10 秒物理时钟倒计时锚点，阻断输入，维持残留结算与免死判定。

- 玩家 HP<=0 触发权威死亡事件，生成递增 `deathIndex` 并锁定 `deathDeadline = deathAt + 10_000`。
- 死亡状态阻断常规位移与技能输入，暂停自然回血回蓝。
- 死亡期间获得击杀经验并升级时，经验与等级正常累加，但 `lifeState` 严格保持 `dead`，不触发升级满血复活。
- 残留技能与流血 DOT 持续结算至其生命周期结束；若击杀最终首领，触发通关免费复活并清除死亡倒计时。
- 纯内核规则测试验证：死亡事件生成、10s 截止锚定、输入阻断、升级保持死亡、残留击杀最终首领免死。

## 02 手动复活、纹章扣除与冷却/状态重置事务

依赖 01。交付：通过真实 ChallengeService 事务接收 `challenge.revive`，校验有效期限与次数，原子扣除复活纹章并重置角色状态。

- 校验 `challenge.result === 'active'`、`lifeState === 'dead'`、`deathIndex` 一致性以及 `now <= deathDeadline`；超时严格拒绝 `DEADLINE_EXPIRED` 且零扣费。
- 消费背包中 1 枚 `resurrection-emblem`，按角色绑定→账号绑定→未绑定优先级扣除；无可用纹章报 `EMBLEM_NOT_ENOUGH`。
- 校验特殊副本挑战累计复活上限（`paidRevives < config.reviveLimit`，上限为 3 次），超限拒绝 `REVIVE_LIMIT_REACHED`。
- 原子重置状态：`lifeState = 'alive'`、`paidRevives++`、清除 `deathDeadline`、赋予 2.0 秒保护（`protectionUntil = now + 2000`）、恢复满血满蓝（`restore: 'fullHpMp'`）。
- 技能与道具 CD 分流：重置 4 个职业主动技能 CD（`bengshan`, `badao`, `cross`, `earth`），保留战斗药水与主动饰品的现有 CD。
- 幂等重放与并发安全：同 operationId 幂等返回原结果，并发复活请求只扣 1 枚纹章，写冲突时自动重试。

## 03 倒计时超时判败、主动放弃与落点退出

依赖 02。交付：死亡超时或主动放弃时安全终结挑战，保留已有收益，并根据在线/重登场景正确落点。

- 倒计时结束时接收复活请求直接返回 `DEADLINE_EXPIRED`，并在生命周期检查中标记 `result = 'failed'`, `sceneState = 'closed'`。
- 支持显式 `challenge.leave`（`reason: 'abandon'` 或 `'deathTimeout'`），进入不可逆失败终态。
- 挑战结束时结算已有掉落与击杀经验，不退还已扣减的体力。
- 场景关闭后清除 `account.openSceneChallengeId`；在线正常退出落回城镇对应副本传送门坐标；离线/重新登录则回退至旅店空间。
- 状态机严格测试：失败终态不可逆、原操作重放一致、非法重进阻断。

## 04 Cocos 死亡复活 HUD、状态机与视觉交互

依赖 03。交付：在客户端战斗场景接入完整的死亡复活交互弹窗与视觉反馈。

- 死亡触发复活 HUD：居中展示 10.0 秒平滑倒计时进度条与倒计时数字。
- 实时展示当前角色背包内复活纹章存量（如 `复活纹章: 10`）以及本局剩余复活次数（特殊本展示 `剩余复活: x/3`）。
- 提供【立即复活】与【放弃退出】交互按钮；无纹章或达上限时复活按钮置灰并提示原因。
- 点击【立即复活】：发送请求，收到成功响应后播放起死金色光环、全满血蓝刷新、职业技能 CD 重置；
- 点击【放弃退出】或倒计时归零：触发渐隐转场，退出挑战返回副本大门。
- 错误与未知状态容错：网络延迟或未知响应保持 HUD 提示，不冲掉新场景，确保离线 Cocos 构建与纯模型测试双绿。

## 提议一次确认的 TDD 边界

1. **纯联合时间与死亡内核**：显式状态/配置/输入，验证 HP 归零生成 10 秒物理截止、输入阻断、升级保持死亡、残留击杀免死；不证明真实数据库提交。
2. **公开服务/查询及真实 MemoryStore**：复用真实身份、角色/装备、背包纹章与挑战，验证纹章扣减（角色绑定优先）、特殊本 3 次上限、超时判败零扣款、职业 CD 重置与道具 CD 保留同成同败；不使用伪终局 handler，不代表云 SDK 验收。
3. **客户端真实传输/持久待决意图与 Cocos 交互**：验证未知恢复、迟包、10 秒倒计时条、纹章/次数展示、立即复活与放弃退出交互；离线无头测试不代表真机验收。

候选配置建议：死亡倒计时基准固定为 10,000ms（10.0秒）；复活后无敌保护时长固定为 2,000ms（2.0秒）；特殊副本挑战累计复活上限固定为 3 次；复活击退冲击波候选 200px；复活消耗 1 枚 `resurrection-emblem`。自动测试使用可控逻辑时钟跳转，不必为了测试缩短倒计时；所有数值均为显式 local-test，后续可由正式配置表覆盖。
