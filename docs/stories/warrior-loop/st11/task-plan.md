## ST11-01：移动输入片段与权威位置

Blocked by：无本包阻塞（真实ST10/ST05/ST04能力已就绪）。

交付行为：真实ST10 ready后的场景接收摇杆输入、客户端预测、服务端重算并纠正位置；移动可独立演示。

验收：

- 真实身份/会话/role、scene/timeline、CP版本、连续seq/tick、摘要及活动前沿全验；累计不超真实允许时间，不逐段赠送容差。
- X走跑/Y定速/斜向和面向服从主规格；地图足迹及静态墙体配置显式绑定版本，扫掠整路径拒绝薄墙穿透，穿怪不产生免伤。
- 打通simulation.submit执行及小型原结果/原操作查询，原子A/H/CP/实际变化块/O；未知恢复原意图，旧场景和旧回执不能覆盖新状态。
- 客户端输入队列有界，离散输入不静默丢弃；超过1秒未确认预测停止并查询原结果/当前CP，重放和心跳不刷新输入缺口。
- 整段/任意切片、不同渲染FPS位置和余数一致；时钟边界/2秒缺口/旧代次/写故障/丢响应/真实接管两顺序有证据。

## ST11-02：三段普攻、逐目标命中与暴击

Blocked by：ST11-01。

交付行为：按住普攻在真实输入链路中完成三段循环，客户端看到权威命中/伤害/受击反馈，恢复后连段及调度可继续。

验收：

- 三段动作、固定衔接/缓冲按版本配置；起手和未生成节点调度进入CP，单段每目标去重，稳定遍历与事件排序不依赖容器枚举。
- 先几何接触再逐段逐目标命中、独立暴击；精通不影响普攻，增伤/护甲等按当前数值合同与明确测试配置，0伤害不私加保底。
- 采用单一精确伤害/时间入口、稳定事件ID和服务端合法战斗随机；原意图重放不重抽，攻击随机不暴露掉落/强化状态。
- 普通倒地从出现/起身后跨招累计直接伤害，死亡优先；受控与免疫用显式靶怪配置，不编造完整怪物AI/奖励。
- CP扩展动作/目标/随机游标及必要紧凑快照，公开查询、预测、拒绝/未知/重开和当前状态纠正完成端到端。

## ST11-03：十字斩、投射物与叠加流血

Blocked by：ST11-02。

交付行为：合法十字斩取消普攻并以近身和飞行十字两节点命中；各有效段独立附加保守预算的流血，跨片段/恢复不丢失。

验收：

- 按等级/MP/CD/控制校验后才取消普攻；低蓝/CD/未解锁拒绝不耗资源、不取消当前普攻，后续合法移动仍处理。
- 十字两节点独立几何判定/命中/暴击；发射后独立存续，路径扫掠及逐目标去重不依渲染帧，未生成和已释放残留分开处理。
- 每招固定流血预算按节点权重精确分配，未中不附着，叠加保留旧预算；攻端快照、逐跳独立暴击、防端实时且减伤一次，DOT不累计倒地。
- 急速封顶2倍，节点/间隔/持续从原点独立有理映射，固定跳数/预算不随切片或急速增加，最后份额承接预算余数。
- 增量扩展CP紧凑效果/快照及按需块与公开证明；最大本技能合法并发、恢复/切房/目标死亡/攻击者属性变更、自然回复余数及写故障可验证。

## ST11-04：崩山击、位移与特殊击倒

Blocked by：ST11-03。

交付行为：崩山击三节点随真实合法地面轨迹结算，终段特殊击倒，客户端反馈与权威事件相连。

验收：

- 起跳接触/下劈/终段三节点及本次MP/CD/急速快照按配置；前两段可触发普通累计倒地，终段才自带特殊击倒。
- 复用移动扫掠/足迹/障碍规则，地图边缘、角落、薄墙、大步长和急速变化均不越界；以实际合法位置判命中，无画面高度豁免。
- 目标抗性/霸体按当时状态处理；普通短控制不缩短已有倒地，起身清累计，致死不再起身。
- 合法取消、拒绝不取消、每段流血份额、残留/打断边界及CP重建全部在真实片段链路演示，无独立客户端伤害上报。
- 最高急速与任意片段切法同结果，写失败/丢响应/恢复/切房并发保留已确认状态。

## ST11-05：拔刀斩与宽幅单节点判定

Blocked by：ST11-03。

交付行为：拔刀斩完成起势后的宽幅单次横斩，多个目标分别命中/暴击，沿同一原操作和CP链路恢复。

验收：

- 解锁/MP/CD/动作合法性、普攻取消和起手快照与共用技能入口一致；只产生一个伤害节点，不恢复为持续扩散剑气。
- 宽幅前向几何、边界与稳定目标排序采用明确配置；每目标每节点一次，可命中近远多个目标但不转成多段。
- 单节点整招预算及附着流血继承共用守恒/独立暴击/实时防御，未命中不补伤，不重复消耗随机。
- 客户端展示明确释放/命中/拒绝/未知及权威纠正，旧响应不得恢复低版本血蓝/动作；重开后可恢复未确认原输入。
- 与十字及普攻连续施放、低蓝/CD拒绝、急速/增益中途变化和各参与写点失败通过端到端验证。

## ST11-06：大崩、独立残留与四技能连续战斗

Blocked by：ST11-04、ST11-05。

交付行为：大崩完成受地图约束的位移、拍地与三次爆发；四技能连续输入与死亡后的合法已释放残留在统一权威状态中重建。

验收：

- 大崩4节点，拍地特殊击倒及后续爆发范围独立判断；倒地等待本次效果结束，不每段叠加整段倒地，免疫仍承伤/流血。
- 整条位移路径采用共用扫掠碰撞，朝边缘、角落、薄墙释放不出地图；实际落点建立后续地面来源，跳跃只影响表现。
- 已释放残留与未生成节点区分，攻击者死亡/属性变化不销毁合法尾伤或改旧快照；目标死亡清目标效果，切场景不打新怪。死亡/奖励对接仅走内部权威事件，不引入公开reportEvents或异步补奖架构。
- 四技能/普攻/控制/属性事件混合序列的整段与任意切片、30/60/120渲染帧一致；真实ST10加载/恢复、非零回复、当前装备/破损与最高急速共同回归。
- 当前战士实现域的稳定按需1～8块、效果128B/快照192B及头16KiB/块80KiB/总640KiB实际UTF-8、32KiB公开页/回复、最大合法并发和有界CPU记录；不截断合法效果。怪物912效果等未来AI状态用合法编码夹具验证接口并标明ST12尚未实现，不能宣称完整AI运行通过。
- 重复/异参/缺序/前沿加速/旧身份/暂停补报、每新增写点故障及提交丢响应/两种争用顺序全部验证；完成真实服务与客户端连续战斗命令演示，最终两轴独立review集中修复。
