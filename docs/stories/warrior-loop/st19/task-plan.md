## 任务详情说明

### ST19-01：策略引擎与多策略分层体系
- **What to build**：
  - 策略算法与配置解耦，构建策略注册表与统一分发接口；
  - 实现三种策略：`weighted-random`（标准权重随机）、`missing-slot-first`（100% 缺件优先）、`weighted-missing-first`（缺件加权，如 2:1 偏向缺件）；
  - 动态策略配置结构（`DropStrategyProfile`）：`profileId`、`version`、`strategyId`、`candidates`、`fallbackStrategy`、`holdingsDomain`；
  - 挑战创建时固化策略 Profile 引用（`challenge.dropProfileRef`），确保挑战进行中不受热更新影响。
- **Blocked by**：无（基于现有 ST15-03 结算接口）。
- **验收**：策略算法独立单元测试、多 Profile 调度分发、特殊本资格严格校验、非特殊本尝试掉落套装失败拒绝。
- **覆盖**：AC19-1、AC19-2。

### ST19-02：全口径持有同步检测与双角色严格隔离
- **What to build**：
  - 聚合检测当前角色 13 槽穿戴、背包、个人金库、公共账号金库、有效邮件、永久待领；
  - 双角色强隔离：同一账号下创建角色 A 与角色 B，角色 A 拥有未绑定的套装部位，角色 B 检测缺件时绝对排除角色 A 的私域物品；
  - 只有真正存入账号金库的公共装备才进入账号 scope；
  - 邮件时效性：`now < expiresAt` 计入持有，`now >= expiresAt` 自动排除并恢复缺件；
  - 完整性防护：摘要损坏、负数、domainRef 不匹配时原子拒绝，绝不当缺件补发。
- **Blocked by**：01、ST09、ST07。
- **验收**：双角色三容器测试矩阵、有效邮件恰好到期前后断言、未拾取地面物排除、损坏摘要整笔拒绝。
- **覆盖**：AC19-3、AC19-4、AC19-5。

### ST19-03：固定样本重映射、全齐平滑回退与提交不可变性
- **What to build**：
  - 确定性基础随机样本绑定 `sourceKey`，OCC 并发冲突重试时重映射候选池，基础样本不漂移；
  - 全齐安全回退机制：当角色已集齐 11 个套装部位时，平滑降级调用 `fallbackStrategy` 正常发放，严禁卡死或拒发；
  - 首次提交后不可变：生成装备实例、pending grant 与原回执 `clearReceipt` 后，重复请求幂等返回原结果。
- **Blocked by**：02。
- **验收**：OCC 模拟并发重试时样本稳定性测试、11 件全齐回退测试、网络重放原意图幂等性测试。
- **覆盖**：AC19-6、AC19-7。

### ST19-04：生命周期联动与客户端套装收集展示
- **What to build**：
  - 资产变动生命周期缺件联动：
    - 商店出售最后一件该部位套装装备 $\rightarrow$ 该部位即时恢复缺件状态；
    - 强化永久损毁最后一件该部位套装装备 $\rightarrow$ 该部位即时恢复缺件状态；
    - 跨 scope 存入/取出账号金库 $\rightarrow$ 账号/角色持有即时同步更新；
  - 客户端套装收集状态协调器（`CollectionCoordinator`）与纯模型/UI 视图：
    - 展示套装收集进度（如 `X/11`）、已收集部位点亮与未收集部位灰显；
    - 通关结算界面展示套装掉落与缺件补齐动态反馈；
    - 迟包与切角代次隔离。
- **Blocked by**：03、ST18-02。
- **验收**：出售/损毁后缺件恢复回归测试、跨库移转持有同步测试、客户端收集模型 100% 测试、迟包隔离测试。
- **覆盖**：AC19-8。

### ST19-05：全链路大闭环联合验收、预算实测与两轴独立评审
- **What to build**：
  - 端到端大闭环：挑战特殊副本 $\rightarrow$ 缺件检测 $\rightarrow$ 补齐缺失部位 $\rightarrow$ 存入账号库验证二角色隔离 $\rightarrow$ 出售/损毁恢复缺件 $\rightarrow$ 全齐回退随机策略；
  - 终局结算物理事务预算实测（R44 / W33 / 78 调用，16KB 汇总限制）；
  - 11 实体原子故障逐写点回滚验证；
  - 并发 OCC 交叉竞争验证（通关结算 vs 装备出售、通关结算 vs 强化损毁、通关结算 vs 账号库存取）；
  - Standards 独立评审与 Spec 独立评审。
- **Blocked by**：04。
- **验收**：全 11 部位逐一收集至全齐完整测试、实际物理读写与字节计量、11 实体逐写点故障注入回滚、两轴独立评审 0 违规 0 偏离。
- **覆盖**：AC19-1 ～ AC19-8 全量。
