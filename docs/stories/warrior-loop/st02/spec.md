# ST02：创建战士、隔离成长与初始物品实施规格

2026-10-22。承接ST01本地交付与用户推进意图；本文件为ST02实施任务图待确认稿，不授权SDK安装、云资源或部署。来源为[故事卡](../st02.md)、[数据字典](../../../backend/data-dictionary-v2.md)、[物理映射](../../../backend/asset-physical-mapping-v1.md)、[核心契约v2](../../../backend/core-contract-v2.md)及[真相源索引](../../../backend/source-of-truth.md)。

## 玩家可验证结果

合法会话下，玩家提交战士创角请求：
1. 校验姓名：中文1～6字或英文1～12字母、不混合；服务端全局原子占名，同账号下同职业不可重复创建（当前仅开放warrior，hunter未开放创建）。
2. 初始化角色：1级、0经验、308城镇体力、独立旅店位置 `inn{characterId}`，3个初始空快捷栏。
3. 隔离容器：初始化20格角色背包和20格个人金库；共享账号金库（100格）和共享钱包保持账号生命周期，创建角色不重置共享资产。
4. 穿戴初始武器：合法10级白品质战士武器，角色绑定，耐久满额（wearEnabled=true），直接穿戴在weapon槽。
5. 发放新手邮件：发送角色绑定新手礼包邮件（8血药、8蓝药、10纹章），有效期30天，并原子写入不可重复领取的来源存根（即使删邮件也不得重复发放）。
6. 原子事务保障：上述9键变更在单一事务内原子提交，任何一处失败整笔回滚；相同意图支持响应恢复，异意图同名/同职业严格拒绝。

## 本轮范围

- 本地真实MemoryStore事务实现v2创角能力，遵守已批准的资产物理映射与9键事务预算。
- 角色全局名称占用采用确定性键 `characterNames/{name}` 原子互斥，解决并发冲突。
- 客户端纯模型 `CharacterCoordinator` 负责输入校验、会话信封封装、超时重试与状态恢复。
- 不引入外部npm依赖，不修改真实云数据库，不连接真实微信鉴权。

## 公开测试边界

1. Character应用入口（会话信封+创建请求→公开响应）：验证合法创角、名称非法/超长/混合、职业重复（CLASS_EXISTS）、未授权职业、会话失效及异参重试拦截。
2. 真实MemoryStore事务入口：并发同名创角单赢、9个写点故障注入全额回滚、同意图网络丢失恢复、已有账号资产与金库不重置验证。
3. CharacterCoordinator+传输端口：超时unknown保持原意图重试、迟到旧回调隔离、状态机驱动。

## 完成与准入

01～06覆盖名称策略、角色容器、武器与邮件、原子事务与回滚、调用方协调器、联合验收与独立评审。任务粒度及硬依赖需人工确认后进入实现；计划批准与独立产物验收分别记录。
