## Question

挑战的唯一性、退出恢复、复活消耗、死亡期间世界运行、通关与掉落如何处理？

## Answer

下表为用户 Q1–Q23 的最终回答整理；Q23 纠正优先于此前概括。用户已确认本轮基线落档。

| 问题 | 确认结论 |
| --- | --- |
| Q1 | 每账号最多一个未完成挑战，换角色须先结束当前挑战。 |
| Q2 | 关闭/重启游戏、设备丢失后不恢复挑战；回城，未通关挑战失败，体力不退。 |
| Q3 | 支持原地复活，满血满蓝，消耗复活纹章。 |
| Q4 | 最终首领死亡立即确认通关与通关奖励，不等退出场景。 |
| Q5 | 短暂断线最多等10秒，暂停本地战斗，超时结束挑战。 |
| Q6 | 手动复活扣当前角色背包一枚纹章，无纹章不能付费复活，不自动替用其他货币。 |
| Q7、Q9 | 普通副本不额外限制复活次数；特殊副本按副本/难度配置整次挑战累计上限，具体次数待定。 |
| Q8、Q10 | 死亡不暂停世界；无有效玩家目标的怪物不主动施法，随机游荡。已有投射物、地面效果、持续伤害及玩家技能冷却继续。 |
| Q11 | 死亡选择窗口10秒；手动确认才消费，放弃或到期回城。 |
| Q12 | 复活不重置技能冷却，提供2秒受击保护，期间可移动攻击施法；击飞周围一定范围怪物。 |
| Q13 | 死亡后最终首领被有效残留伤害击杀仍通关；自动免费复活，不扣纹章、不占次数，取消死亡倒计时。 |
| Q14 | 复活击飞仅控制、不造成伤害，向外击飞后倒地；范围、距离、高度、倒地时长待调。 |
| Q15 | 复活击飞遵循控制免疫：普通/精英默认可控，首领按类型可免疫；玩家保护不因此取消。 |
| Q16 | 死亡与断线倒计时独立，先到期者结束未完成挑战；重连不重置死亡倒计时。 |
| Q17 | 最终首领死亡时剩余小怪视作玩家间接击杀，正常结算经验及随机装备、材料、金币，不漏发、不重复。 |
| Q18 | 通关后在线拾取无时间限制，不主动结束就不返回。 |
| Q19 | 当前不支持挑战中换装，但设计须预留未来换装扩展。 |
| Q20 | 通关后关游戏、换设备或断线超过10秒回城，未拾取掉落消失；成功与已得奖励保留，不能改判失败。 |
| Q21 | 挑战中升级立即生效，基础属性更新，满血满蓝；怪物入口等级不变。死亡例外见Q23。 |
| Q22 | 锁屏/切后台也暂停战斗并进入10秒恢复窗口；超时未通关则失败，死亡倒计时继续。 |
| Q23 最终纠正 | 死亡后仅最终首领被流血或残留技能击杀触发通关免费复活；其他怪死亡、获取经验甚至升级均不自动复活，仍需手动决定是否消耗纹章。 |

已持久化收益保留；响应丢失查询原请求结果；体力不退款。地面未拾取物不转待领区，通关装备满包则进入原角色待领区，沿用整体规划。
