# D04 地图、怪物与副本节奏

Type: design-requirement
Status: proposal-ready
Recorded: 2026-10-19
Parent: [模块地图](../map.md)

## 依赖

D01战斗预算，与D03奖励共同迭代。

## 范围

先提出第一个升级副本普通难度的完整6–8房间遭遇，再扩展第二升级副本及30级特殊副本的难度差异。

## 继承的决定

副本区间1–15/15–30/30、等级入口、整次锁定怪物等级、账号共享逐难度解锁；普通/特殊房间体力1/3；不增加评分或前置通关门槛。

## 待方案与专题讨论

房间顺序、近战/远程/冲锋组合、精英与Boss机制、控制抗性/倒地阈值、难度倍率与预警下限、局长。

## 交付物

已产出 [首个升级副本（1–15级）地图、怪物与节奏方案 v1](../../../design/dungeon-first-proposal-v1.md)，包含：
- 7 房间连续遭遇流线（近战教学 → Y轴聚怪 → 远程投石红圈 → 直线冲锋虚弱 → 中场牛头守卫精英 → 混合波次 → 关底蛮荒牛头巨兽两阶段）。
- 全怪物属性、U单位伤害与生命、倒地阈值抗性、红框预警时间（普通难度 >= 1.1s，王者硬底线 0.8s）。
- 初始 1 级白双刀走位通关路线（3~3.5 分钟预算，不依赖未解锁技能）。
- 冒险/勇士/王者四级难度倍率与高难词缀扩展。
- 单局金币经验均值产出模型（与 D03 联调）。

## 完成标准

初始白武器能靠走位完成普通首局；不依赖尚未解锁技能；升级不中途改变怪物等级；可反应预警；Boss抗性有明确配置；一局节奏与D01/D03预算一致。

本票是设计交接，不代表已获准修改业务代码或部署；关键取舍审阅后才标记resolved，再拆开发任务。
