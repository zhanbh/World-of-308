# D03 掉落、经济与补给

Type: design-requirement
Status: proposal-ready
Recorded: 2026-10-19
Parent: [模块地图](../map.md)

## 依赖

D01经验/资源需求、D02装备价值、D04一局时长和怪物预算联动。

## 范围

经验与金币来源、材料和通关掉落池、商店/兑换、扩容、药品、新手补给、强化成本/纪念品及特殊副本复活次数。

## 继承的决定

不赠初始货币；初始白武器/新手邮件角色绑定；每5级保底邮件；邮箱30天与永久待领分开；背包20到100、费用逐次翻倍；无分解回购；双向兑换不套利；强化既定概率区间不擅自改写。

## 待方案与专题讨论

数量/价格/概率、兑换比例与整数单位、幸运各系统收益/封顶、强化15–20曲线及纪念品参数、复活预算。

## 完成标准

掉落资格和概率合法；普通开局不依赖购买纹章；无买卖/兑换循环增资；失败无通关奖励；强化消费/返还可对账；经验衰减只作用经验；待领不丢奖。

本票是设计交接，不代表已获准修改业务代码或部署；关键取舍审阅后才标记resolved，再拆开发任务。


2026-10-19最新来源限制：套装只由30级特殊副本怪物掉落及通关结算奖励提供。升级副本紫装为散件，不能进入套装池；20/25档套装候选撤回。具体概率/模板与副本难度配置仍待方案。

## 测试节奏反馈

用户要求测试期套装收集更快、正式可调长，并指出3缺1/5缺1。已在经济方案补测试/正式配置分离及测试缺件优先候选，未获确认也未实现。旧27局为纯随机期望，不能作为保证或完整解决重复件长尾。通关奖励仍1件，不擅自改结构。

## 测试缺件优先确认

用户认可测试期特殊副本通关缺件优先，并要求背包/穿戴检测。经济方案第9节已列持有集合、待领/有效邮件、同批次暂占、幂等/并发及全齐回随机验收；仅规划，尚未实现。正式掉落策略独立待定，怪物随机掉落仍可重复，不把测试保证扩大为全掉落不重复。

## 动态掉落策略（已确认方向）

用户要求测试/正式掉落策略可动态配置加载，正式收集周期可调长，不将缺件优先写死。[策略方案](../../../design/drop-strategy-proposal-v1.md)已列策略注册、版本选择/切换、旧奖励幂等与环境隔离；具体生效时点为实现建议，正式概率/保底未定，代码未实现。
