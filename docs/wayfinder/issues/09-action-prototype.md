# 动作原型范围与操作

Type: decision
Status: resolved
Parent: [308世界整体规划](../map.md)
Recorded: 2026-10-15

## Question

做多小的原型，就足以验证移动、攻击、受击和技能是否好玩？

## Answer

用户逐项确认：一个双刀战士、固定镜头房间、一种近战怪的单怪/三怪测试，配套血蓝、冷却、受击反馈、清场恢复与死亡重试。MVP 最终仍含战士和猎人。

后续追加决定覆盖最初两拍普攻：改为左砍、右砍、上挑、双刀交叉横扫四阶段循环，连续输入才推进，断连后从头开始，衔接间隙约 300ms 为可调初值。保留按住连续攻击。用户进一步确认：从当前阶段动作结束、允许再次出招时开始计算衔接窗口，动作期间的提前点击由输入缓冲处理，不按两次按下的时间差判断断连。受击打断或实际释放技能会重置连段，下次从左砍开始。

原型技能由范围斩、无无敌突进扩为三项，新增扩散圆弧剑气。用户纠正出招为快速连续横向挥动武器两次，然后生成一道动态扩散的圆弧剑气；波及怪物均受伤，剑气可穿过多个怪物，不会被某只怪物挡住，到达范围后消失。不是连续三次挥动各生成一道。单目标命中频率、范围参数和挥动本身是否另有伤害仍待设计。用户确认该技能替换最终战士第三技能“周身持续范围攻击”，保持四主动技能，大招留后续实现。

左下虚拟摇杆支持任意方向；X 轴按横向力度走跑，Y 轴越过死区后定速，不随力度和横向走跑变化，斜向不统一归一化。纯上下移动保留朝向，横向输入更新朝向；右下大普攻键及左上方三个技能按钮。出刀短暂限移，后摇末段恢复，允许输入缓冲，攻击有效阶段锁定朝向。

用户提供三星 Note20 Ultra；同意 Creator 3.8.8 + TypeScript、微信真机目标 60 FPS、三怪连续 10 分钟测试。横屏基础战斗画布 480×270，先试本体高约 32–40 源像素的小人物，按真机可读性调整。完整验收见[动作原型规格](../../action-prototype.md)。

双刀覆盖旧双手剑视觉与动作，不自动新增武器槽；装备映射另定。原型使用本地临时状态，不改变正式在线规则。规格落档阶段仅整理文档；后续用户要求继续并完成 Creator 安装，已建立 `client/` 第一切片，不安装额外依赖或操作云资源；没有新的提交或推送请求。

resolved 表示本轮方案讨论收敛，不表示动作、资源或真机性能已经验证。具体动作数值和生产素材规格仍需原型调试。

## 追加：动作表现参考

用户随后要求参考《三国战纪》张辽的攻击，解决第四段收招过快的问题。已找到基础连招演示，但页面访问受限，未核对视频动作；v0.4 先按该反馈增加第四段停顿和回收时间，调试时长由 460ms 改为 760ms。其余三段、移动速度和动作结束后 300ms 的连段窗口保持不变，仍待用户复评。

后续试玩调整：人物显示比例增大约 20%，移动速度保留；连段窗口由最初约 500ms 调整为 300ms。第四段又由下压收招改为双刀交叉横扫：左手向右、右手向左同时交叉，再左手向左、右手向右展开收势，作为一个阶段执行。当前正文按最新规则更新，早期下压动作不再作为实现目标。

用户要求将 Codex 宠物在拖动时呈现的左右移动、站立、转向、跑跳作为角色动作设计参考，并考虑复用相关逻辑或 skill。已记入动作原型规格第 4.3 节及验收 P13：动作随状态切换、走跑可辨、朝向正确、起停自然，游戏输入仍使用摇杆。宠物内部实现尚未检查，直接代码/skill/素材复用需确认适用性与许可；跑跳先作为表现参考，未据此新增主动跳跃或空中战斗。
