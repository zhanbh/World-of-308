# 核心规则补充访谈：已确认基线摘要

2026-10-19。范围Q24–Q119，逐项原始决定见[访谈记录](issues/01-rules-interview.md)。用户已确认汇总并要求提交推送；主规格、挑战交接及实现差异已同步，业务实现未在本轮变更。遇到历史冲突，以用户最后纠正为准。

## 1. 背包、商店与奖励

- 每角色一个背包，初始20格，金币分4次每次解锁20格，最终100格；每次价格翻倍，基础价格未定。城镇直接点击锁定格扩容，战斗不能扩容。取消旧四背包位、背包物品和替换机制。道具每组20、账号金库100格等规则沿用。
- 满包换装可原格交换；直接卸装需要空格；出售穿戴装备前先卸入背包。不提供分解、历史回购或无武器救济；允许卖掉全部武器，无武器禁止进副本。
- 金币商人常驻无限供应各档白武器和基础恢复药；装备按装等/品质固定售价，强化和词条不增加收购价，买卖不能套利。
- 点券商城独立，商城商品账号绑定、不可出售；复活纹章通过点券商城购买。金币/点券既有兑换机制沿用，比例、整数规则及商品表另做方案。
- 通关满包待领奖励归原角色，不自动过期、不设导致丢奖或阻止挑战的数量硬上限。

## 2. 新手、等级奖励与邮箱

- 新角色直接装备职业基础白武器，保障初始入门副本顺畅；武器固定属性、不自动成长，可出售。新手药品/纹章发角色一次性邮件；这些新手赠品均角色绑定，数量待定。创建角色不额外增加共享金币或点券。
- 5/10/15/20/25/30级各发一次固定属性、角色绑定的职业优秀（绿）武器，装等15/20/25/30/30/30，发邮箱；可强化、损毁不补发，各节点防重复。
- 角色邮箱只在城镇使用，战斗轻提示。发件起30天到期，删除邮件及未领附件，不转待领、不补发；可逐附件领取，一键尽可能领取；有附件不能手动删除；不因容量拒收新奖励。

## 3. 强化与装备

- 战士双刀为一件装备、一个武器槽。套装有明确名称，成套品级一致，不跨装等凑套。
- 城镇强化NPC可处理已穿戴武器/耳环；执行后成功、失败均消耗金币/材料，拒绝或未执行不扣。旧成功率和降级/损毁区间沿用，具体成本等另做数值方案。
- 损毁返回统一角色绑定纪念品，目标等级决定数量；满包剩余发邮件。强化时可主动消耗纪念品，仅本次加概率，成功失败均消耗，同次不叠加，不显示概率。
- 首版无强化继承，后续只考虑传说装备继承。取消分解不取消强化损毁/纪念品规则。

## 4. 职业、饰品与冷却（最终覆盖规则）

- 战士四技能在角色1/5/10/20级解锁；解锁为技能1级，之后角色每升2级，技能升1级。每级固定增加技能基础伤害，最终伤害由数值系统结合属性计算，不分配技能点。
- 种族被动物理/魔法暴击各增加1个百分点，受统一上限约束。
- 主动饰品只提供限时主属性/副属性/攻击力等buff；约120秒技能冷却、持续最多30秒为设计方向，实际减CD后仍必须持续短于冷却。冷却中不能更换或卸下；允许更换后触发60秒换装等待。副本内含清场阶段可施放，城镇不可施放；死亡/回城清临时buff。

| 事件 | 职业技能CD | 饰品CD | 药品CD |
| --- | --- | --- | --- |
| 切换房间 | 不重置 | 不重置 | 不重置 |
| 死亡 | 不重置 | 不重置，清增益 | 不重置 |
| 手动或通关免费复活 | 清零 | 不重置 | 不重置 |
| 回城 | **清零** | **清零** | **清零** |

| 短暂重连恢复原挑战 | 不因重连清零 | 不因重连清零 | 不因重连清零 |

“回城所有技能、道具冷却都结束”是Q119最终决定，取消旧饰品回城保留CD及药品重登保留CD的说法。付费/免费复活职业CD清零，覆盖旧挑战记录中复活不重置职业CD的说法。

## 5. 普通倒地统计

每个敌人从出现或倒地起身后开始，累计普攻和技能的直接伤害，跨招式不清零；达到该目标普通倒地阈值后处理倒地。起身清零，倒地期间伤害不带入下一轮。流血DOT不计入、不制造新的受击控制，但可致死。特殊击倒、死亡优先及目标免疫等既有规则沿用。

此决定覆盖旧“单次技能实例”累计方案，现有实现需要后续改造；阈值正式数值另定。

## 6. 副本与排行榜

- 升级副本怪物区间1–15/15–30，分别1级/15级开放；特殊副本30级。无前置通关或评分门槛，既有武器/体力/在线等通用规则保留。
- 各副本成功通关当前难度一次解锁下一难度，账号共享；另一角色达到等级即可使用已解锁难度。武器掉落职业定向。
- 可回刷低级副本，经验随等级差衰减，金币和装备不因角色超等级额外减产。30满级不累计或兑换经验，其他收益保留。
- 装备评分实时更新；玩家主动查看排行榜时取最新排名，不持续自动刷新。同分按更早达到当前分数排前；无排名奖励、无首版赛季重置。

## 7. 药品与快捷栏

- 3个玩家自定义道具快捷位，只绑主动消耗品；纹章走死亡确认，不绑快捷栏。绑道具模板而非格子，同模板耗尽换堆叠，角色绑定→账号绑定→未绑定优先，耗尽显示0不自动换更高级品种。
- 恢复即时，不打断普攻/技能；存活时受击/倒地可用，不解除控制。生命药共享血药CD，法力药共享另一CD，两类独立。固定时长不受急速/技能减CD影响，回城全部清零。
- 30级药品按使用当时最大HP/MP百分比回复，其余固定值；不限使用等级、职业。已满不能用、不耗药不计CD，未满可用、溢出舍弃。具体回复量/CD/价格未定。
