# 核心规则补充访谈记录（Q24–Q119）

本文是用户已答内容的访谈记录，已获用户确认并同步主规格及差异清单，不代表相关代码已实现。Q1–Q23见挑战生命周期记录；以下引用问题编号并保留最终纠正。

## 背包、穿戴与待领

- Q24：满包换装允许新旧装备在同一背包格原子交换。
- Q25、Q68：满包不能直接卸装；出售只处理背包物品，穿戴装备先卸下。
- Q26、Q30：通关待领奖励不自动过期，不设阻止挑战或丢奖的数量硬上限，分页展示。
- Q31最终替换旧方案：每角色一个独立背包，初始20格，其余锁定。花金币每次解锁20格，最多100格，共4次。费用逐次翻倍；1万/2万/4万/8万只是示例，不是正式价格。容量、扩容进度不跨角色共享。取消四背包位、背包物品购买/替换机制；旧Q27及Q31旧背包返还提问失效。
- Q34：城镇背包界面直接点击锁定格确认金币扩容，战斗不可扩容。
- 其他未被修改的规则：道具20个一组；账号金库100格、仅城镇访问；角色绑定物不能存入金库。

## 初始资源与等级保底

- Q32、Q35：创建角色直接装备固定属性职业白武器，不随角色等级自动成长；保证初始对应等级入门副本顺畅，能快速升级获取提升。
- Q36、Q44：新手生命药、法力药和复活纹章通过每角色一次的新手邮件发放，具体数量待定。
- Q37：创建角色不额外赠送金币、点券；账号共享钱包已有余额保留。
- Q38：5/10/15/20/25/30级每角色各发一次保底武器。跨多个节点升级要补齐，各节点不可重复发。
- Q39最终：保底发角色邮箱，不直接入包，不自动穿戴。
- Q40、Q41：保底为优秀（绿）武器，角色绑定、固定职业实用属性模板；具体数值另定。
- Q42：上述节点的武器装等依次15/20/25/30/30/30，不保证25、30级奖励比20级更强。
- Q55：保底武器可强化，适用普通成本/成功率/损毁规则，损毁不重发。

## 邮箱

- Q43：角色邮箱独立，只能由收件角色领取。
- Q45最终、Q48、Q49：发件成功时起连续30×24小时过期，离线计时；到期删除邮件及剩余附件，不转待领区，不自动补发。领取请求到服务端时已过期不能领取。
- Q46：附件逐项领取，一键领取尽可能放下的部分，未成功领取的附件保留，各项防重复。
- Q47：仅城镇打开/领取；挑战中收到邮件只做轻量提示，不暂停战斗。
- Q50：无剩余附件才允许删除；一键删除已读也不能删除仍有附件的邮件。
- Q51：不设导致拒收新奖励的邮件数量硬上限，分页并按有效期清理。
- 邮件30天与通关待领不过期是两套已确认规则，不能擅自合并。

## 商店、出售与取消分解

- Q28、Q63最终：复活纹章通过独立点券商城购买，不按此前建议加副本直接掉落。点券来源包括金币兑换及特殊渠道获得/发放；与普通金币商店分开。
- Q60：金币武器商人常驻、无限库存提供各现有装等档位基础白武器，属性固定。
- Q61：装备出售按装等、品质固定金币价，不因随机词条或强化投入加价。
- Q62：普通金币商品可低价卖回，不能买卖套利。
- Q64：不提供历史回购，卖出的随机装备不保留为商人可买回商品。
- Q65最终：不支持分解功能，取消旧规格通过分解获取材料及分解绑定继承的设计。
- Q66：点券商品禁止出售，不提供常规退点券。
- 点券商城商品账号绑定沿用旧基线；赠送来源物品的绑定不应仅凭同模板推定。

## 武器、套装和强化

- Q52：双刀一套为单装备实例，占一个武器槽；两刀共享穿戴/强化/损毁。
- Q53、Q57：无武器不能战斗；城镇可卸下，但未装备武器禁止进副本。副本仍不能换装。
- Q54：不同装等不能混搭凑套。套装有明确名称、成套品级一致，具体套装模板另定。
- Q59最终：不阻止玩家卖出全部武器，不提供救济武器；玩家通过商人购买，拍卖开放后也可购买。不能擅自加保底返还或强制保留。
- Q67：只在城镇强化NPC处强化；允许强化穿戴武器/耳环，损毁清空槽位。
- Q69：统一一种纪念品，角色绑定，20个一组；失败目标强化等级影响返还数量，具体表待设计。
- Q70：强化前手动选用纪念品，按目标强化等级配置消耗数量，仅本次生效；成功/失败均消耗，同次不能重复投入叠加，不显示具体成功率。
- Q71：实际执行强化时扣金币/材料；拒绝或未执行不扣。
- Q72：首版无强化继承；后续只考虑传说装备继承，具体条件未定。
- Q73：损毁返还纪念品优先入包，剩余邮件发放，邮件有效期30天。
- 高段强化损毁不是分解；取消分解不取消此前确认的损毁/返纪念品规则。

## 技能、种族与主动饰品

- Q74：战士技能解锁为十字1级、崩山5级、拔刀10级、大崩20级。猎人后续设计暂停。
- Q75、Q78最终：解锁时技能1级，从该角色解锁等级起每升2个角色等级，技能升1级；不分配技能点、不花金币培养。技能等级=1+floor((角色等级-解锁等级)/2)。未解锁时不可使用。
- Q79：每级增加固定技能基础伤害，最终仍结合玩家属性等统一计算；伤害公式由数值系统设计。
- Q76、Q80最终：种族被动物理/魔法暴击率各加1个百分点，非相对乘1.01，也非一次攻击加2点，受最终上限约束。取消此前生命加成推荐。
- Q77最终：主动饰品只提供限时主属性/副属性/攻击力等buff；不提供此前建议的护盾/减伤/回复技能。每件固定技能、一个饰品按钮。
- Q56、Q58、Q81、Q83最终：主动饰品冷却中不可更换、不可卸下。可更换时装备/更换触发至少60秒换装冷却。此前重登不清除的表述已被Q119“重登回城清全部CD”覆盖。旧“允许冷却中换装并取较长时间”不再适用，因为冷却中换装已禁止。
- Q82、Q84：增益持续必短于最终实际技能冷却，不设计重复施放叠加分支；急速/套装后仍满足该约束。
- Q85：死亡清除饰品临时增益，冷却继续；复活不恢复增益，常驻装备属性保留。
- Q86：副本内包括清场阶段可施放，城镇不可施放；回城清buff。此前“饰品回城继续冷却”已被Q119覆盖，最终回城清零。
- Q84补充：饰品技能冷却基本2分钟、持续最多30秒，为数值设计方向。技能本身约120秒冷却与换装60秒等待不能混为一条。

## 副本与排行榜

- Q87：升级副本一为1–15怪物区间、最低入场1级；二为15–30、最低15级。入口按角色等级锁定整次怪物等级，超过区间则封顶。
- Q88：每副本当前难度成功通关一次解锁下一难度，无评分/无死亡额外条件。普通四难度、特殊两难度沿用；解锁账号共享。
- Q89：另一个角色满足该副本入场等级即可使用账号已解锁难度。
- Q90：怪物和通关奖励抽到武器时职业定向。
- Q91、Q93最终：副本开放只需达到等级，无前置副本通关要求，无装备评分门槛；特殊副本30级。高难度解锁和已有武器/体力/在线通用规则沿用。
- Q92、Q95：可回刷低级副本；经验随等级差扩大衰减，具体曲线待设计。金币和装备按原副本/难度/锁定怪物等级掉落表，不因角色高等级额外减产。
- Q94：30满级后停止累计经验，无溢出存储或自动兑换，其他奖励正常。
- Q96最终：装备评分实时更新；排行榜独立功能，玩家主动查看时获取最新排名，不做持续自动榜单刷新。
- Q97：同分按更早达到当前分数排序，分数改变后重记新分数时间。
- Q98：不发排名奖励，首版无赛季重置。

## 药品与道具快捷栏

- Q29：战斗可手动使用血蓝药，有冷却。Q99：即时回复，不读条、不单设喝药动作。
- Q100：所有生命药共用血药CD，所有法力药共用蓝药CD，两类独立。
- Q101、Q102：3个玩家自定义道具快捷位，不固定为血蓝药。手动使用，不自动喝药，不打断普攻/职业技能。
- Q103：只绑定主动消耗品；装备由穿戴处理，纹章只在死亡确认中消费。
- Q104：绑定具体道具模板而非背包格，自动寻找同模板其他堆叠；角色绑定→账号绑定→未绑定优先。耗尽显示0，不自动改品种或升级药品。
- Q105：对应资源满时拒绝、不耗药、不进CD；未满可用，溢出舍弃，成功才扣药/计CD。
- Q106、Q111最终：30级药品模板按使用时最大HP/MP百分比回复，其余档次固定回复值；具体值未定。
- Q107：不限角色等级或职业，包括低等级角色也可用30级药品。
- Q108、Q110最终：药品CD固定时长、不受急速/技能减CD影响；死亡/复活不重置，离线自然流逝；回城两类CD直接清零。此前“重登不重置”已被Q119覆盖：重登回城也清零，恢复原场景的短暂重连不清零。
- Q109：存活时受击僵直/击飞/倒地中也可喝药，但不解除控制，死亡不可用。
- Q112：金币商人常驻、无限库存提供各档基础生命/法力药，含30级百分比药；点券商城特殊清单另定。

## Q113–Q119最终补充与覆盖

- Q113：初始白武器、新手邮件药品/纹章全部角色绑定，不套用商城购买来源的账号绑定。初始武器仍允许出售，不强制保留。
- Q114、Q118：职业技能换房不重置，死亡时继续，手动纹章复活或通关免费复活均清零，回城也清零。覆盖旧挑战记录中的“复活不重置职业技能”。药品和饰品不因此同步清零。
- Q115、Q116：普通倒地统计从敌人出现或倒地起身后开始，同一敌人的普攻与技能直接伤害共同累计，跨招式不清零，不再按单次技能实例或单次普攻独立统计。倒地期间伤害不带入起身后的新一轮，起身清零。特殊强制击倒继续按技能规则处理。覆盖此前用户确认的单次施放累计口径及其原型实现。
- Q117：流血等DOT不计倒地累计，不触发僵直/击退/普通倒地，但可致死。
- Q119最终：回城时所有技能、道具冷却全部结束，包含职业技能、主动饰品、各类药品；覆盖此前“饰品回城继续冷却”和“药品重登不重置”。彻底重启结束挑战后回城同样清零，10秒内恢复原挑战的短暂重连不算回城、不清零。
