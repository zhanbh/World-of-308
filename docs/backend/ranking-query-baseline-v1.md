# 排行查询与评分依赖基线 v1

2026-10-21。工程候选，待评审/实现验证；不增加奖励、赛季或社交功能。

评分配置只依赖穿戴实例的slot、itemLevel、quality、enhancement、词条与套装键；候选评分不依赖当前耐久、角色基础属性和临时buff。武器归零照常失效战斗属性，但不凭耐久变化改变装备价值分。此为待审评分政策，尚未写成用户确认。初始公式候选：单件分=floor(100×装等×部位权重×[品质系数+0.05×强化级+0.1×Σ词条归一值])；武器权重2、五防具1、其他七槽0.75，品质白/绿/蓝/紫/橙为1/1.2/1.5/2/2.5。词条归一值=实际滚值/该模板该词条合法上限，仅额外主/副/稀有/奖励属性参与，每条计一次；固定基础不重复加。特殊被动与套装不再单独加一遍分，由品质分承载，不把临时套装触发状态放进评分。总分为13槽单件分之和，空槽0，最多13件；无合法上限/模板的词条拒绝生成评分，不静默用0。该公式是可替换的评分候选，不是战力/伤害公式或用户已认可权重。

首版查询页20条，最多50，缓存只存首屏，键scope+class+scoreConfigRef；候选新鲜期15秒、允许显式标旧的回退最多60秒。缓存是独立rankCaches确定键，刷新使用短租约3秒和版本CAS；抢锁失败读旧缓存或有界索引查询，不等待常驻任务。页面关闭不轮询，同一打开流程最多一个刷新在途。租约过期可接手，旧刷新写须匹配token。所有秒数可调，不改变资产语义。

后续页按稳定排序三元组游标直读索引，游标含scope/公式版本、签名及页上界；10分钟过期候选只影响游标，用户可重新打开，不删除排名或资产。翻页不是快照，会受换装并发影响；界面按characterId去重。首屏asOf不被当成后续页共同快照时刻。

总榜和职业榜索引分别覆盖scope/version/score降序、scoreReachedAt升序、characterId升序。准确本人名次用三段互斥索引count：分高；同分时间早；同分同时间ID小，三数+1。读取本人事实与查询期间可变化，所以返回rankAsOf与equipmentVersion，不承诺跨查询瞬时快照。聚合count能力/索引性能不满足时仅该名次字段返回暂不可用，保留本人分数及有序榜单；不全表拉取，也不伪造“未上榜”。准确名次仍是接入验收项。

缓存失败不回滚装备；投影版本冲突返回明确新鲜度状态，查询不能修改scoreReachedAt。公式更新采用新version隔离、完成离线重建与一致性检查后原子切榜；当前包不授权改变现有玩家装备或热改公式。

验收覆盖15/60秒边界、刷新租约丢失、旧token覆盖、缓存含私有字段、总榜/职业分页、本人500→600→500并发与count失败。所有为计划，未建索引或缓存。

算例（仅公式检查）：装等10白武器+0且无额外词条，2000分；同装等绿武器+0、1词条滚到上限，2600分；白武器+10为3000分。未装备为0分，耐久0按本候选仍保留相同装备分。实现后必须用完整13槽实例和所有合法品质验证。
