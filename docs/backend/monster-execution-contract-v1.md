# ST12 怪物执行边界 v1

2026-10-26。承接[首本组合规则](../design/dungeon-first-proposal-v1.md)、[三本可调整原型](../design/warrior-three-dungeon-baseline-v1.md)、[ST12已确认实施规格](../stories/warrior-loop/st12/spec.md)。本文记录本轮明确批准的待决边界；不冻结候选秒数、伤害或正式内容表。

## 半血交接

首Boss生命降至50%时记录待切阶段；正常施招需等本次动作（包括收招）结束。合法中断结束本次动作后允许交接，但不解除已有控制，不清冷却、不回血、不无敌、不免费追加攻击。死亡优先，禁止待切阶段复活死亡目标。动作/控制/伤害的同刻顺序必须由确定性联合调度规定并验证，不能靠对象遍历或渲染帧。

## 吼叫

首Boss吼叫从正式起手至末跳处于本怪物的施招霸体，收招恢复正常控制；覆盖旧敌招节点候选“起手可控”，不影响其他怪物引用该技能时的显式抗性配置。霸体仍承受伤害与流血。

倒地阈值的最大生命值按本次正式起手快照；分子仅累计这次吼叫对玩家实际造成的伤害。达到配置比例时最多倒地一次，离开重入不重置。倒地后处于扇形范围内仍继续受伤与击退，离开范围或技能结束停止。吼叫六节点候选不允许实现暗加第七跳；比例、范围、时长、击退强度和CD保持版本化候选。

## 验收边界

AI必须和玩家技能、位移、HP及控制在同一逻辑时间链中推进，中途受控/死亡影响同批后续输入。选招、冷却、锁向、待切阶段和随机游标持久化，原意图和恢复不重抽。怪物配置新增必须同步公开协议、私有CP、发布算术与编码/事务预算；旧profile严格兼容，不因字段存在而默认启用AI。

ST12产生稳定击杀与紫名倍率事实供ST15使用，不能提前发送正式奖励。最新Cocos构建/可操作演示与平台、手机验收分别记录；训练配置/确定性测试不能冒充正式三本平衡或真实云事务证据。
