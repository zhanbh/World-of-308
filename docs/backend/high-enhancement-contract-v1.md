# 玛丽高段强化、损毁与纪念品合同 v1

2026-11-02。实施ST18-02，遵循[玛丽低段合同](low-enhancement-contract-v1.md)、[ST18规格](../stories/warrior-loop/st18/spec.md)、[持有汇总](collection-holdings-projection-v1.md)、[事务预算](enhancement-terminal-budget-v1.md)及其字段/API/状态视图。本文记录已确认规则与隔离实现配置；候选参数不是正式数值。

## 可用范围与报价

- 目标必须严格等于当前强化等级+1，最高+20；只作用在当前角色装备或背包里的active武器/耳环。正式场景未接入。
- +10之后每档金币是上一档的2倍，武器费用高于耳环；材料表独立配置。报价绑定原玛丽上下文、角色/装备/钱包/背包版本和不可变配置。
- 可选使用一组角色绑定纪念品。报价将它列为第二项materialCost；必须从本角色背包找到并扣足配置数量。异角色绑定、账号绑定、未绑定或不足时，报价/执行失败关闭，不消费。该布尔选择属于原始请求，迟包及重放仍复用原operationId。
- 11–12失败降至+10；13–20失败永久损毁。尝试成功或失败均扣金币和强化材料；明确选用纪念品时也均扣纪念品。前置拒绝不扣费、不消耗记忆/样本。

## 概率、AP与待校准候选

- 已确认基础率：11=50%、12=40%、13=30%、14=25%。15–20显式读取六项整数百万分率配置，当前隔离夹具为20%、15%、12%、9%、6%、4%，只是可替换的测试样本。
- 幸运及已提交失败记忆按原合同增加成功阈值，总概率受配置上限约束；纪念品加成也按目标等级从配置读取。报价不公开基础率、样本、记忆或阈值。
- 强化AP使用配置的1–20耳环累计表，武器精确取耳环的3/2。项目夹具的高段AP和15–20概率均未经过正式数值平衡，不可发布为正式配置。
- `mementoCostByTarget`、`mementoBonusByTarget`、`destructionMementoReturnByTarget`均必须显式配置。当前隔离夹具在各档耗1组、增加5个百分点、损毁返还5个；这些值没有被产品确认，不能作为线上缺省值。

## 同笔结算、持有与溢出

1. 在原子事务中消费强化材料和所选纪念品，更新各余量的J lineage。失败11/12将既有`enhancementLevel`和AP投影改为+10。
2. 失败13–20将装备生命周期置为destroyed、位置置为`retired{reason:'destroyed', sourceRef:itemId}`；原`sourceKey`、来源定位和损毁前强化事实保留。先从角色穿戴/背包实际引用中移除装备，再处理纪念品返还。
3. 返还只发character绑定的配置数量。先填本角色已有同模板堆叠至20，再按空格编号新建至多20个一堆；背包仍放不下时，生成一封确定键、单附件、30天有效的character绑定stack邮件，`quantityGranted`不超过8。
4. 邮件遵循现有`MailService`和角色邮件索引。领取受当前背包容量/堆叠规则约束，重复原操作不得重复返还；不另造积分或可领余额。
5. 穿戴强化成功/降级/损毁同笔维护当前有效属性、装备版本、固有评分和排行榜；评分不受耐久影响。适用套装损毁同步将角色scope持有汇总减一；普通强化/降级不改持有。非套装不读持有表。背包目标损毁移除背包引用和适用持有贡献，不改变穿戴评分。
6. 钱包、背包、装备、记忆、角色、账号写栅栏、所需排行/持有行、溢出邮件、原O/J同成同败。新写点故障测试逐点验证MemoryStore整笔回滚；商店出售/卸装先后由真实服务和角色上下文/资产版本拒绝过期操作。

## 发布边界

这是显式`local-test`/`isolated-local-assets-only`配置的有界实现。正式高段15–20率、纪念品成本/加成/返还量及完整平衡仍待确认；正式数据库/SDK事务限制、最大场景负载与云成本仍未验证。不得把本地MemoryStore结果或候选数值表述为正式发布验收。
