# 普攻攻速与技能取消（原型）

2026-10-16。用户同意接入基础普攻节奏、属性加成缩放，并确认普攻过程中可以强制取消接技能。状态：模型、Cocos与独立评审页已接入，待统一手机试玩。角色属性换算、正式攻速上下限与装备数值仍待数值系统设计。

## 基础与加成

普攻基础三段280/300/420ms，一套1000ms。姿势节点、命中与移动开放相对位置沿用原动作比例，整段同步重定时。旧780ms是历史原型值。

普通加成 = 属性换算 + 装备 + 被动 + 普通增益；攻速倍率 = 1 + 普通加成。来源先相加，不把每件装备分别相乘。模型接口setAttackSpeedBonuses接收小数比例，例如0.15表示+15%。不默认敏捷提供攻速，不在此轮猜测属性换算率。特殊独立倍率未接入。

实际每段动作时间 = 基础每段时间 / 本段锁定倍率。1.0×/1.25×/1.5×空挥完整一套约1000/800/667ms；命中顿帧会增加实际耗时，不把空挥时间当作带顿帧的实战周期。

- 每段开始捕获当前倍率；段中属性变化下一段生效，当前姿势不突跳。
- 动画、直接命中与攻击移动开放共同使用同一攻击时钟。
- 跨段的剩余时间先按旧倍率换算回实际时间，再按新倍率进入下一段，避免切换加成时漂移。
- 续接窗口维持动作结束后300ms；输入缓存维持收招前120ms的实际战斗时间，均不随攻速变短。
- 命中顿帧、流血、击倒、冷却与技能时序不受普攻攻速缩放。
- 代码保护范围0.25–3×只用于避免无效/极端倍率破坏原型，不代表最终数值上限；无效非有限输入忽略。

## 普攻取消接技能

四技能共用tryCastWarriorSkill入口。角色存活、无受击硬直、技能可用且蓝量足够时，成功施放立即取消当前普攻；无需等命中或收招。

成功后清空普攻阶段、续接、点按缓存和按住状态，保留已经结算的伤害；未来普攻命中不再发出。游戏端同步清空触屏按住普攻记录；键盘仍按住空格时不会在技能结束后自动重启，需重新按下。旧普攻命中顿帧立即解除，避免新技能起手被旧停顿拖住；已出现火花和跳字继续自然消退。

冷却、缺蓝、死亡、受击硬直或已有技能时拒绝施放，普攻状态/资源/当前顿帧不变。不因此开放技能之间取消。

## 对比与验证

Cocos原型在左上方提供1/1.25/1.5×调试按钮，选择只修改调试普通增益；当前段倍率保留到结束，下一段生效。独立普攻页和技能页分别提供普攻攻速选择，原有播放速度是慢放工具，两者互相独立。

独立技能页新增“取消普攻接技能”及技能选择；用于连续战斗规则验证，不像单招艺术评审按钮那样重置蓝量/CD/靶怪。选择一段普攻后可在前摇、命中或收招时尝试取消；拒绝原因显示在页面。

模型覆盖：三档攻速逐段命中与移动边界、固定续接/缓存、属性普通加成相加、段中变化锁定、三段前后分别接四技能、已命中保留/未命中取消、无自动补招、失败输入原子性、成功取消释放旧顿帧。浏览器确认100ms命中前取消后仅十字两段、目标29/30；冷却中再次输入时普攻保留；倍率切换时本段1×/后续1.5×，下一段实际使用1.5×。

## 持续普攻的轻微前移

用户2026-10-16新增要求：持续按住普攻、不按方向时也极缓慢向前移动。原型暂定每段前移1.2源像素，分布在动作进度20%–65%，方向沿角色朝向，仅影响X。按住状态且X/Y输入都在摇杆死区内时生效；单次点按释放、方向输入、受击/死亡、技能取消后停止自动前移。每段位移固定，不因攻速直接变大，因此更快攻速每秒触发更多小步。与主动移动不叠加，受房间边界约束，不自动切到跑步姿势。
