# Warrior Pixel Concept v1

This is an early visual exploration for the warrior character in the 2.5D action RPG, retained as a reference rather than the current gameplay definition.

> Planning note (2026-10-15): the confirmed prototype direction is a **dual-wielding warrior**. This early concept may inform pixel density, palette exploration, and general silhouette only; its exact design is not approved production art. See the [current character specification](../spec.md#4-角色与职业) and the [animation sample brief](warrior-animation-sample-brief.md).

- Concept image: `warrior-pixel-concept-v1.png`
- Original concept direction: Chinese-fantasy agile strength fighter, dual-wielding two large swords. The dual-wield presentation now agrees with the prototype direction, but the archived image is still only a style exploration, not a locked character design.
- In-game visual target: crisp, chunky pixel clusters at approximately the same on-screen clarity as the Codex pixel pet reference.
- Intended use: visual reference and art-direction discussion only. This generated preview is not a production-ready sprite or animation sheet.
- Production follow-up: decide the native sprite grid, side-view proportions, palette, and frame dimensions; then clean and redraw the character as a consistent pixel sprite set for idle, movement, attacks, hit reactions, and skills.

The screenshot reference informed only the pixel density and clarity target. The warrior design is original and does not reproduce the pet's identity or costume.
