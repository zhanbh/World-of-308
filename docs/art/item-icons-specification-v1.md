## 1. 资产概述与规格基准

在角色个人信息（C键）、背包换装（B键）、铁匠修理/强化、杂货商人、银行金库及战斗快捷栏中，所有装备与道具必须采用**高品质 2D 点阵像素风图标（Pixel Art Icons）**呈现，严禁使用纯文字缩写。

- **母版分辨率**：**256 × 256 px**（高精原始设计母版，用于图鉴画册与高分辨率展示）；
- **运行时多规格独立导出（严禁运行时非整数缩放）**：
  - **标准槽位图集**：**48 × 48 px**（离线独立导出，适配 56×56 背包/金库标准格子，预留 4px 内边距）；
  - **详情与检视大图**：**64 × 64 px**（离线独立导出，用于装备详情弹出大卡片、结算大图）；
  - **纸娃娃紧凑槽位**：**34 × 34 px**（离线独立导出）；
  - **采样模式**：严格采用最近邻点阵采样（Nearest-Neighbor / Point Sampling，保留清晰像素边缘与网格对齐，禁用双三次模糊平滑，`image-rendering: pixelated`）；严禁在运行时用 64×64 按 0.75× 强行非整数倍缩放，避免点阵线条粗细不均；
- **透明底纯净切片原则 (Transparent Subject Decoupling)**：所有图标切片必须为**纯透明背景 PNG (Alpha=0)**，仅包含物品主体（武器刀刃、铠甲、宝石、药水瓶），**严禁在图标文件内固化暗岩底衬或品质外框**；底衬（`Layer 0`）与品质外框（`Layer 2`）统一由 UI 槽位组件分层渲染，彻底消除一格双底板、双边框的重复渲染与视觉冲突，并使同一图标可在背包、详情大卡片、纸娃娃、通关奖励中通用；
- **整合图集母版**：[item-icons-sheet-v1.png](item-icons-sheet-v1.png)（1024 × 1024，4×4 网格）。

以下尺寸与命名为候选目标，尚非现有资源齐备的声明。现有目录含原图及部分 `_64` 文件；48、34 版本、透明主体与品质框拆分须逐项核查并离线导出，检查透明边缘及轮廓，必要时人工修整。离线非整数缩小也可能造成点阵不均；保留原稿及各尺寸审阅结果，小样通过后再批量制作。

## 3. UI 格子与角标装配规范

### 3.1 格子层叠渲染架构 (Z-Index Hierarchy)
1. **Layer 0 (底衬层)**：暗岩色网格背景 `#10181e`（由 UI 组件通过 `panel_well_inner` 9-Patch 切片统一渲染，图标素材自身不含底衬）；
2. **Layer 1 (图标层)**：居中放置 48×48px（56×56 背包/金库标准格子）或 34×34px（纸娃娃紧凑槽位）的**纯透明底**点阵 PNG 图标；
3. **Layer 2 (品质外框层)**：由 UI 组件按装备品质动态挂载 2px 边框与内发光 Sprite（粗糙白灰、优秀草绿、精良蔚蓝、稀有暗紫、传说金橙、史诗炽红；图标素材自身不带边框）；
4. **Layer 3 (强化角标层)**：右上角或右下角浮动强化等级（如黄色 `+10`，+10以上带粉色呼吸光芒）；
5. **Layer 4 (耐久指示条)**：槽位底边 3px 纯三色进度条（绿 $>50\%$、黄 $\le50\%$、红 $=0$ 失效）；
6. **Layer 5 (堆叠数量徽标)**：右下角常驻黑色半透明底衬数量标牌（如 `x5`、`x20`，单堆上限严格遵守系统规约 `MAX_STACK = 20`，不可堆叠物品不显示）。
