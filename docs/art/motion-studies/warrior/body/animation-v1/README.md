2026-10-16，用户要求直接接入后统一验收。内置imagegen根据原创战士概念与现有十字斩图集生成9个姿势；模式及完整提示词见[prompt.md](prompt.md)，原始RGBA见[generated-source.png](generated-source.png)。运行图集为client/assets/resources/warrior-body-v1.png，1248×1248、3×3、416单元，脚底纵向锚点352。打包脚本client/tools/pack-body-atlas.py仅做统一最近邻缩放与位置对齐，不绘制/修色；上挑源图刀尖跨原网格16像素，因此扩展取样并在显示时排除相邻脚部残片。

| 索引 | 姿势 | 使用 |
| --- | --- | --- |

| 4 | 急停 | 松开移动后100ms，无额外惯性位移 |
| 5–6 | 后仰受击与恢复 | 原有240ms受击状态前后各一姿势，优先于攻击/移动 |
| 7 | 双脚屈膝落地吸震 | 崩山580–680ms，命中三段与技能总时长不变 |
| 8 | 浅蹲上挑准备 | 替换普攻B2，原24帧图集与780ms循环保留 |

新图集基于前4帧中位身体高度统一缩放到约194图集像素。固定原单元水平中心，避免按每帧落地脚重新定中心导致左右抽动；统一脚底纵向基线。待机使用原普攻守势；既有技能图集角色高度偏小，显示统一放大1.24倍以接近约194像素的普攻/新身体动作标尺，不改变地面移动/碰撞范围。

独立/skills评审页加入步行、跑动、停步、受击按钮；普攻页B2可通过修正开关比较旧新帧。实际游戏复用同一姿势选择和身体状态模型。图集未加载时退回既有像素守势，受击期间不通过压缩整个人物来伪造受挫；新姿势优先显示，再继续原有保护闪烁。
