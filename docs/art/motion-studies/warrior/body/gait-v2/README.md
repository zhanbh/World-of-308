# 双腿交替步态 v2

2026-10-16。用户指出旧跑步“一直一只腿在前，后腿假动”。旧身体v1的四帧虽循环播放，但腿部姿势没有明确交换前伸/后蹬分工；纯播放时序测试无法发现该美术问题。本轮仅替换移动步态，保留v1急停、受击、落地与上挑准备。

使用内置 imagegen，以原创身体v1为身份参考。第一次生成仍重复同一前导腿，未用于运行。第二次明确区分亮甲近侧腿、暗侧远腿并露出膝部。最终源为 generated-source.png，完整两轮提示词见 [prompts.md](prompts.md)。没有从录像提取角色素材。

运行资源 client/assets/resources/warrior-gait-v2.png：1664×832，4列2行，416单元，脚底锚点(208,352)。8个时序槽、7个独立姿势。源第4格仍回到了错误前导腿，打包不使用它；运行第4/5槽复用源第5格的远腿落地接触姿势。不声称八张都独立。

| 槽位（1基） | 腿部运动 |
| --- | --- |
| 1 | 近腿前伸接触，远腿在后 |
| 2 | 近腿支撑，远腿开始回摆 |
| 3 | 近腿后蹬，远膝在前 |
| 4–5 | 远腿前伸落地，近腿在后，接触停留 |
| 6 | 远腿支撑，近膝向前回摆 |
| 7 | 远腿后蹬，近膝在前 |
| 8 | 近腿前伸，接回槽1 |

两次接触的前后腿分工相反，是本轮视觉复核关键，不以槽数测试代替解剖判断。

打包脚本 client/tools/pack-gait-atlas.py 仅进行最近邻统一缩放、平移、选帧与打包，不绘制新动作。生成源1774×887按比例边界取整分格，每行以该半周期接触姿势确定统一地面；不逐帧将抬起的脚贴回地面。参数见 packing.json。

跑步400ms循环，每槽50ms；步行0.65倍步频约615ms。地面速度不变。新步态独立于身体姿势，停步、受击、死亡、攻击和技能均清除移动帧，保持既有优先级。左右为整体镜像。
