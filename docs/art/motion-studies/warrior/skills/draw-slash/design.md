# 拔刀斩分镜 v1

状态：设计初稿，未实现。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。基础形态是本稿目标；不加入拔刀奥义、冲击之刃或武器追加击。

定位：原地收身后的一次迅速前方宽斩。身体旋转幅度大，刀光宽，准备与出刀速度形成反差；不按匀速绘制大圆圈。

| 时间（ms） | 姿势/事件 |
| ---: | --- |
| 0 | 肩腰反向扭紧，主刀收至侧腰后方，副刀贴近身体守住，锁定面向 |
| 140 | 屈膝/压身达到准备姿势，主刀保持收势，衣摆有压紧方向 |
| 340 | 短暂留势末端，身体仍收紧；首轮点按即施放，不加入长按蓄力操作 |
| 400 | 主手爆发横斩，脚底支撑、腰肩带动；副刀略滞后随身体扫回 |
| 440 | 前方宽弧扫过，触发唯一伤害事件 |
| 480 | 横斩结束，手臂与双刀保留末势；亮弧开始快速消退 |
| 600 | 身体留势回收，不能刀光刚消失就直接闪回待机 |
| 660 | 可移动/接动作 |
| 760 | 身体回正结束 |

不安排地面突进。近身刀光按地面透视形成扁椭圆，但默认伤害仍为当前原型的前方区域；背后最多保留贴身回刀短尾，不能画完整可攻击 360 度大环而逻辑只打前方。若后续选择周身判定，应同步改范围与刀光，不仅扩大特效。

主刀承担宽斩轮廓，副刀在身体附近稍后收回，避免两把长刀同时拉满成为重复条带；不强求实体入鞘。分轨：收身/转体、主刀宽弧、副刀短尾、短命中闪光。至少覆盖站姿、收腰、最低重心、准备末势、出刀启动、横斩峰值、横斩末位、留势回收、守势九个关键点。伤害在快斩阶段，不随消散刀光再次结算。
