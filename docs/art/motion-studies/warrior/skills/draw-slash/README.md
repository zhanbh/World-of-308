## 基础拔刀：姿势与节奏

精查画面中角色面向右侧。

| 媒体时间（约） | 画面观察 |
| --- | --- |
| 4.00–4.35 秒 | 站立持剑的准备状态，尚未进入该次明显起势 |
| 4.40–4.80 秒 | 身体压低并收紧姿势，剑横收于身侧，出现短暂白/黄色身体高亮；有可辨认的准备停顿 |
| 4.85–4.95 秒 | 肩腰迅速转动，一次大幅横向挥斩；亮弧绕人物扫过，透视呈扁椭圆，出刀明显快于准备和收势 |
| 5.00–5.25 秒 | 剑停在挥斩结束位置，身体逐步回正，刀光已经消退；不是刀光一消失就立刻恢复待机 |
| 5.30 秒附近以后 | 恢复常态持剑姿势 |

该次媒体画面呈现的主要节拍是“收势停顿 → 极快横斩 → 留住收招姿势 → 回正”。刀光在约 0.1 秒的采样范围内扫过，不代表原作技能有效帧已精确测出。角色没有伴随长距离冲刺；主表现来自原地压身、肩腰转动和宽幅刀路。

刀光能看见绕人物展开的部分，视频字幕也将基础动作描述为向周围横斩。**画面不能证明完整 360 度伤害判定。**本游戏此前写的是前方面积较宽的横斩；是否增加身后判定尚未决定，不能仅凭刀光覆盖范围自动修改逻辑。

25.30–26.80 秒的“拔刀奥义”仍保留收身、迅速横扫、停留收势的姿势骨架，但可见刀光更宽。36.00–37.50 秒则是“冲击之刃”段中一次横斩样本，不足以代表该分支全部条件；其后还有其他蓄力/后续打击演示。用户目前仅要求观看，未选择采用任何进化分支。

## 本游戏制作时应保留的表达

1. 准备与出刀形成明显速度反差，准备阶段的收剑、压身可读，出刀不能像匀速扇形转圈。
2. 身体与武器一起转动，脚底地面锚点稳定；不能让角色站直不动、只播放一个大圆环。
3. 刀光随刀路快速扫过、随后消退，角色保留短暂收势。当前“不发射持续扩散圆弧”的规则不因视频的大弧光自动改变。
4. 双刀如何完成这一横斩需要原创姿势适配；视频单剑角色的持握动作不等于我们已有双刀素材可直接复用。
5. 前后方判定、是否追加第二击、范围、蓄力、技能资源与伤害事件单独设计，不从视频字幕和伤害数字直接移植。
