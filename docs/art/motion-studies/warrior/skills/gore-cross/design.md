# 十字斩分镜 v1

状态：设计初稿，未实现。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。时间为调试提案。

定位：短准备、先横后竖的近身技能。与普攻的交错刀路区分，不把两道斜线同时闪出当作完成动作。

| 时间（ms） | 姿势/事件 |
| ---: | --- |
| 0 | 站稳、收肩，主手横收侧腰，副手预抬，锁定面向 |
| 120 | 主手开始横斩，肩腰转向目标，副手保持竖斩准备 |
| 170 | 横斩完成，胸腰前方留下短横痕；此时不单独结算伤害 |
| 240 | 副手从上向前下挥落，主刀留在横斩末位让出刀路 |
| 290 | 竖痕与横痕组成十字，触发唯一伤害事件 |
| 340 | 角色回收，十字留痕向面前短距推进并淡出，始终不超出实际近身范围造成远程误导 |
| 460 | 可移动/接其他动作，未取消则继续回正 |
| 560 | 身体动作结束；留痕最迟约 620 ms 清理 |

初稿把视频中前移十字适配为近身范围内的短留痕，建议推进上限 12 个原型地面单位，效果不携带碰撞或二次伤害。主手横、副手竖是原创双刀适配提案，须先看轮廓是否清楚。两道痕采用同一视觉语言，按先后出现；颜色与亮度待手机评审。

分轨：身体/双刀、横向短刀光、竖向短刀光、十字留痕。首轮至少覆盖收肩、横斩中、横斩末、竖斩前、竖斩中、十字峰值、回收、守势八个姿势关键点。特效不能遮住两次出刀的顺序。
