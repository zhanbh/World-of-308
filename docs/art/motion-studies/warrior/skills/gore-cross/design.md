# 十字斩分镜 v1

> 2026-10-16 新规则：两段伤害（近身出招＋发射十字），每段短僵直/小后退并刷新流血。下面旧动作时间沿用作参考，新发射物与多段判定待接入；以[命中反馈v2](../../skill-hit-feedback.md)为准。

状态：设计初稿；连续帧粗动画v1已接入，尚未真机验收。实现与未完成项见[四技能归档](../ANIMATION-V1.md)。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。时间为调试提案。

定位：先横后竖完成近身出招，再发射十字。近身段一次、发射段一次，共两段伤害；横/竖挥刀不额外各算一段。

| 时间（ms） | 姿势/事件 |
| ---: | --- |
| 0 | 站稳、收肩，主手横收侧腰，副手预抬，锁定面向 |
| 120 | 主手开始横斩，肩腰转向目标，副手保持竖斩准备 |
| 170 | 横斩完成，胸腰前方留下短横痕；此时不单独结算伤害 |
| 240 | 副手从上向前下挥落，主刀留在横斩末位让出刀路 |
| 290 | 竖痕与横痕组成十字，近身第1段伤害；命中短僵直和小后退 |
| 340 | 角色回收并发射十字；发射段碰到目标时结算第2段，每目标此段最多一次 |
| 460 | 可移动/接其他动作，未取消则继续回正 |
| 560 | 身体动作结束；发射十字按独立寿命继续，不绑定角色收招直接清空 |

旧版“12单位短留痕、不携带碰撞或二次伤害”已被用户新规则覆盖。新版十字为有碰撞伤害的发射物，距离、速度、穿透/阻挡和寿命待制作时确定，不能继续仅画留痕。两段可击中同一目标，各自短僵直、小后退并刷新5秒流血。主手横、副手竖的角色姿势可沿用，先后顺序保持清楚。

分轨：身体/双刀、横向短刀光、竖向短刀光、十字留痕。首轮至少覆盖收肩、横斩中、横斩末、竖斩前、竖斩中、十字峰值、回收、守势八个姿势关键点。特效不能遮住两次出刀的顺序。
