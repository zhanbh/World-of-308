## 来源与记录方式

用户指定当前浏览器视频[《鬼剑士崩山击、十字斩、三段斩制作。》](https://www.bilibili.com/video/BV1Ke411v7GE/)，作者叶匿花翎，页面日期 2024-01-09。这是作者自制战斗演示，不能当成官方原作帧表。

已检查整段战斗的分时画面，并在视频 **101.30–102.50 秒（1:41.30–1:42.50）**以 50 ms 间隔定位、暂停并截取画面。截图是视频时间采样，不是逐个源帧提取。Chrome 原页面可见 0.5x 播放设置，但以下数字均为视频媒体时间，不能直接作为游戏技能实际耗时。

## 画面观察

角色在选定片段面向左侧；不能把画面左向写成技能只能向左。

| 视频位置 | 可见内容 |
| --- | --- |
| 101.30 秒附近 | 角色站在目标右侧，武器进入出刀准备；角色部分被掉落物标签遮挡 |
| 101.35–101.55 秒附近 | 横向扫过的亮色刀光先出现，同时留下红色横向斩痕；可见身体扭转 |
| 101.60–101.75 秒附近 | 第二道竖向刀光出现，与先前横痕构成十字；不是同一帧同时亮出两条斜线 |
| 101.80–102.15 秒附近 | 红色十字斩痕继续在角色面前向左推进，角色动作逐渐回收；角色和残留效果的持续时间不同 |
| 102.20–102.50 秒附近 | 十字效果消退，角色恢复后续动作；后续普攻/其他输入混入，不能据此锁定完整后摇 |

另一处视频约 4:03 可见类似红色十字，用于形态交叉核对；详细拆解以上述选段为准。

## 与本游戏设计的区别

当前原型将十字斩描述为“双刀快速交叉近身斩”。本视频能确认的是**先横后竖的两个动作与独立十字斩痕**，并能看到斩痕向前推进。是否采用推进效果、推进距离、双刀分别如何完成横竖两刀，尚未由此次观察自动定稿。

制作动作时应分别记录横斩、竖斩、身体转动和收势；十字效果与角色动作分轨。不能仅给静止角色叠一张十字图片来代表已还原。

画面存在多个目标、伤害字和其他连招。不能从数字数量反推该技能应结算几次伤害，也不能确定每刀的实际判定范围、冷却、魔法消耗或硬直时长。颜色与原作素材不是本游戏已确认的资源方案。
