# 崩山击分镜 v1

状态：设计初稿，未实现。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。时间和位移均为调试提案。

定位：短距离主动接近与局部落击；以短跃、小落点、紧凑收招区分大崩。

| 时间（ms） | 姿势/事件 |
| ---: | --- |
| 0 | 屈膝压身，双刀聚拢并准备上举，锁定面向 |
| 120 | 起跳，地面位置开始有限前移；身体高度独立变化 |
| 340 | 接近最高点，双刀高举，膝盖收起，保留前倾趋势 |
| 480 | 开始明显下挥，两刀聚成清楚落击方向，地面不提前爆开 |
| 580 | 高度回零，低姿势落地，刀路落到身前地面；唯一伤害事件与冲击效果同时触发 |
| 680 | 保持低位承重，局部石屑/尘环向外短促展开 |
| 780 | 回正到可移动/可接动作状态 |
| 880 | 身体动作结束；局部效果最迟约 1000 ms 消退 |

初稿地面前移沿用现有 34 单位调试预算，发生在 120–580 ms，夹到房间边界，不穿过墙/障碍；最高视觉抬升暂用 25 单位。落地后效果中心固定在实际落点，不能继续追着人物移动。阴影始终留在地面，Y 排序按地面纵深。

不加主动跳跃按钮、无敌、霸体或空中免伤。落地前受击取消未触发的冲击；落地后不重复结算。分轨：起落身体、短下劈弧、局部冲击/石屑、阴影。关键姿势至少为压身、离地、高举、下挥、落地低姿势、承重、起身、守势。
