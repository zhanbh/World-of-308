# 崩山击分镜 v1

> 2026-10-16 新规则：三段伤害，起跳接触→下劈→接近释放完毕的终段；只有终段自带特殊击倒，前两段仍适用通用倒地伤害阈值。多段判定待接入，以[命中反馈v2](../../skill-hit-feedback.md)及[通用受击规则](../../../../../combat-hit-rules.md)为准。下面分段时间为制作建议，未作为用户逐项确认参数。

状态：设计初稿；连续帧粗动画v1已接入，尚未真机验收。实现与未完成项见[四技能归档](../ANIMATION-V1.md)。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。时间和位移均为调试提案。

定位：短距离主动接近与局部落击；以短跃、小落点、紧凑收招区分大崩。

| 时间（ms） | 姿势/事件 |
| ---: | --- |
| 0 | 屈膝压身，双刀聚拢并准备上举，锁定面向 |
| 120 | 起跳，地面位置开始有限前移；打开首次接触的第1段窗口，实际碰到范围内目标才命中 |
| 340 | 接近最高点，双刀高举，膝盖收起，保留前倾趋势 |
| 480 | 开始明显下挥，对应第2段，不自带特殊击倒；普通伤害仍按通用阈值处理 |
| 580 | 高度回零、低姿势落地，刀路落到身前地面；不把整招伤害都压成此刻一次结算 |
| 680 | 接近释放完毕，低位承重与局部冲击对应第3段，命中目标此时才击倒 |
| 780 | 回正到可移动/可接动作状态 |
| 880 | 身体动作结束；局部效果最迟约 1000 ms 消退 |

初稿地面前移沿用现有 34 单位调试预算，发生在 120–580 ms，夹到房间边界，不穿过墙/障碍；最高视觉抬升暂用 25 单位。落地后效果中心固定在实际落点，不能继续追着人物移动。阴影始终留在地面，Y 排序按地面纵深。

不加主动跳跃按钮、无敌、霸体或空中免伤。每个段对同一目标最多结算一次，但后续段可合法再次命中。前两段不自带特殊击倒，终段特殊击倒；所有段仍适用通用阈值与死亡优先规则。每段有效命中刷新5秒流血。受击取消尚未触发的角色段，不补发漏掉的命中。分轨：起落身体、短下劈弧、局部冲击/石屑、阴影；让接触、下劈和终段各有连续可见反馈。
