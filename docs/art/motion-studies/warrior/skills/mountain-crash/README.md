# 崩山击动作观察

更新：2026-10-16。用途：战士技能 2；与技能 4 崩山裂地斩（大招）分开记录。返回[动作索引](../../../README.md)。

## 来源与记录方式

用户指定当前浏览器视频[《鬼剑士崩山击、十字斩、三段斩制作。》](https://www.bilibili.com/video/BV1Ke411v7GE/)，作者叶匿花翎，页面日期 2024-01-09。它是作者自制战斗演示，不是官方动作规格。

已检查整段战斗的分时画面，重点选取 **52.20–53.40 秒（0:52.20–0:53.40）**，以 50 ms 间隔定位、暂停并截图；18.50–20.40 秒另以 100 ms 抽样对照了相似的跃起、下挥与地面效果。媒体时间抽样不是逐个源帧测量，也不知道录制时的角色攻速和作者实现参数。

本地分时对照：[sequence.local.png](sequence.local.png)。文件由上层 `.gitignore` 排除，不进入 Git 或运行时图集。

## 画面观察

本次精查片段角色面向左侧。要把角色的空中身体位置、地面阴影位置和镜头移动分开看，不能直接用截图坐标差当作技能前进距离。

| 视频位置 | 可见内容 |
| --- | --- |
| 52.20–52.45 秒附近 | 身体离开地面，屈腿进入短跃起，武器准备向前下方落击；地面阴影与身体分离 |
| 52.50–52.55 秒附近 | 抬臂/举刀，前上方出现橙色刀光起端，形成下劈准备 |
| 52.60–52.85 秒附近 | 剑与亮色弧线向身前地面挥落，身体随之下降并前倾，形成低姿势收势 |
| 52.90–53.20 秒附近 | 身前地面出现独立的橙黄色竖向爆点/冲击效果，角色保持落击后的姿势；它与挥刀弧线不是同一层效果 |
| 53.25–53.40 秒附近 | 地面效果仍在，角色开始回正；完整恢复到自由移动的时点没有由该短片段确定 |

可辨认的动作骨架是“跃起 → 举刀/下挥 → 落击低姿势 → 地面冲击 → 回正”。录像中的前向趋势可见，但镜头跟随和其他输入影响位移，不能据此给出精确距离。

## 接入时保持的边界

- 本游戏已有的崩山击方向为跃起下砸、有限前移与落地范围反馈。视频支持对照这一动作形态，但并未证明我们的判定与表现已经一致。
- 身体高度只用于空中表现，地面锚点供移动、碰撞与 Y 排序使用。跃起不自动赋予无敌；本游戏此前已确认崩山击不提供无敌。
- 下挥刀光和落地冲击应分别控制时机，不能起跳时就提前播放完整地面爆点。
- 视频还含普通跳跃、其他空中/落地动作和三段斩。不能把所有离地动作都归为崩山击，也不能因为该视频包含三段斩就新增职业技能。
- 不能由命中数字、怪物倒地或特效持续时间直接确定伤害次数、范围、浮空、无敌或冷却；本游戏按落地结算的规则与视觉对应仍需实际验收。
