# 崩山裂地斩分镜 v1

> 2026-10-16 新规则：拍地1段＋地面炸开3段，共4段。拍地即击倒范围内目标，全部特效结束后才起身。多段伤害待接入，以[命中反馈v2](../../skill-hit-feedback.md)为准；下表爆发时点为沿用现有视觉节奏的制作建议。

状态：设计初稿；连续帧粗动画v1已接入，尚未真机验收。实现与未完成项见[四技能归档](../ANIMATION-V1.md)。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。参考的是姿势与先后关系，不照搬厄运九的规模或命中次数。

定位：最长的准备与最明显的空中高举，大范围落刀后出现延迟喷发。小崩是短促落击，大崩要能读出“重落—地裂蓄积—喷发”三层节奏。

| 时间（ms） | 角色与世界事件 |
| ---: | --- |
| 0 | 双腿压身、重心降低，双刀收拢，锁定面向 |
| 280 | 起跳，身体与双刀向上拉开，地面锚点不跟随视觉高度改变 |
| 620 | 到达高位，双刀上举；高度暂用 52 个原型单位，小崩暂用 25，比例可调 |
| 720 | 短暂顶点留势后开始下落，下挥方向清楚 |
| 880 | 高度归零、低姿势重落，拍地第1段伤害，击倒范围内所有命中目标；冻结地裂落点/朝向 |
| 1000 | 保留落刀承重姿势，裂纹红光增强，尚未播放完整喷发 |
| 1180 | 身体开始起身，地裂仍独立存在 |
| 1280 | 裂纹区开始竖向喷发，对应总第2段伤害 |
| 1320 | 角色可移动/接动作，身体占用结束；效果留在原落点 |
| 1500 | 喷发达到峰值，对应总第3段伤害，保留预警与怪物轮廓可读性 |
| 1720 | 炸开过程的第3次爆发，对应总第4段伤害；之后继续消退 |
| 2000 | 高耸喷发结束，保留低亮裂纹与薄烟 |
| 2400 | 残留清理完成，首段被击倒的存活目标此后才开始起身 |

地裂到喷发初值为 400 ms，不直接照用视频约一秒间隔；这是保持手机节奏的设计提案，需要并排复评。角色落地后可回正，不必等待全部残留结束。总效果寿命 2400 ms，角色动作占用 1320 ms，分别管理。

不增加常规地面突进；地裂范围沿用原型调试范围作对照，不能凭喷发高度扩大Y方向碰撞。拍地与后3段爆发分别按实际范围结算，每段每目标最多一次；后3段可继续伤害倒地目标。每段有效命中刷新流血，但不把同一次大崩的倒地等待从该段起重新加满1.52秒，起身仍绑定本次全部特效结束。

分轨：身体/双刀、落刀短轨迹、翻起地面/裂纹、延迟喷发、碎屑、烟尘、阴影。至少覆盖压身、起跳、高举、顶点、下落、落刀、低势承重、起身、守势九个关键姿势。喷发峰值不可完全盖住玩家、怪物轮廓和地面危险提示。

打断与清理：落地前受击不生成地裂/喷发；落地后角色受击不撤回已结算伤害。新地面实例包含后3段伤害，必须有独立生命周期与段去重；其受击/取消策略在接入时与原型规则对齐。角色死亡、房间重置、离场时全部清理，喷发实例不得跨房间补伤害。
