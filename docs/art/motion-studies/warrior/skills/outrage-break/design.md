# 崩山裂地斩分镜 v1

状态：设计初稿，未实现。共通规则见[战士动作设计](../../DESIGN.md)，事实来源见[观察](README.md)。参考的是姿势与先后关系，不照搬厄运九的规模或命中次数。

定位：最长的准备与最明显的空中高举，大范围落刀后出现延迟喷发。小崩是短促落击，大崩要能读出“重落—地裂蓄积—喷发”三层节奏。

| 时间（ms） | 角色与世界事件 |
| ---: | --- |
| 0 | 双腿压身、重心降低，双刀收拢，锁定面向 |
| 280 | 起跳，身体与双刀向上拉开，地面锚点不跟随视觉高度改变 |
| 620 | 到达高位，双刀上举；高度暂用 52 个原型单位，小崩暂用 25，比例可调 |
| 720 | 短暂顶点留势后开始下落，下挥方向清楚 |
| 880 | 高度归零、低姿势重落，触发唯一伤害事件；生成地裂效果实例并冻结其落点/朝向 |
| 1000 | 保留落刀承重姿势，裂纹红光增强，尚未播放完整喷发 |
| 1180 | 身体开始起身，地裂仍独立存在 |
| 1280 | 裂纹区开始竖向喷发；首轮仅视觉，不能再次扣血 |
| 1320 | 角色可移动/接动作，身体占用结束；效果留在原落点 |
| 1500–1720 | 喷发达到峰值再减弱，石屑/火花向外散，控制透明度保留危险预警可读性 |
| 2000 | 高耸喷发结束，保留低亮裂纹与薄烟 |
| 2400 | 残留清理完成 |

地裂到喷发初值为 400 ms，不直接照用视频约一秒间隔；这是保持手机节奏的设计提案，需要并排复评。角色落地后可回正，不必等待全部残留结束。总效果寿命 2400 ms，角色动作占用 1320 ms，分别管理。

第一版不增加常规地面突进；地裂范围沿用原型大崩调试范围作对照，在实际地面坐标绘制透视轮廓。不能凭喷发的屏幕高度扩大 Y 方向碰撞。伤害只在落地时按实际范围结算一次；视觉不表现尚未命中的远处怪物被无故炸飞。

分轨：身体/双刀、落刀短轨迹、翻起地面/裂纹、延迟喷发、碎屑、烟尘、阴影。至少覆盖压身、起跳、高举、顶点、下落、落刀、低势承重、起身、守势九个关键姿势。喷发峰值不可完全盖住玩家、怪物轮廓和地面危险提示。

打断与清理：落地前受击不生成地裂/喷发；落地后角色受击不撤回已结算伤害，无伤害效果可按既有寿命消退。角色死亡、房间重置、离场时全部清理。喷发实例不得在下一房间补触发。
