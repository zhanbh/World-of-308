# 崩山裂地斩（大崩）动作观察

更新：2026-10-16。用途：战士技能 4、大招。与技能 2 [崩山击](../mountain-crash/README.md)分开记录。返回[动作索引](../../../README.md)。

## 来源与采样

用户指定 Chrome 当前视频[《当年厄运九的大崩到底有多强呢？》](https://www.bilibili.com/video/BV1DakNYyEGb/)，要求从约 19 秒观察。页面日期 2024-12-19，作者显示为“乌拉乌拉乌拉i_”，全长约 57 秒。它是玩家的历史装备场景演示，不是普通装备下的官方动画/数值规格。

19 秒附近已经处于落刀后的地裂阶段，因此往前补看起跳：18–24 秒以 250 ms 间隔观察整体；17.80–21.40 秒以 100 ms 间隔定位、暂停并截图。每次采样检查来源 BV 地址，保持暂停，未跟随推荐或自动连播。

本地观察图：[动作分时对照](sequence.local.png)、[爆发与残留全景](effects-overview.local.png)。两图均由上层 `.gitignore` 排除，不提交 Git、不加入游戏资源。当前取得的视频为 640×360，且游戏画面本身带黑边、遮挡与压缩；这是媒体时间抽样，不是逐个原作动画帧测量。

## 动作与特效顺序

以下时间是视频媒体时间的近似定位，不能直接当成游戏技能的最终时长。红色角色光效、怪物和前景树枝影响了手臂、刀尖的辨认，因此只记录能看清的阶段，不编造精确持刀轨迹。

| 视频位置（约） | 可见内容 |
| --- | --- |
| 17.80–18.20 秒 | 出招前的地面状态，周边敌人及其他攻击效果仍在，不能把所有闪光归为大崩 |
| 18.30–18.70 秒 | 角色明显离地上升，随后能看到高举武器的空中姿势；起跳完整前摇的精确起点未测定 |
| 18.80–19.10 秒 | 角色下落并进入很低的落击姿势，身前地面瞬间震裂，出现大块翻起/破开的石面和红色裂隙 |
| 19.10–19.80 秒 | 地裂保持，角色处于落击后的低姿势；裂隙逐步带出更明显红光，并非一落地就已经完成全部喷发 |
| 19.90–20.80 秒 | 较大面积的红色竖向喷发与火花/碎屑效果出现，遮住大量角色与目标画面；这是落击之后的另一视觉阶段 |
| 20.90–21.40 秒 | 高耸喷发逐渐消退，角色回正/转入后续动作，地面仍保留发红裂纹与烟尘 |
| 约 21.50–24 秒 | 地面残留还在，角色已经能在场上行动；残留视觉不等于角色仍被完整动作锁住 |

主要观察结论：**跃起举刀 → 向地面重击 → 地裂停留/蓄积 → 延迟大范围喷发 → 残留消退**。从样本的约 18.8 秒地裂到约 19.9 秒喷发出现，影像上存在约一秒的先后间隔；这只用于说明本段录像的时序，不能成为本游戏固定延迟。

## 与普通崩山击的区分

- 普通崩山击记录的是短跃起、下挥与较局部的落地冲击。
- 本段大崩的识别点是更强的空中举刀/落击、大片地裂，以及落击后另起的高耸喷发；不能只把小崩的圆形冲击放大就宣称动作一致。
- 地面破裂与后续喷发应分别编排；身体动作、武器、地面裂纹、喷发和残留分轨，角色回正不应必须等待所有残留完全消失。

## 本游戏仍待确定的映射

当前已确认的大招方向是明显起势、跃起、大范围落地重击，原型以落地作为主要命中时刻。此次视频进一步提供“落地后延迟喷发”的参考，**尚未决定本游戏是否让喷发另结算伤害**，不能把两个视觉阶段直接推成两个或更多伤害事件。

视频标题明确是“厄运九”装备场景，画面中还有多目标和其他效果。喷发范围、高度、密度、持续时间、冷却、伤害数字、命中次数和控制效果都不能当成普通大招配置照搬。也不能由角色跃起、红色高亮或画面特效断言该技能无敌。

若按该参考制作，先确认空中举刀、落刀低姿势与地裂到喷发的节奏；双刀适配、具体帧时长、范围、位移、判定和收招取消规则仍需原型专项验证。
