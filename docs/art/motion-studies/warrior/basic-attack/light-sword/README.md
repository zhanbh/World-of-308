# 光剑里鬼普攻动作观察

日期：2026-10-16。状态：已观看并抽样对照，动作目标已选定；尚未替换游戏动画。

归档用途：仅对应普攻循环。返回[战士动作索引](../../../README.md)。本目录的 [慢放对照](slow-contact.local.png)与[连续出招对照](normal-contact.local.png)为本地资料，已由上层 `.gitignore` 排除，不随 Git 提交，也不加入游戏资源。

用户在 Chrome 打开 [DNF剑魂里鬼逐帧慢放](https://www.bilibili.com/video/BV1DW411L747/)，并明确选择开头的光剑里鬼，要求以它作为普攻循环的还原目标。当前参考优先于此前混合狂战士双刀、四段交叉展开的视觉方向。角色仍使用本项目原创外观。

## 观察方法与证据边界

- 在用户打开的 Chrome 页面播放、暂停、定位光剑段；随后在 ego-browser 打开同一视频，关闭登录提示与弹幕，暂停后通过视频元素定位时间并截取播放器画面。
- 慢放段：视频 11–25 秒，逐秒抽样；前段连续出招：8.50–10.70 秒，每 50 ms 抽样。前段 0–10 秒另以 250 ms 抽样检查上下文。
- 当前浏览器取得的视频画面为 640×360。50 ms 抽样不是逐个源帧提取；压缩、作者剪辑和录制角色攻速都会影响推断，不能称为原作动画帧表。
- 页面弹幕与评论不作为刀路、左右手、段数或数值的事实依据。以下记录依据实际画面；遮挡下的精确手臂轨迹仍需进一步核对。
- 截图仅保留在本地研究产物中，没有加入游戏资源目录或提交原作图集。

## 能辨认的姿势顺序

左右方向按视频角色面向右侧描述。阶段边界为视觉分组初估，不代表已测得原作输入或伤害事件。

| 视觉分组 | 可见动作 | 对照位置（视频时间） |
| --- | --- | --- |
| 第一组 | 两把剑在胸腰与肩部的不同高度交错，形成横向与斜向结合的刀路；不是两把剑同时以同角度摆动 | 慢放约 12–14 秒；前段约 8.75–8.85 秒 |
| 第二组 | 上身转动，双臂向上交错，刀光在身体前方形成较窄弧线，随后进入双手高举的姿势 | 慢放约 14–18 秒；前段约 8.85–9.05 秒 |
| 第三组 | 从高举姿势向前下方挥落，上身明显俯下、双腿屈曲，较长剑收到身前低处，另一把剑留在身后高处；前方刀光先出现再消退 | 慢放约 19–25 秒；前段约 9.10–9.40 秒 |
| 接回首组 | 低姿势结束后接回下一轮；抽样中可见短暂接近站姿的过渡，不能把该过渡与长时间待机混同 | 前段约 9.45–9.50 秒、10.15–10.20 秒 |

录像前段可见首组姿势约在 8.75、9.50、10.20 秒重复，因此完整循环的影像节奏初估约 0.7–0.8 秒。这只是这段录像条件下的参考，未扣除输入间隔，也不知道装备、增益和录制速度，不能写成游戏固定攻速。慢放段的秒数仅用于定位姿势，不能直接转为游戏动作时长。

## 与当前原型的差距

- `CombatModel.ts` 当前固定四阶段，调试时长为 0.32、0.32、0.40、0.76 秒，整轮约 1.80 秒；这是既有实现，不是此次参考的动作节奏。
- `WarriorSpriteSheetView.ts` 的 `showAttack(progress)` 不接收连段阶段，四段实际上重复播放同一组六帧。只改时长或刀光不能得到上述三个不同的身体姿势组。
- 旧第四段“交叉后反向展开、慢收回”与此次选定参考末段的“高举挥落、低重心收势”不同，不能继续作为还原目标。
- 当前素材没有对应的独立扭身、高举、俯身和低位收势帧，也没有可靠的逐帧脚底、双手、刀尖轨迹记录。

## 接入要求

1. 以三个视觉动作组制作各自的原创关键姿势与过渡帧，先对齐身体轮廓、重心、双手和双刀轨迹；统一脚底地面锚点。末段的上身前倾不应误变成地面碰撞点跳动。
2. 动画配置应区分动作组，并分别指定帧序、帧时长、双刀轨迹和循环接缝。不能继续让每一阶段复用相同六帧。
3. 对照该录像约 0.7–0.8 秒整轮的读感制作首轮样片，允许整体变速；各动作组的精确时间比例仍需更密集抽样和实际循环复评。
4. 先验证持续普攻时第三组能自然接第一组，再检查停止攻击后的回正。不能为每段强插完整待机，造成动作断裂。
5. 视觉上有多次挥剑，不自动等于多次伤害。现有四阶段输入、单阶段一次命中、缓冲和约 300 ms 断连规则，仍是当前运行代码；新动作的输入阶段与命中事件映射须在接入时明确，不能宣称已经同步改变或实测通过。
6. 当前没有观测到命中敌人的完整过程，故不能从空挥录像确定命中停顿、击退、碰撞范围或玩家受击行为，也没有完成移动动画研究。

本记录交付的是已核对的参考方向和实现差距，不是“完美复制完成”的验收结论。完成条件是原创动画接入后，能并排对照姿势、刀路、节拍和循环接缝，并在手机实际显示尺寸复评。
