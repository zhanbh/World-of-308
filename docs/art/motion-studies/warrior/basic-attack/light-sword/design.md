# 三段普攻分镜 v1

状态：设计初稿，未制作动画。共通输入、判定和验收见[战士动作设计](../../DESIGN.md)，视频事实见[观察记录](README.md)。所有时间均为本游戏的建议初值。

## A：交错斩（200 ms）

| 关键姿势 | 时间 | 身体、双手与刀路 |
| --- | ---: | --- |
| A0 收肩 | 0 | 前腿支撑，肩腰略反向预扭，副手横收胸腰，主手收至侧后上方 |
| A1 横向交错 | 50 | 副手横扫，主手开始斜向出刀；重心向前脚落，双刀高低错开 |
| A2 交错峰值 | 80 | 形成胸腰横线与斜线的组合轮廓；一次伤害标记，不按可见挥刀数追加伤害 |
| A3 接上引 | 140 | 身体扭转不停在待机，刀刃分别进入下一段的上引路径 |
| A4 尾势 | 200 | 连续输入直接进入 B；停止则由尾势短过渡回守势 |

## B：上引交错（220 ms）

| 关键姿势 | 时间 | 身体、双手与刀路 |
| --- | ---: | --- |
| B0 承接 | 0 | 从 A 尾姿开始，不能重新出现 A0 或待机 |
| B1 反扭/上引 | 60 | 腰肩换向，主副手在身体前后错层上引，脚底稳定 |
| B2 窄弧斩 | 100 | 前方较窄的上引刀光，一次伤害标记；身体逐渐拉高 |
| B3 高举 | 160 | 双臂到头顶附近，双刀指向形成不对称角度，预备 C 的落刀 |
| B4 尾势 | 220 | 连续输入直接进入 C；停止时回收双臂，不瞬间切回守势 |

## C：高举下落与低收势（360 ms）

| 关键姿势 | 时间 | 身体、双手与刀路 |
| --- | ---: | --- |
| C0 高位承接 | 0 | 接 B 高举姿势，前脚保持落点 |
| C1 下挥 | 70 | 主手从高处向前下方劈落，肩腰随动；副手向后上方打开 |
| C2 低位命中 | 140 | 上身大幅俯下、前腿屈曲，主刀在前下方、副刀在后上方；一次伤害标记 |
| C3 留势 | 230 | 低姿势短暂停留，刀光消退，不能两把刀一起弹回站姿 |
| C4 回收 | 310 | 重心回升，双手靠回首组可接位置，开放移动/技能取消 |
| C5 循环接缝 | 360 | 按住则接 A0，保留身体与脚底连续；松手则完成回正 |

一轮 780 ms，三个伤害事件。A/B 的双刀动势、C 的低姿势留停顿构成节拍；不能给每段都均匀分配“举刀—挥刀—待机”。A/B/C 需各自独立帧组，旧六帧不满足分镜。

姿势编号是动画关键点，不等于最终 PNG 张数；可补过渡但不增加操作段数。停止、受击与技能接入都必须有可复查的姿势出口，尤其检查 B 的高举停止与 C 的低势接 A。
