# 女性猎人立绘 v2

2026-10-17：根据用户“更惊艳、更性感”的反馈调整，造型为待审阅提案。

目标是有吸引力、气场鲜明的成年女性弓箭手。保留栗色编辫高马尾、青绿发带、琥珀棕眼、木质反曲长弓及箭袋；以贴身皮甲和更清楚的肩颈、腰线、腿部轮廓替换v1宽松的内衫长裤。

| 设计点 | v2方向 |
| --- | --- |
| 面容 | 更成熟精致的五官、直接而自信的眼神、克制的眼妆 |
| 上身 | 青绿色收腰皮甲、较深领口、露肩、单侧短披肩 |
| 腰部 | 小面积露腰和斜向皮革束带，强化轮廓 |
| 下身 | 不透明短裤配高开衩分片裙摆，腿部皮带和贴腿长靴 |
| 姿态 | 重心落在一侧，前伸腿和轻微转体形成曲线，整弓和双脚可见 |
| 质感 | 保留青绿、深蓝、象牙白与旧金，强化皮革/金属区分和角色立绘光影 |

只调整美术造型，不改变女性猎人职业、四技能、装备槽或玩法。旧v1设计板保持历史版本，不能混作此版服装的生产三视图；新版三视图和连续动画须待立绘方向审阅后再制作。

本稿为角色概念立绘，不是运行图集；深色背景为立绘展示背景，不声称可直接透明贴入游戏UI。生成提示词见[prompts.md](prompts.md)。
