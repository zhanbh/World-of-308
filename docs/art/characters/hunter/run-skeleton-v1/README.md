# 8帧双色跑动骨架 v1

2026-10-18。独立的矢量动作研究，未修改猎人立绘，也未套回人物。

- 蓝色：角色左腿、近侧；橙色：角色右腿、远侧。绘制层级固定为远腿先、近腿后。
- 金圈：绑定蓝色大腿从髋到膝的36%位置，所有帧由相同公式计算。它是身份追踪标记，后续人物腿环也必须使用这个绑定关系。
- 8帧构成完整的左右双步循环：左接触/承重/蹬离/腾空，右接触/承重/蹬离/腾空；每帧80ms，共640ms。
- 大腿60、小腿65，全帧保持固定长度，以髋与脚踝坐标解出膝盖，膝盖始终低于骨盆。后脚回收保持低位，不踢至腰臀。
- `build.cjs`生成`motion.json`、`contact-sheet.svg`和`preview.html`。只生成矢量骨架，未读取或变形原人物图。`contact-sheet.png`是浏览器对SVG的等尺寸栅格导出。

启动`node client/tools/hunter-animation-preview.cjs`，打开 http://127.0.0.1:8781/skeleton/ 。支持播放、0.5/0.25倍速、上一帧、下一帧、拖动逐帧；接触表同时展示全部8帧。

检查：构建时校验全部大小腿长度、脚踝可达性和膝盖高度；目视核对完整接触表，左右脚轮换承重，4/8双脚腾空，金圈随蓝腿前后摆动；浏览器验证8帧加载、慢放和第8帧下一帧回到第1帧。此检查不代表最终带服装人物已通过。

下一阶段以该骨架作为同一套动画约束，再制作人物分层及逐帧轮廓。不能仅把这张图作为生成参考后重新接受不遵循骨架的源稿。
