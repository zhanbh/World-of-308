## 1. 核心问题根因诊断与修复说明

用户反馈的核心问题包含三项：
1. **左右腿跑动不连贯（卡顿/跳动/跛脚）**：
   - **根因**：旧版 `animation-v4` 跑动图集仅有 **7 帧**（前 4 帧近腿 320ms，后 3 帧远腿 240ms，总长 560ms 为奇数半拍），删减了远腿下沉承重帧，导致远腿着地后直接瞬移跳至支撑位，垂直落差瞬间突跳 25 像素，产生视觉跛行跳动。
   - **修复**：复原并对齐远腿下沉承重姿态帧（Far Down），构成完整的 **8 帧对称双足步态**（4 拍近腿 + 4 拍远腿，每帧 80ms，总长 640ms）。
2. **左右腿交替不均与断层**：
   - **根因**：双腿交替时相位不对称，缺乏平稳的着地缓冲与蹬离抬升过渡。
   - **修复**：近腿半循环（接触→下沉→经过→蹬离）与远腿半循环（接触→下沉→经过→蹬离）相位严格镜像对应，着地基准线统一贴合 $Y=352$，自然展现身体重心的重力下沉（Down 时脚着地 Y=352）与腾空抬升（Passing/Push-off 时身体升高）。
3. **腿环在左右腿之间跳变交换**：
   - **根因**：原画局部重绘及提示词错位，在旧版后半循环误将腿环抹除并在远腿（右腿）上重新画出金扣与饰物，导致循环播放时腿环在左右腿之间跳变多达 3~4 次。
   - **修复**：严格按照解剖学定义，**腿环（黑皮带+金菱形扣+玉坠）100% 且唯一归属于角色解剖左腿（朝右时的近侧腿）**；远侧右腿全帧保持质感纯净的薄黑丝袜。当左腿处于被裙摆或前腿遮挡的角度时自然遮挡，绝不移至右腿。
