# 女性猎人 — 角色概念设计 v1

日期：2026-10-17。阶段：角色外形和动作方向提案；用户已明确女性身份，尚未逐项确认本稿造型。来源：[整体职业/技能基线](../../../../spec.md)、[提示词](prompts.md)。

## 1. 角色定位

一名沉着、敏捷的成年女性弓箭手。核心印象是“停得稳、射得准、转移快”：通过弓的弧线、短披肩和利落的步姿表现职业，面部与体型保持成年女性特征。具体名字、人物背景和种族设定本轮不新增。

与战士共用原项目的像素颗粒、深色轮廓、象牙白布料与少量旧铜装饰；猎人以轻皮甲、短披肩、长弓和箭袋形成独立轮廓，减小肩部体积并让拉弓的两臂清楚可读。

## 2. 造型提案

| 部位 | v1设计方向 | 后续制作要求 |
| --- | --- | --- |
| 头部 | 深栗色高马尾，发根短编辫，青绿色束带；沉着的棕琥珀眼睛 | 发束分成少数大块，避免碎发闪烁；面部不被兜帽遮住 |
| 上身 | 象牙白短内衫、棕色皮革护具与束带 | 左弓臂和右拉弦臂的动作空间完整，避免大肩甲 |
| 披肩 | 苔青/灰绿短披肩，长度不过腰，尾端分片 | 作为移动方向提示，不能遮住双腿和弓弦 |
| 下身 | 深蓝贴身实用长裤、稳固的中筒靴 | 两腿独立清楚；跑动必须近/远腿交替承重，不用同一腿反复前摆 |
| 手部 | 弓臂护腕、简洁护手 | 护腕不能侵入弦的回弹路线；弓手、拉弦手分工固定 |
| 武器 | 深木色反曲长弓，局部旧铜包角与青色握把 | 弓弦必须存在且可辨，拉弓时弓臂有轻微形变 |
| 箭袋 | 背部斜挂，白色箭羽带少量青色识别色 | 箭袋、头发和弓三者分离；取箭动作有明确来源 |

建议配色用于角色稿，尚不作为最终索引调色板：象牙白 `#E9DEC5`、深蓝 `#273748`、苔青 `#4B7268`、皮革棕 `#765039`、旧铜 `#B69558`、发色 `#342A27`。以输出图的实际颜色为准，后续像素清稿再统一色阶。

## 3. 立绘与游戏内角色的关系

- 独立立绘用于角色选择、职业介绍与后续头像裁切参考；全身、整弓、双脚完整；PNG带Alpha，当前仍有局部棕色色晕，正式用于UI前需精修抠图。
- 设计板展示同一角色的前向、侧面、背面及射击/移动关键姿态，采用不透明底便于看清服装和弓弦。前向栏略偏四分之三视角，后续生产需补严格正交三视图。
- 当前生成稿是高分辨率像素风概念，尚未证明具有固定原生像素网格，不能直接缩成正式游戏人物，更不能按设计板裁格冒充连续帧。
- 正式游戏本体的显示身高、脚底锚点、Y排序和视觉重量须与当前战士同屏对齐，避免猎人立绘比例直接决定碰撞盒。
- 制作时至少区分本体、弓、箭/投射物、箭袋与残留特效；装备槽仍沿用整体13槽规则，箭袋外观不自动增加弹药槽或消耗箭矢经济。

## 4. 基础动作方向

| 动作 | 身体与武器表现 | 验收重点 |
| --- | --- | --- |
| 待机 | 侧身轻屈膝，弓斜置，胸腔轻微呼吸 | 双脚稳定，不整体弹跳，不凭空重复搭箭 |
| 走/跑 | 重心先移动，双腿交替支撑，弓随手臂有克制摆动 | 近腿前撑与远腿前撑都出现；脚落地不滑，披肩和马尾略滞后 |
| 急停/转向 | 小幅沉身后稳定，重新建立弓手/拉弦手关系 | 不直接镜像成左右手互换；朝向切换须检查箭袋及弓弦遮挡 |
| 普攻 | 取箭/搭箭 → 拉弦 → 明确释放 → 回收并衔接下一箭 | 释放瞬间箭离弦，手指/弦回位；不把弓当枪反复后坐 |
| 受击 | 肩部和重心受扰，弓臂跟随收回 | 命中反馈清楚，不能因形变缩放使角色忽大忽小 |
| 死亡/复活 | 沿用通用生死和复活规则，分别制作表现 | 死亡期间持续伤害、免费复活与手动复活遵守挑战规格 |

普攻先设计为可持续衔接的单箭射击循环，不从战士继承三拍挥砍，也不据此新增连段增伤。阶段时长、攻速如何映射、前后摇取消和箭速另做动作原型验证；本轮不定正式数值。不增加主动闪避、跳跃或空中连招。

## 5. 四技能视觉提案

沿用已确认的技能功能，不新增控制类型或元素伤害；第3/4技能名字尚未正式确定。

| 技能方向 | 关键姿态与视觉区分 | 需要后续决定 |
| --- | --- | --- |
| 贯穿箭 | 侧身站稳，弓拉得更充分；细长直线箭迹贯穿多个目标 | 前摇、范围、穿过目标的命中规则及伤害量；贯穿不等同忽略护甲 |
| 扇形箭 | 上身打开，短促释放；多条独立箭迹呈扇面 | 箭数、角度、同目标多箭结算与时序，不默认固定三箭 |
| 伤害并减速 | 瞄准偏低，命中后用克制的环/拖尾提示减速 | 具体外观与机制来源；不默认冰冻、陷阱、流血、定身或持续区域 |
| 前方区域箭雨（大招） | 抬弓向斜上方蓄势，先给前方落点提示，再从上方落下箭雨 | 范围、落箭频次、持续时间与伤害；身体结束和投射物/残留分开 |

职业技能消耗魔法并有冷却，首版4主动的范围不变。当前表现只是分镜方向，不写入运行代码或正式配置。

## 6. 后续素材制作顺序

1. 审阅主立绘和三视图，锁定面部、服装大块、弓与箭袋轮廓。
2. 制作与战士同屏的侧向待机样片，核对实际手机尺寸下的弓弦、手部和头发可读性。
3. 优先制作交替腿跑动及单箭普攻连续帧，验证步态、搭箭和释放；本轮不批量生成未审阅动画。
4. 再拆四技能动作及独立箭迹/落点/命中特效，按真实帧序验收，最后接入客户端。

## 7. 本轮交付检查

检查角色为成年女性、人类外形、单弓箭职业；全身未裁切、弓弦存在、手臂与腿数量正确；立绘透明，设计板同角色一致。设计板的武器/拉弦手必须人工复核；生成稿局部一致性不视为已经达到生产动画标准。

本轮检查结果：全身与整弓完整，成年女性形象、弓弦及主要服装识别点清楚；设计板有3个不同基础姿态。Alpha背景残余、严格正面图及生产像素网格仍需精修；跑动循环尚未制作。文件尺寸及生成记录见[资产元数据](assets.json)与[提示词](prompts.md)。
