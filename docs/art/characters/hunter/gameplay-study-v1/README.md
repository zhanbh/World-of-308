# 猎人像素姿态研究 v1

2026-10-18。依据：已认可的[v3外观](../concept-v3/hunter-key-art-v3.png)。战士早期像素稿仅作像素颗粒与小人比例参考，不作为猎人的角色或服装来源。

输出：hunter-gameplay-study-v1.png；待机、拉弓、近腿支撑、远腿支撑四个关键姿态。内置imagegen生成，提示词及实际检查结果见[prompts.md](prompts.md)。

本稿用于检查从高精立绘转向游戏小人后，马尾、短靴、丝袜、裙片、长弓是否仍有识别度。它不是连续动画，也未接入客户端；图片不保证固定原生像素网格、相同帧框和脚底锚点，不能直接裁四格播放。

下一制作规格见[动作制作 brief](../MOTION-BRIEF.md)。近腿/远腿两种承重必须真实互换；有两张跑姿不代表已有完整、无滑步的跑动循环。
