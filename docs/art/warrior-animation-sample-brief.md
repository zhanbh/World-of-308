本 brief 覆盖此前四段交替斩/末段交叉展开的制作要求。新目标是光剑里鬼参考的三段普攻，加先横后竖十字斩、短跃崩山击、收势快横斩拔刀斩、地裂后延迟喷发的大崩。原作录像不直接进入游戏资源。

## 角色与画面约束

原创像素风双刀战士。现有黑发红发带、蓝白金护甲概念稿可作外观参考，仍需保持全部姿势的人体比例、服装细节和两刀一致。横屏 480×270 构图、左右朝向、有限纵深与地面 Y 排序保持不变；纯纵向移动保留最后左右朝向。

角色身体、双刀轨迹、近身刀光、地面效果分轨。统一脚底地面锚点，空中高度不能改变碰撞/阴影的地面位置。用各姿势联合包围盒确定帧框，不能沿用旧生成图的 512×512 图格作为生产规格，也不能为塞进刀光缩小人物。

## 第一轮交付

已有[关键姿势评审草图 v2](motion-studies/warrior/poseboard-v2.png)，供轮廓讨论，不能直接裁格当作第一轮粗动画；细节与来源见[生成记录](motion-studies/warrior/poseboard-generation.md)。

1. 按五份 `design.md` 制作关键姿势，先检查双手刀路、腰肩发力、脚步支撑、低姿势与回收，所有姿势都需保留两刀。
2. 制作可变帧时长的粗动画：普攻三段各自独立，C→A 循环自然；四技能各有起势、有效打击与收势。不能四段/四技能复用同组六帧。
3. 提供单次、持续普攻、技能接普攻、左右转向和打断预览；均有 1×/0.25× 播放及实际手机显示尺寸。
4. 轮廓与节奏通过后，导出透明 PNG 序列/图集、可编辑源文件、帧序与帧时长、统一脚底坐标、刀尖/双手挂点和来源记录；原图集保留作历史，不覆盖删除。
5. 接入前补足待机、慢走/跑动、起停和受击的必要动作，避免用守势帧滑动或闪烁冒充完整动作。走跑不新增跳跃玩法。

## 必须看清的差异

| 动作 | 轮廓与节奏重点 |
| --- | --- |
| 普攻 A/B/C | 胸腰交错 → 上引高举 → 下落低收势；连续输入的循环接缝自然 |
| 十字斩 | 横斩先出现、竖斩后出现；不是同时闪两条对角线 |
| 崩山击 | 短跃、有限前移、落击与小范围地面反馈；起跳时不提前完整爆地 |
| 拔刀斩 | 压身收刀的停顿与极快宽斩有反差，收招姿势留得住；不画持续扩散剑气 |
| 大崩 | 高举重落、地裂蓄积、延迟喷发分层；喷发残留期间角色可以恢复行动 |

## 验收

在 Note20 Ultra 正常握持距离下看清动作差异、朝向与命中，不靠放大截图。脚底不跳、衣摆不闪、武器不断裂穿体；大招不能长时间遮住角色和敌人预警。效果寿命独立于角色动作，不通过加特效掩盖缺少身体姿势。

动作图/草图通过只代表可以进入粗动画；粗动画与类型检查通过也不代表手机手感、微信小游戏性能或完整 MVP 通过。本轮时间与帧数为调试设计，不是正式美术生产帧表。

当前六帧历史草稿：`warrior-dual-slash-sprite-draft-v1.png`，运行副本仍在客户端资源目录。它没有独立的三段普攻、走跑、受击或技能帧，不得当成新动作已完成。
