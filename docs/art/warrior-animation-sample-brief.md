# 战士动作小样美术 brief

状态：**制作前简报；玩法动作规则已确认，具体画风细节、帧框、帧数与动画资源管线待小样验证。**

日期：2026-10-15。对应[动作原型规格](../action-prototype.md)和[整体规格](../spec.md)。本简报只定义验证用的单角色美术样片，不代表正式生产素材规格已经锁定。

## 目标

用最少素材回答两个问题：玩家能否在三星 Note20 Ultra 横屏握持距离下看懂角色的移动、攻击阶段、命中和受击；双刀普攻与剑气技能是否有清楚、有力的动作节奏。手机浏览器 H5 已能打开并操作，但用户认为当前占位人物与动作表现较差。现有原型用程序绘制的临时角色动作，不能代表成品表现。

## 角色与镜头约束

- 角色是原创 2.5D 像素风双刀战士。早期[战士概念稿](warrior-pixel-concept-v1.md)只参考像素清晰度、配色探索和轮廓方向，不照搬 Codex 宠物的外形、服装或身份。
- 横屏固定镜头，横向推进并允许有限纵深移动。双刀挥动和刀光可超出角色本体，但脚底锚点始终代表地面位置，供移动、碰撞和 Y 排序使用。
- 当前先做左右朝向；纯纵向移动保留最后朝向，不要求八方向角色动画。
- 横向摇杆力度区分慢走与跑动；Y 轴过死区后保持固定移动速度。动画应避免明显滑步，但动画表现不能反过来改变移动速度规则。
- 跑跳只作为 Codex 宠物动作衔接与身体起伏的表现参考。本轮没有跳跃按钮、平台跳跃或空中连招，也不新增空中碰撞规则。
- 当前样板人物比例此前按真机辨识反馈增加过；美术尺寸和画布占比不按早期 32–40 像素估值锁定，应同时展示原尺寸和实际手机显示尺寸后再定。

## 第一轮最小内容

先交关键姿势/粗动画预览，确认轮廓与节奏后再精修同一小组素材。第一轮只做一名战士、一种普通近战怪的必要反馈：

| 动作组 | 必须表达的内容 |
| --- | --- |
| 待机与移动 | 有呼吸/警戒感的待机；横向慢走与跑动有可辨差异；起步、停步、左右转向自然。纵深移动按现有左右朝向表现。 |
| 普攻第一段 | 左手发起左砍，动作有准备、发力和收势。 |
| 普攻第二段 | 右手接续右砍，不能只是第一段镜像或人物整体平移。 |
| 普攻第三段 | 双刀动作突出向上挑的方向感；不凭动作新增浮空机制。 |
| 普攻第四段 | 左手向右、右手向左同时交叉横扫；随后左手向左、右手向右反向展开，再以较慢、清楚的动作回收。交叉与展开是同一段，收招不能一闪而过。 |
| 剑气技能 | 先快速连续横向挥刀两次，再出现一道圆弧剑气；只出现一道剑气，动态向外扩散，到达范围后消失。剑气穿过多只怪物，不被单只怪挡住，也不因命中怪物提前消失。 |
| 受击与敌人反馈 | 玩家受到攻击时能看出受击方向、短暂失衡和击退；普通怪被砍中时有明确命中反应。怪物出招前的预警与攻击落点也应容易辨认。 |

## 节奏与规则

- 普攻顺序固定为左砍、右砍、上挑、双刀交叉横扫，然后循环。单次点击只请求当前下一段；断连后从左砍开始；按住普攻才持续请求后续攻击。
- 连段衔接窗口约 300ms，是动作结束并允许再次出招后的输入窗口初值；它不是整段动画的长度，也不是每次挥刀的固定间隔。攻击动作内的提前点击由输入缓冲处理。
- 当前代码调试值为前三段约 320ms、320ms、400ms，第四段约 760ms。它们只帮助首轮动画对齐，不是美术必须照抄的最终帧数；手机复评后可共同调整。
- 剑气当前的两次挥刀总前摇和扩散参数都只是临时值。首轮只需表达“两次挥动 → 一道扩散剑气”的因果和穿透效果，不将未确认的挥刀近战伤害、剑气命中次数或最终范围画成既定规则。
- 命中判定由游戏逻辑决定，刀光用于表达攻击范围和方向，不以可见刀光自动扩大伤害范围。

## 交付物与未锁规格

首轮交付建议：

1. 一段包含待机、走跑、四段普攻、剑气起手与扩散、玩家受击、普通怪受击的连贯预览，可先用关键帧/粗动画确认节奏。
2. 确认后的透明背景像素序列或图集、帧顺序和统一脚底锚点说明；附可编辑源文件、调色板与素材来源/授权记录。
3. 在三星 Note20 Ultra 横屏实际显示尺寸下的预览图或录屏，能看清双刀分工、第四段交叉后展开的收势，以及剑气从两次挥刀后扩散并穿过多怪。
4. 美术建议的帧框、帧数、原生像素密度和循环方式。第一轮前不预设这些数值，也不要求美术先完成猎人、装备、UI、首领或完整方向集。

像素资源保持边缘清晰并采用最近邻采样；角色各帧脚底锚点一致，刀光单独清晰可辨。第一轮先用可导入 Cocos Creator 的 2D 逐帧素材或图集；若美术建议使用骨骼动画，先评估像素边缘质量和现有项目的集成成本，再决定是否采用，不把额外动画插件列作当前前置依赖。

## 验收

- 正常手机握持距离下能辨认角色左右朝向、慢走/跑动、四段普攻的差异、技能的两次起手与单道剑气扩散，以及玩家/怪物受击反馈；不能只在放大截图下成立。
- 第四段能明确读出“交叉 → 反向展开 → 慢收势”，不会误看为一次普通横砍；动作结束后输入响应不显得拖沓。
- 剑气不是两把刀各自发射一道，也不是碰到第一只怪就停；扩散、穿透、多怪受击效果一眼能理解。
- 走跑动作节奏与角色位移协调；起停、转向响应及时，不出现明显滑步或为等动画结束而卡住摇杆。
- 角色视觉起伏不改变地面锚点；怪物攻击预警与玩家受击能区分，不把危险提示和命中特效混成一团。
- 美术样片到位后，集成进现有原型并由用户在 Note20 Ultra 上复评。样片通过只代表单角色动作表达足以继续验证，不代表完整美术、MVP 或微信小游戏性能验收完成。

## 明确不在本样片内

猎人及第二职业、战士其余三个技能、主动跳跃或空中攻击、八方向动作集、精英/首领专属动作、装备换装与成长特效、正式 UI、美术全量生产。后续范围依据手机复评结果再扩展。
