# 首副本方案审阅 v1

日期：2026-10-20。对象：[D04遭遇方案](../design/dungeon-first-proposal-v1.md)。状态：专题审阅中，未修改业务代码。

## 已确认决定

- 初始站位：玩家左侧进入，怪物主要在中右部，入口留观察空间；近战上下错开、远程靠后、冲锋不全站同一横线。紫名沿模板站位、不额外藏角落；Boss偏右中部留绕行空间。配置合法出生点并可小幅随机偏移，不生成于障碍、玩家身上或不可达位置。具体距离和坐标待校准。

- 最新确认替换原分波方案：每个房间所有怪物同时出现，紫名怪随所在房间一同出现；全部消灭才开门。R1近战3；R2近战5；R3近战3+远程2；R4冲锋2+近战2；R5精英1+远程2；R6近战3+冲锋1+远程2；R7单Boss。基础27+紫名1=28；紫名在R6时同屏峰值7，尚未性能实测。

- 首Boss生命降至50%进入第二阶段，施招中先完成该招再切换，不因切阶段强制中断；切换不清空技能冷却。具体转换表现及合法中断后的衔接边界后续明确，不额外添加无敌或治疗。

- 吼叫前后半血均可选用、独立冷却，不固定接冲撞；玩家在前方中距离时可选，玩家在侧后方时不瞬间转向施放。距离边界和选招权重待配置。

- 吼叫击倒玩家后，范围内的持续伤害与击退继续，直到玩家退出范围或技能结束；仍为单次吼叫最多触发一次倒地。此前“倒地后免疫本次伤害/击退”的建议被用户否决，不采用。

- 后续调整：Boss明确为人形牛头人，替换旧野兽分类；精英牛头守卫同为人形，顺劈可打断、横扫霸体、收招恢复正常控制，可流血。
- Boss新增持续数秒的范围声波吼叫，范围内玩家持续受伤并被击退，退出范围停止受到声波作用；前方扇形、起手锁向、持续期间霸体已确认。按本次吼叫对该玩家累计实际伤害占最大生命值的比例判断倒地，每次吼叫对同一玩家最多触发一次；不跨施法累计，不含其他伤害。倒地后仍持续受伤及击退，直到退出范围或技能结束；具体比例及起手/收招边界待定，具体数值暂缓。

- 首个牛头人 Boss 归为人形，可流血；平时可僵直、小幅击退，直接伤害累计达阈值可倒地。重槌/践踏/冲撞施放期间霸体，免疫僵直/击退/倒地，仍受伤且可流血；收招与撞墙虚弱恢复正常控制。该特殊设定不推广至其他怪物；动作边界、阈值与虚弱具体参数待验证。

- 人形、野兽默认允许僵直/击退/倒地及流血；亡灵、机械默认允许这三种控制，但免疫流血。类型默认仍可由单体/阶段特殊设定覆盖，允许控制不代表每次命中必定触发。未确认其他类型默认或其他持续伤害免疫。

- 每局额外1只紫名双倍经验怪，随机在R1–R6之一，挑战创建时确定，重连不重抽；经验为同等级同难度对应普通怪2倍，不追加掉落规则。
- 模板、类型、战斗身份、技能、行为及抗性组合配置，任何模板可为Boss，同技能可跨怪物使用。类型含野兽/人形/亡灵/机械等，不限制扩展。
- 控制抗性按类型默认与特殊设定确定，单体/阶段可覆盖；僵直/击退/倒地分开，不按Boss身份写死免控。未认可的“平时免控、撞墙才可倒地”不采用。
- 技能分本体/动作适配/施放策略/预警表现；参数可按怪物与难度覆盖，攻击结构改变须显式变体，结算绑定动作节点。
- 默认小怪只有快速出招动作，无额外预警；精英/Boss显示范围预警，特殊设定可覆盖。
- 精英顺劈+横扫；首Boss重槌/践踏，后半血增加连续践踏接锁向冲撞，撞墙虚弱；不加全屏伤害、召唤小怪、死亡自爆。
- 四难度行为递进：普通基础行为，冒险追击，勇士近战夹击/远程保持距离，王者提高进攻频率/减少发呆，起手后不瞬间转向追踪。
- 群怪协调可配置，普通主动错开，难度提高增加协同；普通近战可重叠，冲锋/大范围攻击适当错开，保留走位空间；Boss随从参与按遭遇配置。
- 单纯受伤不自动中断；实际控制结合技能配置决定中断。取消未执行攻击，保留已结算伤害。脱手效果默认继续，可特殊清除；死亡停止后续施法。
- 怪物技能正式起手计冷却，中断不退还，冷却期间可移动/普攻/选其他可用技能，特殊规则可配置。

## 本轮整理及纠偏

方案已整合为单一当前口径，逐房表列出模板、类型、身份、技能、行为、抗性和同时出场规则。移除互相覆盖的旧候选正文；历史可由Git追溯。

纠正按整局扣体力、回刷不能用高阶技能、小怪投石红圈/冲锋红线、Boss天然免控、任意技能击倒远程怪等表述。删除未经确认的统一预警下限、倍率/词缀、U伤害及非法装等、旧金币算例，以及未经实测的通关/性能保证。

候选数量核对：普通25+精英1+Boss1=27，额外紫名1后28；该数量不代表已通过运行验收。奖励和性能预算均须计入紫名怪。
