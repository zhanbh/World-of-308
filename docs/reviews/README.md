## Review v1 的复核边界

- 已实现：顿帧、火花、跳字、落地震动、4帧确认的左侧残片裁切、拔刀蓄力/十字发射微光。新身体图集已补移动/急停/受击/落地及B2；完整像素技能特效与副刀过渡仍待制作；图集其他疑似残片保留待复核。
- 大崩提前到960–1000ms喷发、主副刀造型差异、拔刀收纳/恢复动作：属于新调整建议，尚未采纳。当前大崩仍为880/1280/1500/1720ms四段，效果结束2400ms；拔刀仍保留已确认的单刀与200ms蓄力。
- 崩山前移“匀速”的描述需复核：当前模型已有二次缓出，不能据此直接判定尚无缓动；视觉上是否像拖拽仍需真机评价。
- 死亡脚底阴影硬切需复核：当前Cocos与预览已使用 `deathOpacity` 淡出阴影，血条在死亡时退出；不要按旧描述重复修复。
- 高精立绘/头像“完全缺失”的描述是评审时点快照，工作区已有其他会话生成的候选文件，尚未验收或纳入本次提交。
- 装备槽数量不自动意味着MVP必须实现换装外观，分层素材建议不扩展当前规格范围。
