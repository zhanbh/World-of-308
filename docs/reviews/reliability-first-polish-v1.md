# 按可靠度优化 v1

日期：2026-10-16。依据：用户要求按可靠度优先优化视觉与动作评审意见。状态：代码与浏览器检查通过，待真机手感验收；准备归档提交。

## 本轮采纳

- 命中顿帧：普通有效命中33.3ms、带击倒反馈的命中50ms，均为起调值。命中同一时刻的多个目标取最长停顿，不按怪物数量累加；未命中不触发，同一次伤害不重复触发。
- 使用独立表现时钟。顿帧期间暂停战斗模拟（双方动作、位移、技能/残留、受击计时），输入事件与UI仍接收；不会靠跳过时间追赶动画，恢复后各段照常结算。流血和倒地均跟随战斗时钟，因此顿帧会略延长实际墙钟持续时间；后续调参时需要一并观察。
- 每次有效命中产生小型整数像素方块火花，持续140ms；重击扩散略大，不依赖额外图集。Cocos火花放在角色前的覆盖层，Canvas评审共用像素布局模型。火花表现独立消退，重置清空。

## 复核后暂缓

查看普攻v2图集，可见单元边缘的刀光残片，原始意见有依据。但残片邻近有效武器/光效，不能靠全局孤立像素删除可靠区分。本轮未修改源图、Alpha或打包裁切，以免损坏正常刀光。下一次应选问题帧做局部清理前后对比，再重打包。

普攻体积跳变、移动/受击专用帧属于图像与动作制作任务，本轮不冒充已经修复。大崩喷发时间、武器长短、副刀收纳、现有200ms拔刀蓄力等仍保持原设计。震屏、跳字和整套像素特效替换暂缓。

## 验证证据

- 模型：群怪停顿取最大值、空闲不触发、单个伤害不反复触发、轻重停顿、火花清理、整数像素布局、大崩四段在顿帧后仍正确结算。
- 浏览器：崩山步进到实际300ms时动作时钟267ms、命中1次并可见火花；继续步进后命中3次、血量28/30、倒地状态正确。
- 原有多段/流血刷新/阈值/死亡测试及TypeScript检查通过。
- 尚未做Cocos Web Mobile重建与Note20 Ultra真机体验，最终顿帧力度和火花尺寸待手机调节。

## 顿帧/火花对比入口

独立技能预览 `/skills` 增加顿帧与火花独立开关，以及“同条件重播”。重播恢复30血靶怪、清空残留/流血/命中计数与计时，保留朝向、倍速、开关；普通技能按钮仍可用于连续命中刷新检查。关闭顿帧立即解除当前暂停，关闭火花立即清空粒子；重新开启不重播旧伤害。

浏览器验证：崩山同条件步进300ms，顿帧开时战斗267ms，关时300ms；关闭火花不影响顿帧时长和伤害。模型验证开关独立、重置保留选择与旧伤害不反复触发。原型游戏默认开启反馈；对比开关仅在独立评审页提供，未加入正式游戏操作布局。

## 多段伤害跳字

已接入小型伤害跳字，显示每次实际扣除生命（过量伤害只显示目标剩余血量）。显示最多两位小数，低于0.01的正伤害显示“<0.01”；不对战斗数值取整。轻微错开横向位置、上浮淡出，持续550ms；最多保留24个表现项，Cocos复用Label节点。跳字在评审页可独立开关，不影响火花/顿帧和结算。

命中反馈由单个最新命中改为有界事件记录，保证同一个模拟步中的多次伤害分别产生火花/跳字。重新施放保留旧靶怪时建立当前事件基线，不重播旧命中反馈。

模型检查覆盖同帧两次命中、过量伤害、浮点显示、数量上限、过期清理、独立开关、保留靶怪不重播历史伤害；TypeScript与差异检查通过。浏览器可见崩山两次0.67跳字，对应靶怪28.67/30，顿帧后战斗533ms。最终Cocos叠层与手机文字尺寸仍待重建复评。

## 轻微落地震动

按用户继续优化的要求接入崩山580ms落地、大崩880ms拍地的短促震动；十字、拔刀和大崩后续三段不触发。原型最大偏移分别2/3源像素（Cocos逻辑缩放后约4/6屏幕像素），150ms二次衰减，使用整数像素偏移，重置与关闭后严格归零。重复落地取有限幅度，不累加。

只影响地面、角色、敌人、附着血条与命中表现的绘制位置，模型碰撞/命中坐标不变；玩家血条、摇杆、技能按钮与状态栏保持稳定。震动时钟随表现时间推进，即使顿帧也会消退。评审页新增独立开关；关闭立即归零，重新开启不重播旧震动。

模型验证触发条件、整数偏移、幅度上限、衰减、开关与重置、地面坐标不变。浏览器确认：评审900ms/战斗883ms，大崩命中1段，偏移-1,1；关闭立即0,0；后续命中4段时仍0,0。原有回归与TypeScript检查通过。Cocos真机幅度和舒适度仍待验收。

## 本轮最终收尾

### 无损显示裁切替代整图生成

生成候选继续弃用，但通过源图连通区域分析与浏览器同帧对比，确认普攻v2 A5/A6/B2/B4（0基索引4/5/9/11）的左边独立残片。仅在显示时裁去左侧70/64/48/40个图集像素；补偿显示宽度与横向锚点，不拉伸图像、不修改PNG，不改变脚底位置。Cocos、普攻页、技能页共用attackVisibleRect；普攻页新增问题帧选择与裁切开关。B4同帧对比确认悬空刀光消失、主体与有效右侧刀光保留。源图右边已有截断及仍连着武器的光效未擅自修补，不能声称全部图像缺陷已解决。

原图主要连通区域的左边界分别81/84/75/62，裁切边界均在其左侧，另保留约10–27图集像素间距。左右朝向脚底锚点与比例检查通过；Cocos增加图集尺寸检查，错误尺寸不会继续套用固定裁帧参数。逐帧检查失焦只解除按住输入，不清空检查帧。

### 小幅衔接提示

拔刀140–340ms原有200ms蓄力保持不变，在既有刀刃位置加入短暂微光；十字290–340ms加交汇点聚光，发射时结束。均为整数像素小块，未重绘身体、未增加伤害段、未改变单刀/双刀恢复或原有技能时序。浏览器233ms可见拔刀微光，仍是第3帧蓄力、命中0次。

### 验证边界

独立评审页在915×412横屏与390×844窄屏布局检查无横向溢出；这不是手机触控或性能验收。页面图片加载异常现在明确显示刷新/服务检查提示，不永久只显示“加载图集”。回归、TypeScript、两张评审页JavaScript语法与差异空白检查通过。
