日期：2026-11-02
范围：Cocos 玛丽强化面板接线与交互、状态机映射、报价与风险展示、纪念品勾选控制、未知结果恢复、信息隐匿门禁及迟包/切角隔离。来源为已批准 [ST18 规格](../stories/warrior-loop/st18/spec.md)、[04 实施任务](../stories/warrior-loop/st18/issues/04-cocos-enhancement.md) 及 [开发真相源](../backend/source-of-truth.md)。本报告只记录 ST18-04。没有创建、同步或回填 Jira。

## 实现

1. **`EnhancementPanel` Cocos 表现层面板实现**（`client/assets/scripts/ui/EnhancementPanel.ts` 及 `.meta`）：
   - 严格基于 `EnhancementCoordinator` 权威视图与报价状态构建单向数据驱动 UI；
   - 状态机全覆盖：`closed`、`empty`、`loading`、`ready`、`submitting`、`unknown`、`failed`；
   - 强化信息综合呈现：
     - 装备标题：支持传入 `templateLabel` 格式化装备模版，清晰展示部位（武器/耳环）与装备等级（Lv）；
     - 等级与属性变化：显示当前强化等级至目标强化等级（`+X → +Y`），并计算呈现物攻/魔攻变化量预览（`攻击力: before → after (+Δ)`）；
     - 风险与后果警示：根据服务端返回的 `failureConsequences`，准确展示失败后果：
       - 1～10 级：`失败后果: 保持当前等级不变 (保级)`（绿色）；
       - 11～12 级：`失败后果: 强化等级降至 +10 (降级)`（橙黄色）；
       - 13～20 级：`失败后果: 装备永久损毁，返还纪念品 (损毁)`（红色）；
     - 费用与消耗：精确展示所需金币费用及材料列表（强化石、战神纪念品等）；
   - 纪念品选用交互：目标等级 $\ge 11$ 级时自动激活纪念品开关按钮（`[ ] 使用纪念品` / `[√] 使用纪念品`），点击时通知协调器调用 `setMemento(enabled)` 并触发带纪念品报价的自动刷新；目标等级 $< 11$ 级时自动隐藏；
   - 结果横幅：成功时展示强化成功横幅，降级时展示降至+10横幅，损毁时展示装备永久损毁横幅并将本地装备指针重置为空；
   - 严格信息隐匿门禁（AC18-2/AC18-8）：UI 节点树上绝不渲染任何内部成功率百分比（`%`）、随机数样本、阈值或记忆数值；
   - 未知网络结果恢复：进入 `unknown` 状态时，正常强化按钮自动禁用，单独显现 [确认操作结果] 按钮，用户点击即可安全调用 `coordinator.recover()` 恢复原意图；
   - 迟包与切角隔离：关闭面板（`close()`）递增协调器内部代次，退休所有在途网络回调；面板销毁（`dispose()`）完整注销指针监听与 Cocos `game.off`。

## 验证证据

- **定向 Cocos 面板测试套件**：`backend/test/enhancement-cocos.test.mjs` **10/10 全部通过**：
  1. 初始化、打开空状态、合法武器选择与基础信息渲染；
  2. **信息安全隐匿门禁**：递归遍历整棵 UI 节点树的所有 Label 字符串，断言绝对无 `%`、概率、阈值、sample、memory 等涉密信息；
  3. 低段强化提交、状态变更为 `submitting`、强化成功横幅与 `onResult` 结果回调；
  4. 高段 10→11 级降级风险展示、纪念品勾选交互、带纪念品重报价及失败降级横幅；
  5. 高段 12→13 级永久损毁风险展示、失败损毁横幅及本地指针平滑重置为空；
  6. 金币不足（`CURRENCY_NOT_ENOUGH`）拦截状态、按钮禁用与刷新恢复；
  7. 丢包未知状态下恢复按钮显隐、`coordinator.recover()` 幂等推进且零重复扣款；
  8. 面板关闭与切角代次隔离，迟到网络包不污染已关闭 UI；
  9. 耳环选择与部位属性及费用准确呈现；
  10. 20 级强化封顶（`MAX_GRADE_REACHED`）状态与按钮禁用。
- **强化全链路四套测试套件**：`enhancement-cocos` (10) + `enhancement-memory-recovery` (10) + `enhancement-high` (8) + `enhancement-low` (24) 共 **52/52 全部通过**。
- **跨领域关联回归测试集合**：覆盖装备管理、单件修理、商店买卖、银行存取、邮件服务与终局结算共 **150/150 全部通过**。

- **代码与格式门禁**：`git diff --check` 通过，无空白字符与换行异常。
