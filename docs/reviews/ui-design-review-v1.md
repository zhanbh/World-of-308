## 第一轮：信息架构与检视边界

当前信息架构初评6/10：主要服务分区清晰，个人与他人模式复用合理；社交只有按钮，且公开字段未定义，暂不能交付开发。改进后未评分，避免把建议视为已实施。

建议的完整规格：个人模式保留资产与穿脱操作；他人模式只读公开资料，展示昵称、职业等级、13槽已穿戴装备、强化/词条、套装与最终战斗面板；不返回金币点券、背包/金库、邮件、内部账号标识及资产审计来源。缺装备、查询失败、角色不存在、快照时间须明确显示。使用独立公开查询投影，不能仅在客户端隐藏私有字段。用户已确认默认完整公开上述装备与战斗属性，不提供隐藏属性选项；入口为排行榜或玩家搜索，移除城镇点击模型入口。搜索仅按角色名，角色名不可重复；创建时检查并发唯一。精确/模糊匹配与名称规范化仍待确认。
