## 4. 剩余平台与环境 GAP 归档（明确保留）

根据 ST13 规格边界，以下非本地自动化范畴项作为独立 GAP 归档，后续由专门的平台/数值切片承接：

1. **GAP-1: 微信小游戏 SDK 运行时与网络层**
   - 包含 `wx.request`、本地缓存文件大小限制、真机小游戏冷热启动切换等。本地以 Node.js 标准 HTTP/内存协议驱动。
2. **GAP-2: 真实生产数据库与跨机房网络延迟**
   - 包含真实 DynamoDB/Redis 网络 IO 抖动、分布式锁 lease 失效、高丢包弱网长连接断线重连。本地以确定性 `MemoryStore` 验证事务语义。
3. **GAP-3: 三星 Galaxy Note20 Ultra 硬件性能与物理触控手感**
   - 包含 120Hz 屏幕触控采样率、双拇指握持阻挡盲区、高温降频帧率稳定性。本地以 Cocos 纯逻辑热区模型及 Chromium 模拟器验证。
4. **GAP-4: 正式商业化数值平衡表**
   - 包含各等级装备掉落率、药品售价与消耗产出曲线。当前使用显式 `local-test` 候选表。
5. **GAP-5: ST14~ST16 终局结算与团队复活完整闭环**
   - 包含死亡后复活币复活、团队互助复活、地牢最终结算翻牌。当前已完整交付单人死亡清理 buff/保留 CD 以及回城手递手进客栈重置 CD 的权威接口。
