# 流血持续伤害与战斗闭环 v1

2026-10-16。用户同意补齐流血DOT与最小战斗闭环。代码和模型检查通过；用户重建试玩后确认本轮验收通过。

流血暂用 `bleedTuning` 集中配置：每1秒0.2点，持续5秒，共5次。按战斗模拟时间推进，顿帧期间随战斗暂停。重新命中只刷新持续时间，保留已积累的扣血间隔和心跳相位，避免高频命中一直推迟扣血；无流血后再次施加才重置间隔。伤害独立于普攻攻速，不叠层。DOT可以致死，复用白影/淡出并清除状态；不产生僵直、击退、倒地累计、火花或顿帧，仅显示伤害数字。

本地一场战斗分准备、战斗、胜利、战败。准备时怪物不行动；点击上方文字或Enter开始。清场/死亡后停止战斗与技能，死亡淡出继续，结果保留至手动再挑战。结束时同帧双方死亡优先判战败。显示的秒数为不含顿帧的战斗模拟时间。R或切换单怪/三怪返回准备；重开清空生命、法力、冷却、状态、输入和残余效果，保留攻速调试档。没有奖励、装备或在线资产结算。

模型覆盖30/60/120Hz五次扣血、到期边界、刷新不推迟下一跳、DOT无顿帧/火花但有数字、致死及死亡清理、准备不计时、胜败锁定与重开。既有动作、取消、位移和命中回归通过。

手机验收：重建后点击开始；技能命中再停手观察每秒扣血与5秒结束；连续技能刷新后确认不叠层；清场和死亡后确认不自动重开；点结果再挑战检查血蓝、冷却、摇杆释放及残余特效；单怪和三怪各连续试玩几轮，观察衔接和遮挡。
