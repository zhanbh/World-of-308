# 大崩前跳与持续普攻前移 v1

2026-10-16。依据：用户要求大崩默认前跳、按面向方向的前键起手跳更远；持续按普攻且不按方向时极慢前移。状态：代码、模型与独立预览已接入，待手机重建复评。

## 当前起调规则

大崩默认64源像素，起手水平输入沿朝向且超过0.15死区时100源像素；反向、仅纵深输入、死区内输入不增距。面向与距离在起手锁定，中途松手不缩短、改方向不转向。280ms离地开始水平前移，880ms落地前完成平滑位移；跳跃高度、四段时序、蓝耗/CD均不变。提前受击打断后停止后续位移。边界使用房间约束，地面后续伤害与特效绑定实际落点，不绑定起跳位置。

持续普攻每段1.2源像素、进度20%–65%缓慢推进；必须held且两轴无有效输入，主动移动不叠加。松开、受击/死亡或取消接技能后停止；X沿朝向、Y不变。攻速改变每秒小步次数，每段总位移不变。默认一套约3.6源像素，含命中顿帧时实际耗时更长。此为调试值，不是最终数值。

## 验证

覆盖30/60/120Hz、左右朝向、默认/前/后/死区输入、离地前不位移、提前打断、房间边界、落点伤害；三档攻速同套位移一致、松手停止、纵深输入抑制、点按不自动走、技能取消停止。已有攻速/取消/多段/反馈等回归继续通过。独立技能页增加默认/按前/按后大崩对照和持续普攻开关，普攻页显示地面X。

浏览器复核：默认起手后X=64.0，按前起手后X=100.0；持续普攻关闭顿帧、推进1000ms后X=3.6，松开继续500ms仍X=3.6。页面与Cocos使用同一技能位移和普攻微步计算。实际手机手感仍待重建复评。
