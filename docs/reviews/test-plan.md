# 战士闭环 QA 测试计划

日期：2026-10-22；来源：soflow plan-eng-review。仓库World-of-308，main基线414de3e+已确认设计1A/2A/3A。状态：计划，尚未实现/执行完整新闭环；当前后端49项旧测试通过，不代表本计划通过。4A～11A已获用户集中批准，恢复就绪、随机重映射和回复余数按批准合同验收；不是已实现或已执行测试。

## Affected Pages / 场景

- 登录/角色选择/创角/旅店：身份、名称、初始化邮件与重登落点。
- 城镇安全区、角色C、背包B：13槽、容量/整理、换装和耐久；遵循UI纠偏合同，旧PNG只作参考。
- 银行、修理、强化、商店/兑换：两栏/数量、报价、绑定、费用、未知结果恢复。
- 邮件与永久待领：独立列表、30天/永久、部分/批量领取、包满跳过。
- 三副本入口/加载/战斗HUD/死亡/通关拾取：体力/地图/技能/CD/恢复全路径。
- 总榜与职业榜：当前穿戴评分、同分时间、新鲜度、分页；耐久只影响战斗、不改价值评分，政策已确认。

## Key Interactions / 关键玩家路径

1. 真实微信登录→创战士→旅店→领取8血/8蓝/10纹章→初始白武器/20格背包；快速重复确认无双份。
2. 首副本普通1体力进场→逐房至0继续→途中跨固定刷新→Boss通关→回城加载最新体力；不加评分门槛。
3. 武器途中磨损0→伤害降低但继续本局/下房→通关后下次开本受限→城镇修理，金币不足不部分修理。
4. 死亡期间普通残留升级仍dead；手动复活只扣1纹章，清职业CD但不清药品/饰品CD；Boss残留击杀则免费满血蓝通关、小怪收益完整。
5. 血/蓝药分别固定10秒CD，倒地可用不解控；饰品独立按钮可触达，CD中禁换/卸，增益消失不改旧技能快照。
6. 清房换图：剩5秒CD、有效联网加载3秒，新房剩2秒；buff时间也推进；断线恢复段排除。重试加载不重复回血或重置CD。
7. 断网、切后台、原请求丢响应→查询/恢复；保留已确认收益，未确认表现可回溯。恰到10秒按截止处理，重登回旅店不续关。
8. 包满通关→永久待领；包满地面仍留地，退出失效；批领放不下项后仍尝试后项，有部分量和原到期时间。
9. 套装在包/穿戴/两库/待领/有效邮件间变化后再通关，缺件检测范围正确；其他角色绑定不计、有效邮件到期立即不再算持有。
10. 强化+11/+12失败回10，目标+13以上失败损毁；纪念品消费/返还/满包邮件、角色会话记忆、成功丢响应重查；界面无概率数字。
11. 连续500→600→500评分时间更新，同分换装保持时间；打开榜单才刷新，不暴露别人背包/库/钱包。
12. 第二升级本/特殊本按候选内容逐房验收，特殊手动复活整局3次；首本紫名每局额外1只，不能因重连重抽。

## Edge Cases / 异常交互

所有写面板快速连点、改数量、关页/切页、断网重开、旧回包迟到、报价/版本变更；结果未知先查原操作。空列表、权限拒绝、读取失败必须可区分。移动离开NPC后旧面板不能继续授权；取消数量框不提交。

地图角落/薄墙/朝外大崩，移动穿怪仍可受伤；最高急速、多段/流血叠加与Boss霸体收招边界。UI检查摇杆+普攻+四技能+饰品+三快捷位热区不重叠、安全区及银行独立滚动。

## Critical Paths / 必须真实集成验证

- 微信小游戏当前AppID可信身份，跨AppID/伪造身份/旧会话拒绝。
- 提交前任一写失败无半资产；提交成功响应丢失仍查到原结果；两个请求/接管与Boss终局竞争不复制或吞奖励。
- 恢复分页/资源装载跨2秒，状态未齐不开始战斗；具体恢复激活规则依问题4最终决定。
- 最大合法检查点、终局/持有汇总写集、实际SDK调用/字节、P95/P99及预测冻结率，不能只以键数判断。
- Note20 Ultra微信横屏长时、峰值8怪/叠加效果、资源失败/前后台/触控、FPS目标与包体分包。
- 隔离数据备份还原：钱包/容器/来源/O/J/配置引用一致，恢复前旧写无权继续；不操作正式玩家数据。

## 独立复核增量（4A/11A已批准，待实施验证）

恢复及房间激活成功但响应丢失：完整状态尚未就绪不得形成无法追上的计时循环，不重复扣体力/费用，原10秒恢复截止不刷新。另一角色私库的未绑定通用套装不得满足当前角色缺件；角色穿戴绑定不改变物理scope。纳入现有持有、加载和恢复验收组，不增加虚假的已执行用例数。


## 集中批准后的新增反例

4A：resumePrepare分页超过2秒仍不启战斗，原10秒/死亡截止恰到即结束；activate成功丢响应不重扣，ready成功丢响应查回执不刷新锚点。5A：冲突导致持有从缺A/B变为只缺B，同基础样本允许未提交候选映射变化，提交后所有重试固定结果。7A：0.6最小单位两步得1余0.2、分段速率/切房/恢复同结果、满值不存余量、复活/回城清零。11A：另一角色私库未绑定通用套装不满足当前缺件，实际转入账号库才共享。P01：破损/修理不写评分或刷新时间，永久损毁移除评分。纳入既有42组的子情形，不宣称新增通过数。


## FR01～FR03闭环反例

prepare时剩5秒CD，activate在2秒、ready在3秒，最终剩2秒；activate丢响应仍保留H.transitionClock，ready只结一次、关闭清理不重复。ready在3秒，首次新输入4.9秒可校验、5.0/5.1秒进入恢复；旧lastAcceptedInputAt=0不触发立即恢复，心跳与ready重放不刷新inputGapBaseAt。终局预算不包含rankingEntry，13槽只读验证归战斗，含持有汇总按R44/W33；套装强化损毁R26/W11另加必要指针。所有为待实施的验收断言，不是已运行测试。
