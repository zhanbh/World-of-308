## 打开方式

仓库根目录执行：

    node client/tools/preview-ui-slice-kit.cjs

打开 http://127.0.0.1:8774 。修改代码后加 --rebuild；缺少构建时会调用本机已安装的 Creator 3.8.8。也可在 Creator 打开 client 工程，选择 assets/scenes/UISliceKitPrototype.scene 预览。

常规 Prototype 重新构建后，城镇顶部有“UI小样 U”，点击或按 U 进入；小样右上“返回原型”回到原场景。活动权威挑战不能通过此入口离开。

微信独立构建：

    node client/tools/build-ui-slice-kit.cjs /Applications/Cocos/Creator/3.8.8/CocosCreator.app/Contents/MacOS/CocosCreator wechat

导入 client/build/wechatgame-ui-slice-kit 到微信开发者工具，AppID 沿用 wxa68f1165ec1284fa，点击预览后用手机扫码。本目录与正式原型构建目录分开。构建成功仅证明打包，微信登录、上传预览和手机扫码仍由实际环境操作确认。

## 操作与判定

### 背包与装备卡

1. 检查 56×56 槽位、48×48 透明主体、独立品质框，数量显示 ×20，强化角标和耐久条清楚可读。
2. 点击第 1、2、3 件，检查武器、防具、药水。第 4 件为长名称、+15、0 耐久样本。
3. 点击小浮窗“完整详情”，滑动正文或使用滚轮/上下移按钮，确认 16 条属性、套装与谱系末尾均可读，正文不会盖住固定关闭按钮。
4. 依次点“左上/右上/左下/右下”，检查紧凑卡和完整卡保持在可用区域内；浮窗外点击或 Esc 关闭。
5. 禁用态按钮不可触发；锁格仅展示，不扣金币。

### 多指 HUD

1. 手机左手持续拖摇杆，右手依次按住普攻和四技能，再检查独立饰品与三药格。控件高亮与“同时按住”必须对应实际触点。
2. 抬起右手时左手移动应继续；抬起左手后摇杆归零。滑出原按钮不应触发邻键，取消/进入后台必须释放持有输入。
3. 键盘支持 WASD/方向键、空格、E/F/Q/G、T、1/2/3；鼠标验证单个控件。浏览器触控模拟与键鼠结果不能替代手机多指证据。
4. 热区检查使用实际点击判定的同一份几何：圆形动作按钮与摇杆、矩形药格。目标间距 ≥8 设计坐标，全部位于系统安全区及微信胶囊换算后的可用区内。
5. 场内标记只反映移动与按键，不执行伤害、冷却、命中或三段普攻动画。本小样不验证打击感或更改战斗时钟。

### 验证记录与采样

“开始采样”重置本次帧时间记录；预热后在目标页连续操作至少 5 分钟，再停止采样。切页会标记混合场景，进入后台会停止采样。最多保留 10 分钟，数据仅驻留内存。

记录实际视口/安全区、控件间距、触控峰值、移动与动作同按观察，以及 FPS、帧时间中位数/P95/P99、Draw Calls 峰值、可用时的 JS 堆峰值。JS 堆并非显存或设备总内存；无接口时显示不可用。当前采样仅代表此 UI 小样，不代表真实城镇或 8 怪战斗性能。

四项人工判定默认“待验”，点击依次切换为“通过/问题/待验”。桌面“导出记录”下载 JSON；微信端复制 JSON 至剪贴板，同时输出控制台。导出不自动发给其他人。另补记设备型号、屏幕/游戏分辨率、刷新率、温度、画质、工具及异常录屏；这些信息不能从样本自动推断。
