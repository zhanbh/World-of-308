# 多段命中判定粒度对照 v1（已选每段判定）

2026-10-20。已确认每段/每跳独立暴击和流血按有效命中份额施加；“每个伤害段独立命中还是整招对同一目标一次命中”尚未明确。本稿只补这个差异，不重问已确认暴击/预算规则。

执行 `python3 docs/design/analysis/hit_resolution_trial.py`。几何判定先于命中骰：没碰到攻击范围不掷，不能靠命中属性打中空间范围外的敌人。示例都是4段等权、总直接预算100，目标存活且4段几何均有效；实际段权重、目标提前死亡或漏段另按真实结算。

## 候选A：每个敌人、每个有效伤害段分别判命中（推荐）

每段按该段命中机会判定，没命中就没有该段直接伤害和流血份额，也不计倒地直接伤害；其他段仍可命中。每段暴击独立，但只有命中段才结算。每段/目标的命中结果按稳定来源记录，事件重发不得重掷。怪物不同，判定分别进行。

流血已经成功附着后，各跳不再额外掷一次命中骰；仍每跳独立暴击、预算按原释放快照结算，离场/死亡等既有清理规则生效。这个命中阶段建议现已获用户确认，不能从“逐跳独立暴击”自行推导每跳也要独立闪避。

## 候选B：同一次施放对同一个敌人只判一次命中

对该目标第一次几何有效接触时判定，失败则该次施放后续所有段都不能命中这个目标；成功后后续段仍须各自通过几何/目标状态检查，不能隔空补齐。不同目标各自判定，不能一次命中骰让全场敌人同成同败。

## 数值与手感

假设每次命中机会95%，四段等权且都几何接触：两者期望直接伤害都是95，但：

| 指标 | 每段分别判定 | 整招对该目标一次 |
| --- | --- | --- |
| 四段全空概率 | 0.000625% | 5% |
| 四段全中概率 | 81.450625% | 95% |
| 直接伤害方差 | 118.75 | 475 |

前者更常出现部分命中，整体伤害更平稳；后者更常整招全中，也更容易把已经打进范围的大招整招判空。它们不改变几何躲开就打不中的规则，只影响命中/闪避属性的随机层。流血只分配有效份额，因此整招判空也没有流血。

命中概率95%仅为对照输入，不是装备命中率已定稿。暴击上限100%、急速上限2倍等已确认规则不受本项影响。

建议A，和现有多段/有效命中份额的规则衔接，也减少完整施法无伤害的概率；既然它改变大招手感和命中属性波动，现已获用户选择，不采用整招对同一目标一次判定。每跳DOT不额外判命中作为同一候选包一并审阅。选择后再定基础命中/敌方闪避曲线，继续重跑房间与蓝耗，不先推翻旧装备命中词条。

检查通过：概率质量和为1、期望相同、分段方差与独立事件公式一致；没有业务实现或实机手感证据。

## 本轮确认

2026-10-20用户确认命中候选1：每个敌人、每个几何有效伤害段分别判定命中；某段被闪避不影响其他段。只有命中段造成直接伤害、累计倒地并施加该段流血份额；流血附着后各跳不再额外判命中，只按既定规则独立判暴击。空间未接触不靠命中属性补中，段/目标重发不得重新抽命中。
