# E02a：身份与确定文档事务探针计划

2026-10-22。仅准备可执行验证设计，未安装SDK、配置凭证、登录环境或创建/调用云资源。依据[平台合同](../backend/platform-adapter-baseline-v1.md)、[身份合同](../backend/identity-adapter-proposal-v1.md)、[故事前置](../stories/warrior-loop/enablers.md#e02-隔离平台适配验证)。版本候选沿当前合同，不将其当最新查询或已经兼容的事实。

## 当前可复用能力

E01已提供严格公开v2协议、真实摘要的战士测试release、Node24.19.0/TS5.8.2本地检查与消费者。backend当前无SDK依赖、锁文件或云组合根，只有旧v1应用/MemoryStore。没有因浏览器可访问动作原型就取得正式账号权限。ST01任务图单独待确认，实施后可为本探针提供真实登录应用，不能先搭固定成功函数替代它。

## 探针与可判定出口

| 编号 | 最小实际操作 | 必须保留的证据 | 失败出口 |
| --- | --- | --- | --- |
| P01 包与runtime | 在获授权隔离环境加载锁定SDK及传递依赖，导入后打印精确runtime和包完整性 | SDK/lock摘要、冷/热启动、区域实际runtime；业务日志无秘密 | 包不兼容则停止适配，不自动升级或回退另一SDK |
| P02 可信小游戏调用 | Cocos微信小游戏原生callFunction调用只读身份探针，Adapter读取平台上下文并验证策略 | 同AppID与环境判断、可复现匿名化trace；原始subject只在受控服务端，不返回秘密 | 缺上下文/跨AppID/环境/调用来源不匹配在任何资产事务前拒绝 |
| P03 不可信入口 | 使用缺上下文、请求体伪造身份、HTTP/控制台等非允许来源调用相同玩家入口 | 明确拒绝及数据未变化；没有自动降级匿名入口 | 不能证明来源可信则关闭正式入口 |
| P04 确定键事务 | 两个并发请求竞争同identityLink/账号版本，使用真实SDK事务建立隔离探针记录 | 成功/冲突/重试次数，唯一键最终状态与完整读写集合 | 不拆分事务绕过冲突，不假定未验证的索引唯一性 |
| P05 逐写故障 | 在初始化探针各写点及commit之前触发可控故障 | 每一中止路径全回滚、候选键未被半初始化，attempt按实际调用计数 | 发现半写则阻断登录适配 |
| P06 提交丢响应 | 实际commit后由隔离传输截断响应，沿同原键查询/重试 | 一份原结果、没有第二次初始化或增epoch；notFound不等于永不提交 | 不把超时映射为确定业务失败或另开意图补发 |
| P07 当前会话栅栏 | 两张相同baseEpoch票据竞争及旧会话写与接管竞争 | 一个有效代次、原回执历史状态、先提交结果保留 | 旧会话可写或历史回执重新激活则阻断 |

P02/P03必须由实际微信小游戏产物与已验证平台上下文执行；本地伪造对象或SDK源码阅读只形成合同证据。身份探针不能直接初始化钱包。P04～P07仅针对经授权的隔离、可重建测试数据；没有自动清空生产集合或账号资产的脚本。

## 同一份证据的最小字段

记录代码/构建/SDK/lock/配置摘要、环境匿名标签、AppID匹配结果、测试用例ID、请求原意图摘要、预期/实际、服务端时间、冷/热、冲突与重试、逐调用类型/次数、UTF-8字节及耗时。记录数据状态时仅裁剪隔离探针需要的版本与来源，不保存平台令牌、session_key、AppSecret、完整私有检查点或私有随机流。

唯一键读写不是SDK调用次数；显式commit、额外读取、重试均计入。不得拿E01测试条数、旧内存49项或逻辑R/W设计量替代实际平台结果。当前最大终局含持有汇总R44/W33=77只是后续E02b起点，本探针不宣称最大预算已经通过。

## 执行前仍缺的具体条件

需要用户明确授权精确SDK依赖安装及隔离环境操作，并指定/确认目标测试环境；还需核验当前合同候选wx-server-sdk4.0.2与实际可用runtime。当前本地Node24.19.0不是云Node24.11已可用的证明。未取得这些条件前，本计划状态保持platform-gap，不开匿名H5正式资产接口，也不执行远程探针。

ST01本地事务及调用方可先按其确认任务图实现；E02a通过后再将同一应用接入真实Adapter。完整最大CP/8怪/强化损毁/持有索引、成本及备份恢复属于E02b和后续故事fixture，不由此最小探针冒充完成。
