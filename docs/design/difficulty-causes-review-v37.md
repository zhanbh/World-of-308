# 出招截断、群体命中与反应延迟诊断 v37

日期：2026-10-21。接[v36](difficulty-pressure-review-v36.md)。**确认存在较多伤害节点前的出招取消，但不能把难度不递进归因于单一因素，尚未完成难度验收。**

## 试验口径

两组各96次：普通/冒险/勇士/王者同血量诊断，各24次；两策略×6种子×10/14级。所有Boss生命0.20、同一套实际获取装备输入、XP0/当前药各8。第二组仅增加0.20秒危险范围决策延迟。不是王者90/120秒的正式节奏配置，也不是连续供给经济路径。

危险范围仍按旧模型在敌招开始0.2秒后纳入观察；新增延迟从危险集合被模型识别后算起，集合发生变化会重新计算等待。它不是敌招总前摇，也不是测得的人类反应时间；只影响精英/Boss危险范围规避决策，不给无预警小怪增加提示，不改变攻击动作本身。该简化在同时多危险变化时有局限，不能直接用作游戏AI/玩家输入实现。

## 结论

1. 零额外延迟时，普通约39.33次出招中19.38次在待执行节点阶段被控制取消、1.50次被击杀取消；王者同HP约44.62次中22.71次控制取消、1.83次击杀取消。出招增加不能等价于有效伤害压力增加。
2. 零延迟多目标段比例从普通19.09%升至王者同HP20.88%，是快速聚集更容易被范围处理的辅助证据，差异较小，不能证明它是唯一/主要原因；尚缺各技能、各怪物类型和空间密度分层统计。
3. 增加0.20秒决策延迟后，各组前六房平均掉血提高，但仍未形成普通<冒险<勇士<王者稳定递进。排除“只因玩家零延迟，所以一改延迟就自动合理”的简单解释；没有证明所有玩家或所有延迟都不递进。
4. 怪物多次受控与清招是当前规则/节点/模板组合的结果，不据此擅自给全部高难度怪添加霸体或免控。应按已确认组合模式，把具体怪物、技能是否可中断、站位职责分别配置；保留玩家打断和范围处理的价值，不能为抬难度削掉核心反馈。

## 下一步按证据推进

- 给出分怪物/分技能的起手到伤害执行漏斗，区分普通受击、强制击倒、死亡截断；核对单纯受伤不必然中断与具体模板节点的配置边界，避免模型默认清招误当正式规则。
- 分析远程退让是否实际保留输出窗口、近战分侧是否真的形成夹击，而非只有移动；先比较策略效果，不用任意增伤遮盖问题。
- 延迟模型后续应按每个危险的首次可感知时点建时钟，保留已观察危险的反应进度；本轮集合时钟只作敏感性证据，不进入正式实现。
- 扩展到非王者其他等级/真实剩余药量/第二副本和猎人后，才验收难度经济与整体成长。普通480次一分钟结果是旧已验证范围内证据，不将本轮诊断当全部MVP完成。
