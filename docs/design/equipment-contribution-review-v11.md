# 装备共同增益分层试算 v11

2026-10-20。承接[首副本接入v10](first-dungeon-sync-review-v10.md)，仅设计模型，不修改正式装备或战斗配置。

## 比较方法

运行 `python3 -B docs/design/analysis/equipment_contribution_trial.py`。1/5/10/15级，每级6种配装，各60个种子，共1440条路径。分别是仅初始/保底武器、仅武器升蓝、保底武器+五防具、蓝武器+五防具、保底武器+其余七槽、全13槽蓝装。每次比较使用同等级、同装等及同武器基础AP，品质变化只改变已有词条。没有把“更高装等武器”的收益混入品质升级。

蓝装是敏感性配装，不保证该阶段掉齐；1/5级全套只用于查曲线。其余七槽包含三首饰、三特殊与主动饰品，未施放饰品buff，无紫装套装。混装按每件实际品质计修理费，只对已穿戴耐久槽扣损耗。保底武器混装与原starter模型、全蓝混装与原blue模型均做相等检查。

输出倍率使用独立60秒站桩模型；有效生命=HP×(1+护甲/100)，只对本模型物理减伤有效，不代表包含回复/魔法/穿透后的综合生存力。遭遇时长沿v10；种子一致不保证每次敌人攻击抽样完全配对。

## 武器失效对照

为检查“没有武器其他装备能否替代”，在全蓝配装保留其他槽，禁用武器属性，单独比较60秒站桩输出。此为途中武器破损后的静态场景，不允许以0耐久创建新挑战，也未把已经释放的快照追溯变弱。

## 判断与后续

- 当前模型符合“武器提供AP基础，其他装备共同增益”的方向；仍有武器失效残余伤害，不制造绝对无法击杀。五件防具是组合，不能将五件的总收益直接与一件武器相比后判定单件权重失衡。
- 同装等武器升蓝10级约+23%站桩输出；五防具约+40%，同时显著提升物理有效生命。品质升级和更高装等武器要分开评估，不能用此表推断换下一档武器只提升23%。
- 全蓝相对基线有效生命倍率从1级2.03升至15级3.27，而输出倍率从1.47升至1.99。当前少用药的重要原因是防御与HP共同增长，加上缩短敌人存活时间；暂不调整防具护甲、怪物攻击或药价。
- 本轮保留v10所有空间/招式局限。下一步优先把输出时间拆成攻击、移动对齐、机制躲避及房间过渡，再接完整Boss/精英节点；否则直接把目标4分钟与当前约2–3分钟的差值全补成怪物HP，会让差装备承受更长磨血。
- 经验曲线、升级回满的影响、强化材料实际供给和金币长期回收仍未完成；这些不能由本轮配装对照推定已平衡。

验证：混装两端等价、保底武器遭遇等价、28怪数量与固定种子输出通过；旧模型脚本回归另行执行。所有倍率/耗时是候选公式的离线结果，不是实机验收。

后续回归修正：属性聚合按稳定槽位顺序求和，避免集合遍历顺序引发浮点末位差异，导致全蓝/混装等价检查在不同进程偶发失败。补PYTHONHASHSEED=0/1/42/123四组独立进程输出完全一致检查；不改变装备预算或规则。
