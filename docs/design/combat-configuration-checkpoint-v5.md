## 2. 逐段与控制对照

复算：`python3 docs/design/analysis/control_timing_trial.py`。

普攻按现有三段命中时点0.112/0.4163636364/0.7433333333秒，伤害权重0.9/1/1.1再归一化；职业技能时点取现有原型 `WarriorSkillsModel.ts`：十字0.29/0.34、崩山0.24/0.48/0.68、拔刀0.44、大崩0.88/1/1.2/1.4，均按候选急速缩时。技能权重沿数值候选，十字50/50、崩山25/30/45、拔刀100、大崩各25；未声明原型伤害数值已迁移。

每段只分得整招直接和流血的对应份额，仅命中活目标施加，不提前给整招流血。普攻仍以一整套动作占用开始，三段锁主目标，未实现目标死亡后转移到其他怪；这会低估灵活转火能力。空间最多命中两目标仍是几何假设。

倒地候选：小怪35%最大HP、精英20%，倒地0.8秒/起身0.24秒；精英额外起身保护0.6秒。非DOT直接伤害累计，起身清零，倒地和保护中不触发新倒地；击杀优先。崩山末段/大崩首段特殊击倒绕过阈值但不绕过目标免疫。当前Boss始终免疫仅作保守对照，不代表首副本最终机制已确定。短僵直仅对近战/远程小怪候选0.28秒。

## 3. 预警/反应交接

现有候选前摇：投石1.2秒、冲锋1.2秒、精英旋风1.1秒、Boss下砸1秒/践踏1.3秒/P2三连0.9秒；旧稿泛称全部至少1.1秒与Boss自身配置矛盾。按招式配置明确前摇，不保留与表内数值冲突的全局断言。

预警开始→攻击准备→可打断/霸体检查→命中→恢复，必须是可检查的状态节点。倒地后清理已取消预警，无法继续命中；已发射投射物是否保留按其独立生命周期处理，不能把“被击倒”解释为全场所有旧效果消失。弱点窗口采用独立开始/结束时刻，禁止每个受击段重开一轮窗口。

本轮没有真实X/Y坐标、移速/走出预警计算或轨迹，仍以命中概率情景替代躲避。不能把上述对照称为预警可读性、真机反应时间或几何碰撞验收。固定Boss窗口方案需用户选择后才能进入这部分模型，避免先做成既成规则。

## 4. 死亡、复活和连接：12个顺序参考场景

复算：`python3 docs/design/analysis/challenge_lifecycle_trial.py`。

| 已核对场景 | 设计预期 |
| --- | --- |
| 武器途中归零及重复房间磨损 | 不暂停、不额外死亡，重复不扣两次 |
| 付费复活响应重试 | 同请求只扣一枚，满血蓝，仅清职业CD，2秒保护 |
| 死亡9秒后残留击杀Boss | 免费满血蓝、通关、小怪完整计击杀，不扣纹章/次数 |

| 活着短暂断线恢复 | 模拟暂停，恢复不清CD，不重新收费 |
| 恢复窗口超时回城 | 未完成挑战失败，回城清全部CD |
| 通关长期拾取及断线超时 | 在线无强制返回；超时仅结束拾取，不撤销成功 |

| 无纹章 | 不替扣金币/点券 |

这是设计参考模型，不是现有后端或数据库的验收；没有并发、宕机恢复或真实持久化证明。请求结果去重仅示范内存顺序回放，不能替代服务端原子资产事务。截止时刻同值时先到期再接受新命令为协议候选；已提交付费复活与后续Boss死亡的退款政策不由该模型擅自定义。

死亡继续模拟与断线暂停模拟分别处理；死亡/恢复窗口都用权威墙钟。顺序模型仅检查CD不清零和城镇清零，具体技能/药品计时器在暂停中的自然流逝策略不能从简化绝对时间字段推定。

## 5. 两项玩法边界（本轮用户已确认）

复算：`python3 docs/design/analysis/snapshot_boundary_trial.py`。已有流血伤害预算在释放时锁定不重问，以下只补未确认的属性/机制。

### A. 暴击和急速是否也随本次施放锁定

推荐每次施放锁定本次暴击率/暴伤与急速；每段/每跳仍独立掷暴击，不沿用触发段暴击结果。动作速度、流血节奏与本次CD按释放时确定，后续buff变化影响新施放，不重排已开始的技能。这样短buff结束/武器破损不会让已经开始的技能忽快忽慢，也便于复盘。

反例：一份100基础流血、5跳，施放时暴击40%，两跳后buff结束降至20%，暴伤1.5。全快照期望120；暴击率逐跳实时读取期望114。施放时急速倍率1.5、两跳后降至1：全快照末跳3.333秒，动态改间隔末跳4.333秒。两者均可能实现，不能以“预算已锁”推定用户选择了其中一个。示例只比较概率期望，没有让伤害预算先暴击一次再暴击。

### B. 首个Boss的控制窗口

推荐平时免疫普通硬直/倒地；只在机制触发的虚弱窗口允许累计直接伤害或特殊击倒使其倒地，窗口结束恢复免疫。普通怪/精英仍沿原控制规则。窗口外崩山/大崩正常造成伤害，不强制控制Boss；复活纯击飞遵循同一免疫，玩家保护不取消。

用户已选择窗口内可击倒方案，不采用全程控制免疫。建议虚弱窗口先保留旧稿3秒/承伤+20%作候选，倒地不延长窗口；模拟反例验证窗口外强制击倒无效、DOT不累计、窗口内直伤8+12达到20阈值只倒一次、后续强制击倒不续窗口。阈值20仅反例单位，不是正式20点或20%配置。
