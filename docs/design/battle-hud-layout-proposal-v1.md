# 战斗HUD布局提案 v1

日期：2026-10-20。状态：用户已确认布局方向；具体尺寸与位置待尺寸稿验证，尚未实现或实机验收。依据[UI规格](ui-layout-specification-v1.md)、[动作原型](../action-prototype.md)。

## 已定规则

左侧固定底座摇杆；右侧普攻与四职业技能，无额外跳跃或闪避按钮。主动饰品是独立装备道具，不占三个消耗品快捷格。血药共享10秒冷却、蓝药另组共享10秒；满值拒绝不消耗。既有UI稿中的动态摇杆与每格独立药品冷却已纠正。

## 已确认方向：四技能沿普攻左上方排弧，饰品独立

以960×540设计坐标讨论：左下摇杆，右下84直径普攻，四技能按72直径沿普攻左上方扇形分布；饰品设独立按钮，放技能组上方偏右，视觉和标签与职业技能区分。三个药品快捷格位于底部中间偏右、技能组左侧。普攻、四技能、饰品均可直接点击，不用展开菜单或切页。

用户确认右下普攻、四技能沿左上方排弧、饰品独立上方及药品位于技能组左侧，全部直接可点。图示排列方向已确认，不是已经验收的坐标。四技能排列、手指可达距离及饰品是否易误触须用实际尺寸稿验证；不得仅把54改为72就宣称全部控件已放得下。

## 后续尺寸稿约束

- 上述尺寸为设计坐标，不能直接称设备物理像素。安全区读取设备实际遮挡并换算到UI坐标，再留操作间距；左右24、底16只能作为候选设计留白，不替代真实安全区。
- 技能有效触控区域至少72×72，药格至少48×48；相邻热区不重叠，不以扩大透明区域侵占其他按钮。
- 饰品显示装备图标及独立冷却；不套用职业技能急速或套装减冷却，不表现成解控/护盾。未装备、冷却中及当前状态不可用须可区分。
- 冷却、蓝量不足、未解锁用遮罩加文字/图标区分；不只依赖颜色。蓝量不足时不触发技能取消普攻。
- 左手移动与右手普攻/技能可同时操作；各触点归属独立，抬起右手不清除左侧摇杆输入。
- 本期不引入未经确认的普通手动暂停按钮；断网/后台的暂停恢复沿挑战规则，不能以UI草图创造暂停能力。

## 验收证据要求

补完整尺寸稿，核对全部热区和安全区；Note20 Ultra横屏双手握持验证移动中普攻、普攻取消接技能、饰品与药品触达，以及横屏浏览器/微信遮挡。当前只审文档，不能把历史动作原型通过等同完整HUD通过。
