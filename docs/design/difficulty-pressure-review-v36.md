# 难度压力观测与因素拆分 v35/v36

日期：2026-10-21。接[v34](difficulty-behavior-review-v34.md)。本轮结论：**难度递进尚未通过，不能仅因出招更多或Boss时长达标就将难度参数定稿。** 全部为docs下离线分析，未修改游戏业务/发布配置。

## 比较方法

v35共96次：普通基线、冒险/勇士/王者候选，各24次。所有组Boss生命统一0.20，消除上一轮王者0.50生命带来的时长混杂；这里不是王者90/120秒节奏的重新调参。v36共72次：重复同24次普通基线，加“仅提高出招频率/特殊并发”和“原速度分侧接近/后撤”两组。共168次试算，其中普通24次为重复验证，不当作独立新样本。

两轮均沿v31的10/14级实际获取配装、6种子×2策略，入场XP0/当前档药各8，敌人伤害/经验/掉率不变。固定遭遇种子在动作分化后不保证每一次命中随机抽样对应相同；这是完整策略对照，不是逐击相同随机数的因果证明。

新增观测包括：实际起手数、执行到的伤害节点、受保护过滤后的受伤次数/实际掉血、主动躲避移动时间、怪物累计追击/分侧接近/后撤时间。伤害节点计数不等于命中机会（投射物到达、冲撞及持续段口径不同），不以节点/受伤次数直接计算命中率。怪物移动时间是多个怪的累计秒，可超过房间实时时长。

## 结论

1. 分侧和后撤实际触发，不是只有profile名称改变。但冒险/勇士/王者同血量诊断前六房平均掉血都低于普通；与同种子/等级/策略基线成对比较，掉血更高的分别仅9/24、5/24、4/24。难度不具稳定递进证据。
2. 仅提高频率/并发后，平均出招从39.33次增至46.13次，平均掉血从634.52降至570.28；不能用更多出招数代替有效操作压力。原速度分侧/后撤的平均掉血610.87更接近基线，但仍非明显更难。
3. 快速聚拢更易被范围攻击清除，是符合当前现象的解释假设，尚无逐段群体命中/聚集距离统计证明；出招被控制/击杀截断、脚本即时规避、随机序列分化也可能影响结果。不能将此假设写成已经证实的唯一原因。
4. 当前脚本玩家对危险范围有即时几何判断，实际触屏反应、注意力和攻击取消成本尚未校准。下一步先增加玩家受击/输出窗口与怪物被控/被击杀截断、群体命中分布观测，再验证站位策略；不同反应延迟可作敏感性，不直接代入人类反应结论。
5. 不通过增伤硬抬这轮掉血，也不改变已经确认的预警规则、穿怪或施招朝向锁定。普通一分钟与王者90/120秒节奏结论保留为各自试验条件下证据；完整难度/经济、第二副本/猎人及真机尚未验收。
