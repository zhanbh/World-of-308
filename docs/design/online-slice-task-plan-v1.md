# D06 最小在线切片开发任务草案 v1

2026-10-19。设计交接，不改业务代码、不创建/部署云环境。总体依赖[实现差异](../implementation-gaps-2026-10-19.md)、[D06](../wayfinder/mvp-design/issues/06-online-slice.md)。按以下顺序形成可验收切片；配置未定稿可用明确版本的测试数据，不将试算值默认发布。

| 顺序/任务 | 工作范围 | 依赖与验收出口 |
| --- | --- | --- |
| T01 规则与配置版本基线 | 将最新决定映射到领域、协议、测试；列出旧规则替换清单和配置版本 | 20格背包、扩容定价、最新CD矩阵、流血/倒地、耐久7槽、破损继续挑战均有来源；旧49测试逐项区分沿用/替换/新增 |
| T02 属性与伤害纯函数 | 职业、技能、怪物参数独立；聚合主属性/武器/强化/副属性/套装；实例失效与修复重算 | 依赖D01/D02；禁止重复加成；完成初始/绿保底/30级完整及破损对照。流血预算与分段守恒，DOT不计倒地，饰品CD固定；未定快照/上限不暗中锁死 |
| T03 本地资产事务与迁移 | 实例耐久、20格/扩容、邮件、待领奖、金币差额流水、幂等命令 | 旧数据缺字段按版本迁移，不作0耐久、不重复补满；金币不足拒绝；满包不丢资产；并发出售/修理/强化只接受合法版本；重复请求返回原结果 |
| T04 挑战生命周期联接 | 入场体力、0耐久武器入口、磨损事件、掉落/终局、复活/退出/断线 | 依赖T02/T03；武器途中归零能攻击/换房，怪物不停，下一新挑战被拦截；末房归零保留通关奖励；房间/死亡磨损各自去重；boss残留击杀免费复活与三次付费复活限额沿原规则 |
| T05 城镇最小操作闭环 | 背包穿戴、领奖、NPC单件修满/穿戴全修、失败提示 | 依赖T03/T04与D05；报价变化重算、全修不足整批拒绝；响应丢失可查原结果；武器全损且无资产显示真实限制，不添加未授权救济机制 |
| T06 持久化与真实身份适配 | 账号/角色权限、数据库事务、写入栅栏/租约、幂等结果持久化 | 依赖本地契约验收及明确的目标环境；重启不丢账/幂等；旧会话不可写新角色；以平台实际事务能力验证，不拿MemoryStore测试充数 |
| T07 Cocos/微信接入与内测 | 登录→创角→入场→战斗→领奖→换装/修理→重新登录恢复 | 依赖T06；真机记录断网10秒恢复/超时回城、杀进程、重复领奖、满包、破损继续战斗；服务器存储与客户端表现一致；内测配置/数据隔离 |

T01可先做规格映射；T02涉及武器占比、HP/药品与技能消耗的联调。尚待审阅的快照/完整属性、价格和内容配置按D01–D05收口，不为拆任务把整个设计票提前标resolved。真实环境的创建、凭证及部署另以明确目标环境执行。

每个实现任务交付：变更文件/对应规则、可重跑验证命令、结果和未覆盖项。记录本地模拟、持久化适配测试、微信真机三个证据层，不以单层通过宣称在线闭环完成。当前仅完成任务拆分，没有上述实现验收。

2026-10-20同步：公司端已新增[实现切片v1](implementation-slices-v1.md)及后台v2契约；本稿是较早的T系列思路，不替代S系列规划。新规则字段/模型作为补充交接，不重复声称D06未产出工程方案。
