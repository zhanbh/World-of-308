## 与控制试验的区别

本轮每局连续保留真实XP余量、穿戴/耐久、候选随机掉落、钱包和药品库存，沿v27城镇修理/出售/购买策略、每局30秒城镇候选；没有每局免费8瓶。v29重置经验与供药条件下的10/14级48次达标，不能替代本轮所有等级的结果。路径到15级即停止，入场覆盖1至14，尚未覆盖以15级回刷。

## 后续方向

- 超时出现在4/8/9/13级，不能只校准整5级检查点。下一轮应比较这些等级的输出/装备换档和Boss成长，再验证略低HP或分档曲线；0.25只是可行起点，不直接作为全难度发布值。
- v27原模型1至15级约93～98分钟，本轮约53～55分钟。减少主要来自Boss战缩短；本轮不改经验、不额外追加刷本次数。仍需第二副本及15至30级验证，不能线性外推宣布3～5小时整体目标达成或失败。
- 初始赠药已覆盖多数正常使用，穿插策略样本实际购买支出为0。符合普通升级不应频繁耗蓝的方向，但不证明所有补给/金币回收合理；强化材料支出、扩容、其他难度等未纳入，期末金币偏多需整体经济联调。
- 冒险、勇士、王者的行为与收益并未模拟，不能套普通结果宣布达标；非王者仍遵循一分钟校准方向，王者时长未定。猎人、第二/特殊副本、真机操作与权威服务验证均未完成。
