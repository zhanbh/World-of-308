# 会话内跨装备强化记忆 v5（方向已确认，分组与曲线待审）

2026-10-19。用户认可垫装备能给主装备提供成功率加成，并明确记忆只在当前角色会话内有效，切换角色或下线重登即消失。不是DNF实现事实的推断，而是本项目主动设计的机制。既定+13起损毁、金币翻倍、高强化极稀有定位仍保留。

## 1. 已确认及作用范围

- 失败历史可以跨装备影响下一次强化，不能继续按不读历史的独立抽样作为当前机制。
- 记忆属于当前角色的本次游玩会话，不跨角色继承；切走再切回来也不能恢复旧记忆。
- 下线后重新登录开启新会话，计数从零开始，不提供恢复旧计数入口。
- 沿此前用户认可的失败补偿机制，成功后清零、失败后累积。哪些目标等级/槽位共用计数、具体每次加成和上限仍需审阅，不把说明示例30%→35%当正式配置。
- 不在玩家界面展示成功概率的既有规则保留，不擅自新增概率条/保底倒计数或显示隐藏计数。

连续抽样仍可使用独立随机数，但每次判定阈值取决于当前失败状态，因此结果序列不是原来的无记忆模型。它是主动的失败补偿，不是方差本身或“均值回归自动补偿”。

## 2. 会话事件矩阵

| 事件 | 失败记忆处理 |
| --- | --- |
| 同角色同会话更换待强化装备 | 保留，跨装备可用 |
| 强化失败且操作真正提交 | 对应计数仅增加一次 |
| 强化成功且操作真正提交 | 对应计数清零 |
| 金币/材料不足、非法参数或尚未执行 | 不修改计数 |
| 请求响应丢失、重复点击重试 | 查询或返回原结果，不再次抽样、不再次增加/清空 |
| 关闭强化界面、修理、回城或进出副本 | 不是切角色/重登，不据此清零 |
| 短断线恢复原角色会话、同会话认证令牌刷新 | 保留；网络请求恢复不冒充重新登录 |
| 实际切换角色 | 关闭旧角色游玩会话并清零，新角色从零开始 |
| 切走又切回原角色 | 新角色游玩会话，从零开始 |
| 显式下线、客户端重启后重登、新设备接管后登录 | 新会话从零开始 |
| 服务进程重启但玩家会话仍合法有效 | 不能仅因进程换了而悄悄丢失已提交计数；恢复当前有效状态 |

挑战的10秒恢复截止和角色会话有效期不是同一个概念。挑战超时回城本身不等于切角色或重新登录；只有实际角色游玩会话结束才清零。服务端应按会话状态识别，而不是看到登录SDK刷新令牌就误判重登。

## 3. 服务端交接（未实施）

当前身份协议已有account sessionId/epoch；还需要角色游玩代次rolePlayEpoch，因为同一个账号会话内切角色也必须失效旧记忆。角色切换和下线使旧代次不可再写，新代次初始化零计数；旧角色晚到的强化请求必须被版本/会话栅栏拒绝，不能污染新角色记忆。

“会话内有效”不是“只放客户端或单个服务进程内存”：服务端保存当前会话计数及版本，和金币、材料、装备、纪念品及幂等结果在同一原子边界提交，至少具备宕机重试后不多扣/不重抽的能力。退出后旧记忆不再参与任何新判定；审计/请求结果可保留用于查账，但不恢复旧加成。这不创建云资源，也没有声称实际数据库事务已验证。

每次合法强化固定：当前会话/角色代次、规则版本、目标等级/槽位、计数前值、幸运/纪念品输入、实际计算概率、随机结果、计数后值和资产差额。内部概率可用于审计，不能返回玩家界面。更换配置不能重算已提交结果；未提交或拒绝的动作不增加“垫子次数”。

旧会话操作的持久结果仍可走operation.get查询，不允许把查询当新会话重新执行强化。结果查询与新会话计数初始化分别处理。客户端时间、退出请求是否成功到达，都不能作为复用旧记忆的凭证。

## 4. 候选加成曲线与垫装成本

复算：`python3 docs/design/analysis/enhancement_memory_trial.py`。候选 `p=min(总上限, 该目标基础率 + min(步长×连续失败, 历史加成上限) + 幸运/纪念品加成)`；本轮先不计幸运/纪念品。总上限95%仅为计算候选，不新增必成保底。

三条曲线：温和每失败+2个百分点/最多+10；中间每次+3/最多+15；较强每次+5/最多+20。它们尚未获确认。若成功清零且始终强化基础率30%的目标，长会话实际平均成功率会分别升至33.30%/34.62%/36.65%，并非仍维持30%。原30%只能称“无历史基础率”，不能同时宣称为含补偿的长期平均。

在已经准备好无限多件指定目标等级垫子的乐观假设下，等待连续3次失败的期望如下：

| 曲线 | 连败3次后主装备基础30%变为 | 用+1垫子达到3连败：期望尝试次数 | 仅尝试金币 | 用+13垫子达到3连败：期望尝试次数 | 仅尝试金币 |
| --- | --- | --- | --- | --- | --- |
| 每次+2，封顶+10 | 36% | 214.58 | 21,458.33 | 6.93 | 554,112.55 |
| 每次+3，封顶+15 | 39% | 259.24 | 25,924.37 | 7.23 | 578,091.68 |
| 每次+5，封顶+20 | 45% | 410.00 | 41,000.00 | 7.89 | 631,501.83 |

+1垫子基础率80%，+13垫子基础率30%；费用只用30档武器候选+1每次100、+13每次80000。低装等和耳环可能更便宜，尚无全表价格，不能宣称上表已排除所有低成本路径。成功后的垫子不能继续假装仍为同一目标等级，需要另换准备好的装备；高段失败则会损毁并需补充。材料、垫子取得/预强化与主装备本身费用全部未计，所以不是完整策略的收益结论。

较强曲线下，用+1垫子凑5连败的期望约164420次，单是尝试金币约1644万。原因是连败加成也作用于垫子本身，使下一次失败越来越难；并非“垫5件就必然得到5连败”。不通过暗中让垃圾装备更容易失败去操纵结果。

计算使用带计数状态的更新过程：每次失败进入下一状态，成功回0；无限会话下到达指定连败长度的期望为一次“成功或达标”周期长度除达标概率。有限会话可能来不及达标，切角色/重登还会清零；不能把无限期望当一次会话保证。

## 5. 现在必须选择的分组方式

A. **角色会话全局共用**：同一角色这次会话中，各强化目标等级、武器/耳环共用计数。便宜+1失败也能为主装备冲+13甚至+20提供加成；任何级别的成功都清空公共计数。垫装最自由，但需按全经济空间重算高强化可达性。

B. **同目标强化等级内共用（建议候选）**：以角色会话＋目标强化级别分组，不按装备实例隔离。同目标+13的垃圾装备与主装备共享；+1失败不加成+13。不同目标组分别累积/清零，切角色/重登所有组一起清零。武器/耳环是否再分池先不额外限制，比较同目标两槽价差再决定。这个选择尚未获用户确认，不能擅自把它写成正式防套利规则。

A/B都会允许跨装备垫装，也都满足会话清零；区别在低阶失败能否转移到高阶成功率。须先选这个玩法边界，才能有意义地比较完整成本和最终加成曲线。上表仅说明量级，不是在推荐玩家一定要垫装；直接强化仍必须是可用选择。

## 6. 检查与后续

7项参考检查通过：失败重试只更新一次、垫子到主装备继承并成功清零、原会话短恢复保留、角色切走切回不恢复且旧写拒绝、重登清加成但旧操作可审计不重抽、同目标分组反例、概率封顶与无记忆特例公式核对。这是内存参考/数学验证，未实现正式资产事务。

原[无记忆重建风险v4](enhancement-rebuild-risk-v4.md)保留作独立基线，566亿金币不得再称为新会话补偿系统的当前预测。分组确定后，联合幸运/纪念品、低装等/耳环成本、会话时长与断线重登重算；不擅自改变+13损毁、费用翻倍和极稀有定位。

## 2026-10-20最新方向（覆盖A/B二选一）

2026-10-20用户纠正分组：不采用所有强化等级等效共用，也不简单限定只有完全相同目标等级才有效；强化程度越接近，历史失败补偿越充分，差距越大效果越弱。仍然是随机判定，不保证成功，也允许连续成功。记忆仍只属于当前角色本次会话，切角色/下线重登清零。距离度量、衰减曲线、补偿上限和成功时清除范围需方案细化。

候选以本次尝试的目标强化等级作为距离，失败+12冲+13与下一件+12冲+13距离0；下一件冲+14距离1，不拿装备等级/品质当强化级别距离。候选高斯相似权重 `w=exp(−0.5×(等级差/σ)²)` 仅用于平滑衰减；最终强化仍为成功/失败的随机判定，不是正态分布直接产出成败。σ、步长和上限未确认。

复算 `python3 docs/design/analysis/enhancement_similarity_trial.py`：σ=1、每次失败基础加成3个百分点、最多15个百分点的纯示例中，连续3次同目标失败给同目标+9个百分点，差1级约+5.46、差2级+1.22、差3级+0.10。远差只提供极小增益，不视为所有等级等效共享。成功清全部历史还是只清相近历史，本轮不擅自确定；候选连成算例暂按成功后全清来比较。

连续n次成功的一般概率为条件概率乘积，只有每步条件概率相同为p才是p^n。存在补偿、成功清除、目标等级变化时，各步p可能不同；允许连成不等于独立同概率。等级相近的具体曲线与叠加记忆对高强化成本的影响仍待重算，旧566亿只是无记忆历史基线。

后续：[等级相似记忆与成功消耗v6](enhancement-similarity-consumption-v6.md)替代本稿A/B分组讨论，新增单来源补偿上限以防远阶失败海量累积绕过等级衰减；成功后处理仍待选择。

## 2026-10-20成功消耗最新确认

2026-10-20用户已选择成功按相似程度消耗失败记忆：同级来源清空，邻级来源消耗较多，远级来源消耗较少；不采用任何成功都清空全部历史。其他来源有余量时，成功后的下一次仍可能获得加成。切角色/下线重登仍清全部。具体相似函数、步长和上限为待联调候选，不因本次机制确认自动锁定。
