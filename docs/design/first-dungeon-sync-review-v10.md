## 本轮范围

新增独立脚本 `python3 -B docs/design/analysis/first_dungeon_sync_trial.py`，旧27怪脚本及报告保持可复算。沿最新首副本基础27怪，R1–R6额外加入1只紫名怪，同房同时出场；每组种子0–59，每个紫名房间各10次。紫名暂用普通近战模板、房间均匀分配，仅是候选，不代表已确认模板/抽取权重。紫名双倍经验未进行经验结算，本轮不推断升级速度。

Boss普通状态可控；施招霸体，仍受伤/流血；50%生命待当前招结束切阶段，不重置技能冷却。新增独立12秒冷却吼叫，暂用3秒6跳、每跳0.45旧伤害单位、累计实际伤害达最大生命15%触发一次倒地。倒地仅延迟新动作0.8秒，无额外伤害免疫；未模拟击退位移。其余招式暂合并为2秒施招+2秒恢复的时间代理，第二阶段伤害单位2.5→3。这些全部为敏感性输入，不能替代重槌/连续践踏/冲撞/撞墙虚弱的完整动作模型。

玩家沿当前动画本体时长、既有分段时点、独立命中与物理流血预算；目标护甲固定25、穿透释放锁定，未覆盖防御动态变化。暴击使用期望值。站位仍按最多同时命中两目标，绕后、击退出扇形、群怪攻击协调、精英横扫霸体尚未接入。因此这轮是接入检查，不是最新副本完整验收。

## 发现与下一步

1. 仅初始/保底武器的中位耗时约163–191秒，低于约4分钟待验证目标；不能据此立即加怪血量，模型尚缺真实移动/对齐、技能空间与交互耗时。
2. 全身蓝装对照约108–110秒且本组不需要生命药，提示装备防御和伤害的共同增益较强。应拆成“仅换武器／仅换防具／全套”分层验证，避免把全套收益误归因武器。
3. 吼叫暴露从10%升至60%，5级武器组平均生命药从0.75升至2.03瓶，15级从0.92升至2.08瓶；时长基本不变。它反映当前代理更偏补给压力，缺少真实击退/走位导致的输出损失，不能当作机制强度最终结论。
4. 接下来先拆装备收益，再接入精英横扫、Boss各招式节点与群怪协调；结合房间尺度/移速做移动时间预算，最后校准怪物HP和约4分钟目标。完整经验与强化材料供给仍独立待补。
