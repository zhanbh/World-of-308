## 模型继承边界

v10加入28怪和Boss施招代理；v11/v12扩配装与时间账。它们仍是整局抽象模型。v13–v17逐步补空间、动作与受击，为独立参考。v23首次将首副本这些节点与成长合到同一流程，作为当前联合入口；v10–v12旧模型仍留历史对照，不能把新路线耗时再叠到旧抽象窗口，也不能把各报告样本相加成整局证明。

旧27怪、Boss仅虚弱期可控、旧动作本体等报告保留历史对照；实际Boss规则以平时可控、施招霸体为准。旧“等待用户家中提交数值资料”已过时，资料已同步，现在缺的是联合模型与审阅。
