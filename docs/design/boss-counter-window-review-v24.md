# 技能射程、Boss窗口与HP对照 v24

承接[联合模型v23](spatial-growth-review-v23.md)。复算：`python3 -B docs/design/analysis/boss_counter_window_trial.py`。

## 控制变量

4种等级/配装×4种方案×6种子，共96条参考路径。共同使用固定120Hz、同一出生/紫名候选与数值。

- 贴身策略基线：回到普攻距离才施放技能；避开危险后等待剩余伤害段结束再回近身。
- 安全射程反击：不改任何伤害/血量，利用拔刀142源像素范围和十字飞行段；在已确认安全且不需自身位移的位置可反击，实际每段仍重新检查几何/命中，不提前赠送全招伤害。
- 收招+0.5秒：沿贴身策略，只延长Boss本体收招/撞墙虚弱，不改预警、伤害节点或起手CD。
- Boss HP80%：沿贴身策略，只减少Boss生命20%，不改小怪、奖励、装备或玩家属性。

技能射程反击是脚本操作策略对照，不是给玩家新增功能或强制一种打法。初始原型已经存在这些技能攻击范围，修正的是模型策略。

## 当前判断

1. 初始武器用好射程约229.6秒；贴身策略削Boss血到80%约230.5秒。两者接近，不能据保守策略约301.5秒就断言必须削Boss或加武器攻击。
2. 当前先保留Boss HP与装备公式，采用射程更完整的策略作为后续参考；不把96条路径当概率期望或真人测试，不发布80%血量配置。
3. 收招+0.5秒并不保证整局更快；出招节奏、控制、玩家回位与随机序列都会改变。不能把名义窗口简单换算成线性DPS提升。
4. 仍有两个数值缺口：用好射程后，部分武器组Boss房约139–162秒，仍高于早期合理配装Boss60–120秒的候选目标；低装备的高频技能策略蓝药约3.5–4瓶。整局接近4分钟不等于这些子目标都完成。
5. 全蓝对照Boss约70秒、整局约142秒，是完整装备共同增益效果，不应为了让全蓝也固定4分钟去拉长怪物血量；正常成长和高手/回刷提速要分开校准。

## 下一步
