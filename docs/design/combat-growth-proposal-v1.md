# 战斗数值与成长方案 v1（待审阅）

日期：2026-10-19。关联：[D01设计票](../wayfinder/mvp-design/issues/01-combat-growth.md)。状态：专题审阅中，普攻/技能适用范围及蓝量压力方向已确认；其余公式、系数和预算仍待审阅，未写入正式配置或业务代码。本稿不声称已验证平衡，也不改现有原型手感。

## 1. 已确认的约束

以[核心规则摘要](../wayfinder/core-rules-v2/SUMMARY.md)及[规格数值框架](../spec.md#6-数值框架)为准：1–30级、自动成长、力量增HP/敏捷增暴击/智力增MP且职业主属性增攻击；同类来源先聚合再递减封顶；精通只作用职业技能；急速影响普攻、技能前摇和CD，不提高移速。被动种族暴击为加1个百分点。

战士技能在1/5/10/20级解锁，技能级数为 `1 + floor((角色等级 - 解锁等级)/2)`，未达解锁等级不能使用。每技能级固定增加基础伤害。已有三段普攻1000ms、300ms续接、120ms缓存与普攻取消接技能保留为动作基线；临时四技能CD、蓝耗及HP=3的小怪不能直接升级为正式配置。

普通倒地以目标跨招累计直接伤害为准，起身清零，倒地中伤害不带入下一轮；DOT不累计、不造成控制，但可致死。最新复活/回城/重连冷却矩阵直接继承，不重新提问。

## 2. 推荐的输出与生存目标

先维持既定目标：匹配等级、普通难度、合理装备下小怪约3–5次普攻命中，精英15–30秒，Boss60–120秒；初始白武器可完成首局，不以高强化或消耗纹章为前提。首角色3–5小时有效游玩满级属于校准目标，不能只靠公式声称达成。

2026-10-19用户确认：普攻和技能都可作用于任何怪物，不按普通怪/精英/Boss限定攻击方式；具体空间判定与既定目标免疫规则仍各自生效。正常装备、正常使用技能时蓝量不应大量消耗。同一技能的耗蓝规则不因装备好坏改变；装备不足导致战斗更久、施放次数更多，因此累计消耗更多蓝量，这是正常结果，不增加额外耗蓝惩罚。不能以“精英/Boss必须用技能”或“普通怪只能普攻”作为设计约束，也不固定玩家普攻/技能输出占比。

数值方案据此校准正常打法与低装备高频施法两组场景。先用蓝耗、恢复、技能效率及战斗时长的共同结果体现压力，不擅自增加按装备评分额外扣蓝的机制。使用“攻击单位”预算而不是直接以原型1点伤害定职业数值；最终按D04遭遇数量及D03奖励校准，避免同时独立调HP、攻击和经验。

## 3. 属性与伤害结构提案

公式展开及逐跳算例见[属性汇总与伤害计算草案](combat-formulas-proposal-v1.md)。用户已确认AP为基础攻击数值：职业匹配主属性、武器必带攻强及强化增量参与AP汇总，副属性在后续各自环节生效；流血采用该草案结构，系数仍待校准。

聚合顺序：角色基础/成长 + 装备固定属性 + 强化 + 套装 + 临时增益 → 各属性换算/递减/上限 → 生成战斗属性快照。百分比同类先相加后应用一次；只有明确命名并审阅的独立乘区才能另乘，不能每件装备各自乘算。

建议使用一条有界收益曲线：`f(r; C,K) = C * max(0,r)/(K + max(0,r))`。r是聚合后的有效评级，C是该项收益上限，K是达到半上限所需评级。K随等级或装等基准调整；具体评级系数待装备预算完成，不从现有测试fixture反推。概率统一用0–1，暴击伤害倍率用倍率值，避免百分数与百分点混用。

候选公式：

- `Attack = 职业基础攻击 + 武器攻击 + a × 职业主属性 + 强化攻击 + 固定攻击增益`；a待校准，力量/敏捷不默认跨职业同效转换。
- `HPmax = 职业基础成长HP + b × 力量 + 装备HP`；MP同理由智力转换。基础成长逐级增量应缓慢增加，实际1–30表由预算生成。
- 命中概率建议 `clamp(命中基础率 + 命中收益 - 目标闪避收益, 命中下限, 命中上限)`，空间未命中直接失败，不进入概率判定。命中基础率及上下限待讨论；原型目前确定命中不变。
- 直接伤害建议 `max(0, (固定技能伤害 + Attack × 动作系数) × 职业技能精通倍率 × 暴击倍率 × (1+同类增伤合计) × 护甲倍率)`；普攻固定技能伤害为0，精通倍率为1。特殊效果若例外，须在模板中显式声明。
- `有效护甲 = max(0, 护甲 × (1 - 最终穿透率))`；`护甲倍率 = Karmor/(Karmor + 有效护甲)`，Karmor按攻击方等级取表。相同等级同样护甲下结果应稳定，不出现负护甲放大。
- 暴击率先合并敏捷来源、装备和种族1个百分点，再进入统一曲线/上限；具体直接概率与评级的合并口径需专题确认，不能把种族1个百分点误当评级后衰减。推荐普通评级先换算，再加固定百分点，最终共同封顶。

本稿不擅自改变命中/闪避的已确认作用域。概率闪避是否足够可读、暴击上限和基础暴伤值，均是接下来需要用方案审阅的取舍。

## 4. 急速与时钟提案

建议最终急速收益h先统一递减，再用于 `普攻倍率=1+h`。保留每段起手快照、动画/命中/移动开放同一动作时钟；300ms续接与120ms缓存按实际战斗时间，不缩短。

2026-10-19用户确认：急速影响技能出招与收招；有前摇的技能缩短前摇，多段伤害（如连续爆炸）结算间隔也缩短。撤销此前“仅缩短起手、保留后续多段/收招”的建议。动画、伤害节点、起跳/落地移动及技能残留须同步重定时，不能只有伤害加快而画面不变。固定多段技能保持既定段数；具体缩放公式、倍率上限仍待审阅，施放时锁暴击率/暴伤/急速及本次CD的口径已确认，当前原型尚未迁移。

CD候选：`max(技能CD下限, 基础CD × (1-同类套装减CD合计)/(1+h))`；套装减CD自身封顶。药品和主动饰品固定CD均不参与；饰品持续必须短于其独立固定CD。CD从实际成功施放起计，建议该次锁定，不因后续换装变动反复改剩余CD；此快照口径需审阅。

2026-10-19最终纠正：急速缩短流血伤害间隔及整段持续时间，总伤害不因急速增加；撤销此前“固定5秒、增加跳数/总伤害”的确认。5秒只作为无急速时的基础持续时间，重复有效施加改为叠加，保留旧流血未结算伤害，不以新流血覆盖丢失旧预算（2026-10-19最新决定，覆盖旧刷新规则）；伤害预算按用户最新确认在技能释放时计算并锁定，后续增益消失不降低；用户确认每招一份流血总预算，按各段有效命中分配施加份额，未命中不施加；再次施放可叠加新预算。具体权重、急速和暴击参数取值时机另做方案；不得覆盖旧流血剩余伤害。流血直接以最终攻击强度为基础，主属性、副属性、装备、强化等来源按各自作用参与最终战斗计算；精通、增伤间接影响流血，暴击也影响流血暴击。用户进一步确认：流血每一跳独立判断暴击，不继承触发技能的暴击结果；精通/增伤不得重复乘算。急速保持跳数和非暴击总伤害预算一致；每次实际总伤害可因独立暴击随机结果不同而波动，不能把随机差异视为急速增加总量。候选时间缩放：固定基础跳数与单跳预算，间隔和持续时间同除以急速倍率，完整结算总量保持一致。当前原型固定0.2/秒、5秒尚未迁移。

## 5. 首轮相对伤害预算（候选，不是正式值）

用一记基准普攻非暴击命中的伤害作为1U；以下忽略护甲/概率/顿帧，只比较同一靶上的预算。为了不因段数重复增伤，整招基础伤害和Attack系数先分配到各段，权重和必须为1。

| 动作 | 建议相对预算 | 校准方向 |
| --- | --- | --- |
| 普攻三段 | 0.9 / 1.0 / 1.1 U，共3U | 1秒空挥基线，末段略重，取消不能提前获得未来伤害 |
| 十字斩2段 | 总2U，近身/发射各50% | 范围与双段控制有价值，不要求单怪重复吃满才可用 |
| 崩山击3段 | 总3U，25%/30%/45% | 重心落在终段，强制击倒另计控制价值 |
| 拔刀斩1段 | 总4U | 保持单次宽范围爆发及单刀蓄力表现 |
| 大崩4段 | 总8U，25%/25%/25%/25% | 高总量换较长承诺与资源/冷却；不调整已确认动作时序 |

表中U是当前基准攻击伤害；正式每招仍使用“技能1级固定值 + 每技能级固定增量 + Attack系数”，不能将技能升级后所有项再次相乘。CD/蓝耗不能沿用原型1.1/3.4/2.4/8秒作为正式结论；须配合平均战斗与恢复占空比一起出表。

## 6. 成长、经验、恢复和评分的校准表

本轮先定义每个等级检查点要交付什么，而不填未经验证的整数表。

| 等级 | 既定变化 | 试算与试玩场景 |
| --- | --- | --- |
| 1 | 初始白武器、十字解锁 | 无额外装备/无初始货币也能完成首局；检查普攻次数和蓝耗 |
| 5 | 崩山解锁、装等15绿武器邮件 | 新技能有控制价值；换保底武器的收益清楚 |
| 10 | 拔刀解锁、装等20绿武器邮件 | 群怪爆发提升，不让旧技能失去用途 |
| 20 | 大崩解锁、装等30绿武器邮件 | 用精英/Boss检查长动作风险、爆发和蓝量 |
| 30 | 停止累计经验、装等30保底 | 特殊副本与套装成长；未强化高段也有合理入口 |

另需输出15/25级保底节点及所有1–30实际配置。经验建议先定各级目标耗时，再用“每局期望经验/有效分钟”反解升级经验，避免先拍指数曲线。经验等级差衰减仅修改经验；金币装备不加超等级惩罚。满级经验直接停止，不溢出兑换。

恢复建议以最大值比例/秒表达：战斗内低、清场后高，回城满值。先校准一次普通房间中技能使用次数、失误后的可恢复程度，再确定回复/蓝耗/药品；禁止单独调自然回复让药品和走位失效。具体比例待D03/D04联动。

评分建议只按当前穿戴装备的固定/随机属性、强化与套装常驻收益重算；不纳入临时buff、当前血蓝或战斗CD，避免刷临时榜分。属性权重应按职业归一化，同分时间沿既定规则。跨职业可比性和套装计分权重待D02出表，不以战斗瞬时DPS直接评分。

## 7. 进入正式配置前的验证与下一轮讨论

2026-10-19已补[战士数值试算v1](combat-numeric-proposal-v1.md)及[逐级CSV](combat-numeric-v1.csv)，含检查点攻强/血蓝、技能伤害/蓝耗/CD、候选上限、怪物时长解析估计与经验预算。本表候选数值取代上文早期U概算用于下一轮审阅；尚未真实战斗排程/试玩，未写入代码，不代表本票已完成。

实现前需补齐：1–30级成长/经验表、5个检查点完整属性和武器、四技能等级参数/CD/蓝耗、属性上限与K、怪物护甲/HP/攻击、恢复及药品、评分权重。此稿仍不是可直接开工的完整数值规格。

普攻/技能适用范围、耗蓝规则及急速作用方向已确认：所有怪物均可使用普攻和技能；装备不改变同一技能耗蓝，施放次数决定累计消耗；急速加快出招/收招、多段结算和DOT间隔，DOT总伤害不变、持续时间随急速缩短；伤害基于最终攻击强度并受精通/增伤/暴击影响。后续先提出属性曲线、上限、DOT暴击/快照和成长资源试算方案，再审阅实质取舍，不重新提问已确认方向，也不把每个系数都变成一轮问卷。

验算用例：相同来源相加；零/极端评级；上限边界；技能等级解锁；三段与四段总伤害；概率0/1；DOT刷新/致死/不计倒地；急速与动作同步；饰品持续短于CD；自然恢复及满级经验；初始武器通关；3–5小时成长预算。自动验算、靶场和真机分别记录，不能互相冒充。

## 2026-10-19补充确认：消耗成长与职业基础副属性

技能随技能等级提高增加消耗；不是按装备好坏额外扣蓝。角色初始就有基础副属性：战士暴击偏高、猎人急速偏高，未来法师可精通偏高，法师不因此纳入当前MVP。已在数值试算中加入候选基础值、技能等级蓝耗增量，并重算20/30级消耗对照；具体数值仍待审阅。

## 2026-10-19补充：暴击与生命

用户确认暴击不设低于100%的上限，可堆到100%，取消试算的50%上限；换算曲线必须允许有限投入达到100%。用户要求玩家生命进一步提高，本轮将试算生命整体翻倍作为待审阅候选，怪物攻击暂保留旧绝对预算，AP/MP不变；倍数未获确认，百分比恢复/药品影响需联调。
