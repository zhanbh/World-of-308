# 动作解锁与预警时间轴 v14

2026-10-20。承接[空间反例v13](spatial-dodge-review-v13.md)。运行 `python3 -B docs/design/analysis/action_warning_timeline_trial.py`，仅设计验证，不修改业务实现。

## 本轮改进

直接从[普攻动作表](../../client/assets/scripts/WarriorAttackAnimation.ts)、[技能动作表](../../client/assets/scripts/WarriorSkillAnimation.ts)与[技能分段表](../../client/assets/scripts/WarriorSkillsModel.ts)读取三段普攻、四个技能的duration、moveAt和接触时点，缺字段即失败。

警告起始作为t=0，玩家动作已经进行age秒；剩余移动锁定=max(0,moveAt/q−age)，可起步时刻=max(反应时间,剩余移动锁定)，而非两者相加。动作q取1/1.45/2，按施放时快照缩放；本模型不让急速提高横向/纵深移速。当前客户端技能elapsed仍按dt推进，q缩放是目标设计情景，不是假称现有实现已完成。

v13中反应+锁定顺序相加保留作历史保守对照，本轮以可重叠方案检查。反应0.2秒仍是候选输入，不是玩家能力结论。收到警告后不继续接新普攻、反应完成释放普攻按住状态，是本轮策略；不能假设一直按住普攻仍自动保证走位。

## 同一个候选扇形，1秒预警

沿v13正前方(150,20)、半径140、全角60度、足迹半径8、移动到搜索安全点约0.38秒；当前位置在锁定期间固定，未算技能自身位移。下面比较q=1且警告恰逢动作开始，安全裕量=预警−可起步时刻−路线耗时。

| cross | 0.460秒 | 0.160秒 | 是 |
| bengshan | 0.780秒 | -0.160秒 | 否 |
| badao | 0.660秒 | -0.040秒 | 否 |
| earth | 1.320秒 | -0.700秒 | 否 |

这张表不用于设定统一预警下限。负裕量表示本搜索路线未及时到安全端点，不证明连续空间所有路线均失败。对长动作，更晚看到警告、预先站在扇形侧边、施放时急速及技能自身位移都可能改变结果。

## 仍缺的接入与下一步

- 崩山击向前34像素、大崩默认跳跃64像素、普攻小步都会改变锁定结束位置；当前固定位置隔离测试不能当真实技能躲避结果。下一步接强制位移轨迹和朝向，避免忽略跳入/跳出范围。
- Boss重槌、践踏、连续践踏、冲撞/撞墙虚弱与精英横扫尚无已确认的完整时长/范围/控制节点。先写明确候选节点及反例，再接整局；不把本轮扇形自动推广到全部招式。
- 实际1/120秒步进、命中停顿、受击取消、同帧移动/判定、接招输入需要实现阶段回放；本轮连续时间没有证明这些边界。
- v10–v12整局模型仍用抽象走位，此独立时间轴未替代其输出窗口，也不直接将本轮耗时追加整局。

验证：7动作×3急速×3动作进度×3预警，共189组完成；源表提取、动作尾段可移动、反应/锁定重叠、急速缩放及本体后接触时点断言通过。没有新增玩法确认，不修改正式数值。
