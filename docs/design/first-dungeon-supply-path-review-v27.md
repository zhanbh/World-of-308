# 首副本1至15级连续供给路径 v27

日期：2026-10-21。接续[v25](basic-skill-policy-review-v25.md)/[v26](intermediate-gear-policy-review-v26.md)。状态：候选数值路径，不是正式掉落/药价或完整成长验收；未修改游戏实现和发布配置。

## 1. 这轮新增什么

从1级初始白武器、0金币、一次性低档血蓝药各8和纹章10开始，连续挑战首副本普通至15级。每局保留经验、钱包、实际药品余量、材料、掉落装备、穿戴和耐久；在城镇领取5/10/15级武器邮件、选择换装、出售多余装备、付费修理/补药。没有每局免费补满8瓶，不把剩余低档赠药自动升级。

每件分析装备都含durability对象，7磨损部位启用；其他槽显式不适用。白绿蓝装备基础预算沿同模板固定基础一致的规则；绿1副、蓝2副及蓝主属性使用已有预算候选，绿副属性取模板第一条，不额外编造第3条。不同槽可持有不同装等，升级不自动提高已持有装备等级。

模型仍不是游戏资产事务实现：装备按装等优先再品质的测试策略挑选；赠药优先、同局绑定一种血药/一种蓝药，用完不在局内自动换模板；城镇先修理，再买血药/蓝药至目标8瓶。它们是可替换的玩家代理策略，不是新增强制玩法或自动战斗功能。

## 5. 对v26合理装备假设的校正

本候选普通难度到15级绝大多数仍靠白绿装，平均已穿非武器槽11.4–11.5件，而不是空槽只拿武器，也不是五蓝/全蓝。白装通关奖励逐渐补齐固定HP/MP/护甲，绿装添加副属性；品质不提高同模板固定基础的规则得到保留。

入口10级以上的108次挑战/策略：高频平均血药1.16、蓝药2.81，Boss房中位140.21秒；自适应血药1.13、蓝药1.98，Boss房中位161.05秒。中位只含实际到达Boss的挑战，不能将未到达当0秒；该层级分组在每种策略中均有108次记录。

因此v26“5蓝装使Boss进入1–2分钟”是给定装备下的能力证据，不是正常普通掉落路径已达该目标。穿插策略平均节省约590金币购药、增加约4.64分钟有效时间，并未自动解决Boss时长。

## 6. 当前结论与下一步

1. 当前候选下，没有出现必须靠免费补满药品或凭空赠蓝装才能完成首段的样本；白绿装正常成长的固定基础贡献不能被忽略。
2. 不立即提高蓝装掉率、加武器AP或削Boss。先以实际可得白绿装复核普通难度Boss目标及使用策略，必要时做版本化候选对照；约2.3–2.7分钟是待校准信号，非已验收目标。
3. 1至15级约1.5–1.6小时只是本模型结果，不能线性翻倍声称完整1至30级满足3–5小时。第二副本的地图/怪物/供给与全段材料/强化/扩容支出仍未接入。
4. 下一轮应对正常白绿装路径的Boss预算与第二副本内容先形成合法候选，再继续完整成长验证。材料约120和钱包约2.5万不证明强化/扩容节奏合理，因为本轮尚未花费这些可选支出。
