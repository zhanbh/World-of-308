# D05 界面与验收清单 v1

更新：2026-10-20。依据：[当前交互方案](town-interactions-proposal-v1.md)、[正式规格](../spec.md)、[挑战流程](../challenge-flow.md)。

## 界面清单

| 界面 | 入口与布局 | 核心操作 |
| --- | --- | --- |
| 旅店 | 上线进入当前角色隔离空间 | 其他玩家不可见、不可进入 |
| 城镇 | 可移动，禁普攻/职业技能/饰品 | 背包/个人信息随时打开；服务到对应地点办理 |
| 副本选择 | 走入地图对应入口范围自动打开 | 选择难度确认；不提示体力消耗；离开再进入才重触发 |
| 个人信息与装备检视 | 快捷键 C/M 或点击头像/菜单 | 13装备槽全身检视、装备极详卡片、攻防属性拆解、套装激活汇总、检视他人只读快照 |
| 背包换装 | 快捷键 B 打开，左纸娃娃右背包 | 点击对比、穿戴/替换、卸下、扩容与快捷栏拖拽编辑 |
| 林纳克斯修理 | 左修理，右自动打开个人信息/装备 | 点装备选中、显示耐久和费用、单件修满/当前穿戴全修 |
| 玛丽强化 | 左强化，右装备/背包切换 | 点武器/耳环；等级、属性变化、消耗、失败后果、纪念品；不显示概率 |
| 商人 | 左商店，右背包 | 购买选数量确认总价；出售选背包物品确认数量与收入 |
| 银行 | 左当前金库，右背包 | 个人/账号页签，一次仅开一种；拖动存取及数量选择 |
| 邮箱/永久待领 | 旅店门口，共用双页签，右背包 | 时间倒序；领取、空间不足保留；邮件有效期与永久待领区别展示 |
| 消耗品快捷位 | 背包中编辑3个位置 | 拖动绑定/替换；移除不删物品；显示数量/CD，耗尽保留绑定 |
| 排行榜 | 具体菜单位置待定 | 主动查询总榜/职业榜，当前穿戴评分、同分时间排序，无奖励 |
| 拍卖行 | 独立建筑 | 建筑位置确认，交易功能仍后置，不据此验收拍卖实现 |

买卖、修理、强化、银行、邮箱打开时停止移动；关闭恢复，不能推导战斗中打开背包可暂停战斗。有新邮件/待领只提醒，不自动打开面板。

## 资产与容器验收场景

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| UI01 | 满包替换同部位穿戴装备 | 原格交换；直接卸下无空格则拒绝，不丢装备 |
| UI02 | 背包扩容重复/超时 | 按已定2000/4000/8000/16000价格，20格一档，最多100；同档不重复扣费 |
| UI03 | 切换金库页签 | 只显示对应金库，清除选择；个人仅当前角色、账号仅本账号共享 |
| UI04 | 个人金库存本角色绑定、账号绑定、未绑定物品 | 允许且绑定不变；账号金库存角色绑定物品拒绝 |
| UI05 | 拖动存取所选数量超过可容纳量 | 整次不执行并提示可容纳量，不发生半笔转移 |
| UI06 | 解锁个人金库 | 初始20，上限100，4次各20；点锁格展示阶段两种价格，选择一种支付确认，不同时扣两币 |
| UI07 | 个人解锁后换角色/切账号金库 | 不将角色解锁进度共享；账号金库仍100全部开放，不受个人付费影响 |
| UI08 | 单件/全修、满耐久、余额不足 | 仅7耐久槽计磨损；服务端核价，单件修满；全修不足整批拒绝，满耐久不收费 |
| UI09 | 强化成功/失败/损毁及纪念品 | 按既定等级后果执行，概率不显示；已执行成功失败均消耗；拒绝不扣；损毁溢出纪念品入30天邮件 |
| UI10 | 商人购买满包/余额不足，出售穿戴装备 | 购买整次拒绝；穿戴先卸下；不得因强化/词条提高NPC售价，不提供买回 |
| UI11 | 邮件部分领取、未领附件删除、到期 | 可容纳部分领取，未领保留；有附件不能手删；30天到期不按永久待领保留 |
| UI12 | 永久待领满包、领取重试、重新打开 | 奖励不丢不自动过期、不直接穿戴/出售/跨角色；时间倒序，原生成时间不随重试改变 |
| UI13 | 快捷绑定耗尽后补充同模板 | 显示0并保留绑定，补充恢复；按角色绑定→账号绑定→未绑定消耗，不使用金库/邮件库存 |
| UI14 | 关闭任一服务面板时请求结果未知 | 不撤销已提交请求，先查原结果；再次打开展示已确认状态，禁止重复扣款/转移/发奖 |
| UI15 | 个人信息装备检视与他人检视只读快照 | 点击装备弹出完整Tooltip卡片；攻防属性公式展开正确；0耐久部件扣除套装计件；检视他人采用服务端快照且隐藏修改操作 |

## 待定项与开发切分输入

- 数值：个人金库两种货币各阶段价格，商品模板/价格，修理单点价，强化成本与材料等未定表；伤害试算继续等待用户资料。
- 交互范围：是否直接修背包装备；排行榜入口与分页、快捷位移除手势、耐久文字颜色/分档、出生坐标/入口范围等视觉细节。
- 实现边界：跨刷新回城体力加载的服务端状态模型；上线/在线回城事件优先级；资产操作ID、版本校验、稳定排序及重复响应。工程方案可在既定行为下细化，不能擅自改变用户规则。
- 实机：手机横屏触达、拖动误触、双栏信息密度、文字可读性与性能，均尚未验证。

D05主要交互可交接D06切分，但仍保留proposal-ready，不宣称所有未决项关闭或功能已实现。D06先切规则/状态/资产验收和最小持久化闭环；涉及未定价格使用可替换测试配置，不能冒充正式数值。云环境创建、部署和业务代码变更不在本轮范围。


2026-10-20范围澄清：UI15的本人角色信息仍属本期，他人检视及玩家搜索、好友/私聊、城镇其他玩家展示为后续社交储备，不计本期验收。本期不显示这些未实现的可操作入口，社交详细状态未收敛不阻塞本期。


背包补充验收（2026-10-20）：背包/金库固定5列上下滚动；背包一键整理入口存在，整理规则确认后覆盖数量与绑定不变、快捷模板不变、装备实例不合并、并发领取/换装不丢物及请求重试。当前仅确定功能范围，未通过实现验收。


2026-10-20整理规则已确认：先合并同模板、同绑定归属及其他堆叠条件一致的物品（每堆最多20），再按装备→消耗品→材料排列；装备按部位固定顺序、品质高到低、装等高到低，其他同类按模板稳定排序，同排序键保持稳定次序。支持正序/倒序切换：默认正序采用上述顺序、空格置末；倒序反转该排列并将空格置首。快捷栏模板绑定不变，装备不合并，不改变数量、属性、绑定或来源；仅整理当前背包，金库整理未确认。
