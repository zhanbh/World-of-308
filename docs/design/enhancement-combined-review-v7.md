# 强化记忆、幸运与纪念品联调 v7

2026-10-20。用户已选择成功按等级相似度消耗记忆；方向正式记录，数值仍为候选。本稿补直接强化从0重建、失败损毁、纪念品库存和会话重置的联合路径，不修改业务代码。

复算：`python3 docs/design/analysis/enhancement_combined_trial.py`。固定种子0–399，每条路径最多15000次强化。它是有限样本，不把均值称为理论期望，不把固定次数会话当真实游戏登出规则。

## 1. 已确认与试算输入

已确认：同级/邻级/远级按相似程度提供补偿，成功也按相似度消耗；切角色/下线重登清全部，短恢复保留；仍为随机，不显示玩家界面成功率；+13起失败损毁、+11/+12回10、金币高段每级翻倍，最高段定位极稀有。

沿v6候选：σ1、每失败来源+3个百分点、每来源/历史总加成上限各15个百分点；主角30档武器C10=10000，低段平方费用，15–20成功率沿平滑候选。材料每次ceil(目标级/2)仅为已有候选；材料没有金币估值。

沿经济旧稿补充的候选纪念品：+13起失败按目标等级−12发放；玩家主动选择消耗5枚，本次+5个百分点，成功失败均消费，不叠加多组。模型策略只在+13以上且库存足够时选择使用；实际游戏仍由玩家决定，不将脚本策略做成自动使用。纪念品初始0，按失败真实产生，不能把每次免费加5个百分点作为正常收益。

幸运+5个百分点只作恒定满额敏感性输入，未定义或验证角色能够如何获得该额度。候选叠加先加基础率、历史补偿、幸运和单组纪念品，最后统一封顶90%；另算95%对照。两种上限都未正式确认，均不提供必成。高段概率一般不到上限，二者主要影响低段及后续重建。

## 3. 纪念品流水与高段返回

+15、记忆＋纪念品组，样本平均产生56.36枚、消费54.49枚，余量非负；加入5个百分点幸运后平均产生35.18、消费33.16。每条路径都核对期末库存=期初＋产出−消费，没有免费借用尚未获得的纪念品。

+13失败返1，使用5后失败净减少4；+20失败返8，使用5后失败净增加3。这不是免费循环：每次+20尝试仍支付高额金币/材料，失败还销毁已强化装备。但高段纪念品供给会变强，需要保留全经济流水验证，不能只统计概率收益。返还/消耗数目前仍是候选，没有锁定。

## 4. 最高段的乐观边界

不在有限样本内假装“模拟出了+20的实际期望”。另用无记忆重建递推给一个极乐观对照：假设每次尝试无成本、永久取得历史15＋幸运5＋纪念品5，共25个百分点加成，低级也同享，且使用更宽松95%总封顶，材料/装备重获完全免费。

同一费用和失败规则下，从0到+20理论期望仍约277574435金币（约2.78亿），按当前特殊普通19448候选净收益等值约14273局。实际历史不可能始终满额，纪念品与幸运也有获取限制，因此这不是新机制的实际成本预测，只是模型内偏乐观的可达性对照。旧无记忆566亿同样只能作为历史基线。

结论：给定当前候选，最高段极稀有方向仍有空间，不需要为“允许垫装”擅自提高既定基础率、取消损毁或改变金币翻倍。
