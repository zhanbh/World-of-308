# 逐段随机命中与命中词条：七房联调 v9

> 2026-10-20跨环境同步：本报告数值使用旧遭遇/Boss控制假设，仅保留历史对照。用户现已最终确认首Boss平时可控、施招霸体；当前首副本还包含公司新增紫名/吼叫与抗性规则，见[整合方案](dungeon-first-proposal-v1.md)。不能把本报告样本当最新关卡验收。

2026-10-20。用户已确认每段/每敌人独立命中，只有命中段施加流血份额；DOT附着后不额外判命中，仍独立暴击。本轮把这条规则接入离线模型，未改业务代码。

复算 `python3 docs/design/analysis/segmented_hit_dungeon_trial.py`。当前身体时长、2倍上限、逐段时点、控制与Boss窗口沿v8；新增独立的玩家命中随机流，敌攻的躲避随机流分开，避免一次玩家命中骰直接改变敌方下一次随机数。战斗路径变化依然会改变敌攻时刻/次数，所以不能把不同路径逐击当成严格配对。

## 1. 命中与有效流血

每个阶段先检查目标还活着（几何在本模型假设接触），再判命中。miss跳过本段所有直接伤害、倒地/特殊击倒及流血；命中后才排该段5份DOT。基础普攻没有技能流血，不为0预算排5个无意义事件。DOT本身不再判命中，也不计倒地。

候选 `p_hit=clamp(基础命中得分+装备/套装命中增益−目标闪避,0,1)`，基础得分1，普通怪闪避5%、精英8%、Boss10%。命中得分不是最终概率，不能先把得分截到1再减闪避，否则会让额外命中失去作用。真正对该敌人的概率始终≤100%。这些曲线/数字均未获确认。

每次技能阶段把该段直接/流血预算和急速一起带入事件；命中得分暂按施放时携带，目标闪避在接触时取值。这是模型约定，不能将已确认的暴击/急速快照自动扩展成所有命中字段已定稿。模型没有战中命中buff/闪避buff变化的专项验证。

## 2. 命中词条不是白送第三条

蓝装命中对照用武器“急速12评级”换成“命中12”，耳环“暴击2”换成“命中2”，按装等比例缩放；命中候选每评级0.5个百分点。AP不变、急速和暴击下降，满足同件副属性不重复及条数限制。初始/保底武器不修改已固定的赠送属性。

三组是同一命中判定事件路径：零闪避必中参照、原配装与闪避、命中词条替换与闪避。没有拿旧的预先排流血的必中分支直接混作新的基准。
