# 技能位移与危险区联调 v15

2026-10-20。承接[动作时间轴v14](action-warning-timeline-review-v14.md)。复算：`python3 -B docs/design/analysis/skill_displacement_dodge_trial.py`。仅离线设计模型，不修改客户端战斗实现或正式配置。

## 接入来源

从[技能模型](../../client/assets/scripts/WarriorSkillsModel.ts)和[动作表](../../client/assets/scripts/WarriorSkillAnimation.ts)读取：

- 崩山击：0.12秒开始位移，到impactAt=0.58秒完成34源像素向前移动，曲线为1−(1−p)²；moveAt=0.78秒允许玩家主动移动。
- 大崩：0.28秒起跳，到impactAt=0.88秒完成位移，曲线为p²(3−2p)；默认64源像素，施放时沿朝向输入超过死区则100源像素；moveAt=1.32秒。
- 位移沿施放朝向，警告出现时已经走完的部分不重复计算。警告后剩余位移=位移函数(当前动作年龄+t)−警告时已完成位移。

q=1/2按已确认设计统一压缩动作和位移完成时间，总位移距离保持不变；主动横向/纵深移速仍是原型100/45源像素每秒。当前原型技能更新尚未实现这套急速缩时，本轮不声称客户端已经一致。

[skillLift](../../client/assets/scripts/WarriorSkillAnimation.ts)是独立视觉高度，地面位置与碰撞不随角色画面升高。本模型没有据此添加无敌、穿怪或地面伤害豁免。

## 情景与边界

比较崩山34、大崩64/100；两朝向；警告出现时动作0%/50%/90%进度；q1/2；圆形半径72/前方扇形半径140全角60度；预警0.6/1/1.4秒。共216组，每组分别计算带位移与固定位置两条路径，保持其余参数相同。反应0.2秒与剩余移动锁定按max重叠。

Boss位于(100,20)，朝右锁向，圆形起点(140,20)、扇形起点(150,20)。这些范围、位置、足迹半径8及房间矩形均为v13候选，不是首副本已批准地图。离墙时限定完整足迹，原型目前只夹住角色锚点；靠墙结果须待统一碰撞规则后复核。

到主动移动解锁时，按该时刻实际落点搜索2像素网格安全终点，再按横纵独立速度直线退出；锁定期间继续技能自带位移。警告起效时检查完整地面足迹；扇形额外检查预警结束后0.5秒起共6次持续段。未模拟伤害、击退、受击停顿或累计伤害倒地，也没有主动提前取消技能。

## 数值联调结论

1. 旧固定位置时间轴对部分组合会误判，不能据此直接要求更长预警或提高怪物伤害。
2. 位移技能可能同时输出与改变位置，不能把位移用时全算成失去输出，也不能将这段再次加到v12抽象走位时间。
3. 单招路线可行不代表群怪战斗可行；碰撞、投石、冲锋协调及完整Boss招式仍需接入。未把216组对照当整局通关或约4分钟目标的验证。
4. 保持武器/防具、HP、药价和金币候选不变；先统一空间、动作与敌招节点，再评估新的补给和局长。

## 验证与下一步

源参数提取、位移起终点、单调性、采样路径足迹合法性及地面位置变化检查通过；样本按120Hz输出位置诊断，路径计算仍为连续函数，不宣称等价原型每帧取消/判定顺序。

下一步建立敌方技能候选节点表：起手锁向、范围起效/结束、施招霸体、恢复可控、独立冷却与P2衔接，先覆盖吼叫、精英横扫和Boss重槌，再扩连续践踏/冲撞。每个候选清楚标注来源和未定参数，避免把目前2秒施招代理误当正式动作方案。
