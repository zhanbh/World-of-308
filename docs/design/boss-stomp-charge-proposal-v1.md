# Boss连续践踏与冲撞节点候选 v1

2026-10-20。补充[敌招节点](enemy-action-nodes-proposal-v1.md)，承接已确认的后半血连续践踏接锁向冲撞、撞墙虚弱。只定义参考候选，尚未正式动作/AI配置。

运行 `python3 -B docs/design/analysis/boss_stomp_charge_trial.py`。

## 候选序列

| 节点 | 相对正式起手秒数 | 行为 |
| --- | --- | --- |
| 三次践踏 | 0.8/1.4/2.0 | 每次独立结算，不能提前整招扣血 |
| 冲撞锁向 | 2.4 | 此时读取玩家位置，不在第一脚就锁定未来方向 |
| 开始冲撞 | 3.2 | 候选水平180源像素/秒，距离上限单独配置 |
| 墙接触 | 根据实际路径 | 沿路径扫碰撞、接触即停，不越界 |
| 撞墙虚弱 | 接触起3秒 | 恢复正常控制，不凭空附带已确认增伤 |
| 未撞墙结束 | 跑满距离后0.8秒恢复 | 未碰墙不能伪造撞墙虚弱 |

连续3次、全组合施招霸体、间隔/速度/距离/虚弱时长均为候选。霸体结束、起手/收招边界还须动作审阅。玩家跨到另一边不使已锁向冲撞瞬时掉头。死亡取消未来践踏与冲撞，不进入死亡后的虚弱状态。

Boss地面足迹半径14是夹具，合法位置用地图边界减足迹；玩家已确认可以穿怪物身体，不把玩家位置当冲撞的实体墙。玩家能否被冲撞命中需按攻击范围/轨迹另算，身体穿过不免伤。

## 验证

12组起点/目标方向/距离对照执行；60/120Hz终点相同，两侧墙停在±204而非越出±218地图；顶侧合法位置的水平冲撞也不越界。短距离跑满但没碰墙不触发虚弱；锁向后玩家换边不掉头；施招受控参考被霸体拒绝；1.5秒死亡只保留此前两次践踏节点，不继续第三次；薄实体墙首次接触即停。

目前把不可破坏实体障碍视为墙接触候选，可破坏物与滑动另行配置。60/120Hz只比较终点和碰墙有无，不宣称实际接触时刻逐浮点完全相等。

这不是完整Boss战：未算玩家被命中、伤害、技能选招、CD或P2切换。本节点序列将供后续联合模拟使用，不能将构造情景等同实机Boss机制已完成。
