## 1. 核心设计基准与视觉规范

### 1.1 屏幕与画布规格
- **目标平台**：微信小游戏（横屏横向滚动与 2.5D 有限纵深）。
- **设计基准分辨率**：**960 × 540 px**（对应 2.5D 战斗画布 480 × 270 的 2× 放大点阵像素风格）。
- **安全区留白 (Safe Area)**：左右两翼各预留 **24px** 物理边缘缓冲区，关键操作控件严禁贴死屏幕边缘，全面屏手势条底部预留 **16px**。
- **触控人机工效**：
  - 主要动作按钮（普攻、技能）：$\ge 72\times72\text{px}$；
  - 列表单项与功能按钮：高度 $\ge 44\text{px}$，触控热区最小 $\ge 48\times48\text{px}$；
  - 格子尺寸：背包/金库单个物品格子标准尺寸为 **56 × 56 px**（内边距 4px，有效贴图区 48 × 48 px）。

## 2. 界面 1：HUD 常驻界面

### 2.1 城镇态 HUD 布局（安全区）

```
| HP: 600/600                                                [信箱红点] [待领红点] [设置] |

|   (O)                                                                       [角色 C]  |
| 半透明底圈                                                                  [排行 R]  |
+---------------------------------------------------------------------------------------+
```

- **左上角状态栏**：
  - 头像尺寸 48×48px，点击直接打开【个人信息与装备检视界面】（等同于点击右侧【角色 C】或快捷键 C / DNF M 键）；
  - 旁边展示角色等级（黄色加粗）、角色名字；
  - HP 条（长 160px，高 10px，底深红 `#3e1b1b`，填充红 `#e54b4b`）；
  - MP 条（长 160px，高 8px，底深蓝 `#132636`，填充蓝 `#2b82c9`）。
- **右上角工具栏**：
  - 金币、点券当前持有数显示（只读，带对应图标）；
  - 信箱按钮（带有新未读邮件时右上角显示 10px 红点）；
  - 通关待领按钮（待领仓库有积压装备时显示红点）；
  - 设置按钮（音量、画质、返回登录）。
- **右下角功能区**：
  - 【背包】（快捷键 B）：点击打开背包与快速换装界面；
  - 【角色】（快捷键 C / 类似 DNF M 键）：点击打开个人信息与装备检视界面；
  - 【排行】：点击打开全服战力评分排行榜。
- **左下角移动摇杆**：
  - 固定底座虚拟摇杆，半径 55px，透明度 40%，负责角色在城镇内的 X/Y 轴移动。

## 3. 界面 2：旅店与城镇安全区交互

### 3.1 地点与空间流线
1. **上线默认点 — 独立旅店房间**：
   - 角色上线、重新登录时，默认置身于“单人旅店房”中（其他玩家不可见、不可进入）；
   - 房内中央为单人休息床，右侧为房门；
   - 走到门边自动踏出进入城镇主街道。
2. **城镇主街道分布**：
   - 旅店房门口：常驻【信箱与待领】互动邮筒；
   - 街道中部：【铁匠铺】（林纳克斯修理、玛丽强化）、【杂货铺】（商人买卖）、【银行】（金库）；
   - 街道东侧：【拍卖行】独立建筑大门（靠近交互提示“拍卖行正在修缮中，敬请期待”）；
   - 街道外围道路：通向各独立副本的入口区域。
3. **离开副本返回逻辑**：
   - 通关或中途离开副本返回城镇，角色精准落在**该副本门口对应位置**，不会被强制传回旅店。

### 3.2 NPC 交互气泡
- 角色移动至 NPC（如林纳克斯、玛丽、商人）附近 60px 范围以内，NPC 头顶浮现金黄色交互气泡（带呼吸微动）；
- 点击气泡或点击右侧出现的【交谈】按键，角色**瞬间停止移动**，对应全屏服务界面淡入弹出。

## 5. 界面 4：个人信息与装备检视界面 (Character Profile & Gear Inspector)

### 5.1 界面定位与呼出途径
- **定位**：对标 **魔兽世界 C 键 (Character Sheet)** 与 **DNF M 键 (角色个人信息/冒险家名片)**。
- **主要职能**：
  1. 完整展示角色全身外观（2.5D 高精立绘/动态骨骼像素纸娃娃）与当前穿戴的 **13 个装备槽位**；
  2. 点击/触摸任意装备槽位，弹出极度详尽的**装备细节卡片 (Detailed Item Tooltip)**；
  3. 提供全维度战斗数值面板（攻击强度展开、暴击、急速、精通、穿透、护甲减伤率、抗性、技能冷却缩减）；
  4. 套装激活进度与效果汇总切页；
  5. 战力/装备评分 (GearScore) 与荣誉记录展示；
  6. **复用机制 — 检视其他玩家 (Inspect Player)**：在排行榜点击角色条目，或搜索玩家信息并选择目标角色时，拉起该界面的**只读检视模式**，杜绝属性黑盒。

### 5.3 13 个装备槽位严格规则与角标定义

严格遵循项目确认规格（规范中**明确无头部槽位**，共 13 槽）：
1. **左翼（防具 5 件 + 主动饰品 1 件）**：
   - 护肩 (Shoulder)、上衣 (Chest)、腰带 (Belt)、下衣 (Pants)、鞋子 (Boots)；
   - 主动饰品 (Trinket)：独立功能性道具（如解除控制、短暂护盾），拥有固定独立冷却（不受急速/套装减CD影响）。
2. **右翼（首饰 3 件 + 特殊装备 3 件）**：
   - 首饰：项链 (Necklace)、手镯 (Bracelet)、戒指 (Ring)；
   - 特殊装备：辅助装备 (Sub-Equip)、魔法石 (Magic Stone)、耳环 (Earring)。
3. **中央底部（武器 1 件）**：
   - 主手武器 (Weapon)：双刀（战士）或弓箭（猎人）。
4. **槽位角标与指示条规范**：
   - **强化角标**：**仅武器与耳环**允许强化（+1 ~ +20），槽位右上角显示黄色高亮角标（如 `+10`）；其余 11 个槽位严禁展示强化等级；
   - **耐久度微型指示条**：**仅 7 个启用耐久的槽位**（武器、5 件防具、耳环）在槽位底部展示 3px 高度的微型耐久进度条（绿色 $>50\%$、黄色 $1\%\sim50\%$、红色闪烁 $=0\%$）；其余 6 个槽位（首饰 3 件、辅助装备、魔法石、主动饰品）不启用磨损，绝不显示耐久度条。

### 5.5 多页签切换与数值计算公式透传

#### 页签 1：【属性详情 (Detailed Stats)】
完整展开公式层计算拆解，方便玩家深度理解配装成长：
1. **攻击强度 (AP)**：
   $$\text{AP} = (A_{\text{基础}} + A_{\text{武器}} + \alpha \times \text{主属性} + A_{\text{强化}} + A_{\text{词条}}) \times (1 + \text{攻击\%})$$
   - 界面分项列出各加成源，其中战士主属性力量按配置系数（如 0.45）换算，猎人按敏捷换算；
   - 明确标注副属性“攻强”仅计入武器与耳环，不重复转换。
2. **暴击与伤害倍率**：
   - 物理暴击率展示为精确百分比（如 `18.5%`）；暴击伤害基础倍率固定为 `150%`。
3. **物理护甲与减伤率**：
   - 展示护甲总值及基于目标同级怪物的等效减伤率：
     $$\text{DR} = \frac{\text{Armor}}{\text{Armor} + 50 \times \text{Level} + 300}$$
4. **急速与精通**：
   - 急速：缩短普攻攻击间隔、缩短四技能施法前摇与技能冷却（不影响药品与主动饰品固定CD）；
   - 精通：提升自身职业专属机制（战士流血与技能增伤、猎人远程穿透增伤）。

#### 页签 2：【套装效果汇总 (Set Bonuses)】
- **防具五件套**：展示当前穿戴件数（X/5），明确提示 2 件套与 5 件套触发效果；
- **首饰三件套**：展示当前穿戴件数（X/3），达成 3 件套时增加全主属性、AP 与副属性；
- **特殊装备三件套**：展示当前穿戴件数（X/3），达成 3 件套时增加全主属性、AP 并减少职业技能冷却。
- **0 耐久防呆联动**：若穿戴的某件套装防具耐久度降为 0，该件立即移出套装计件，界面实时刷新并灰显失效的套装效果。

## 13. 界面 12：通用异常处理、Toast 与断网重连

### 13.1 弹窗与 Toast 规范
- **Toast 轻量提示**：屏幕顶部居中，黑底白字（背景 `#000000cc`），圆角 6px，出现后停留 1.5 秒向上淡出消逝；
- **二级确认模态框 (Modal)**：全屏 50% 黑色遮罩，居中 420×220px 弹窗，包含标题、正文、取消（左灰）与确认（右金/蓝）。

### 13.2 网络中断与资产未知结果处理（验收点 UI14）
- 当玩家点击背包扩容、强化、修理或领取邮件后，若发生网络超时（3 秒未回包）：
  - 界面居中显示转圈菊花，提示“**正在同步数据结果，请稍候...**”；
  - 严禁允许玩家连击重点！所有发包按钮立即进入 Disable 冻结态；
  - 若 10 秒完全断线，提示“网络连接已断开，正在恢复会话...”；
  - 重连成功后，**客户端首先向服务端查询该请求序列号的原操作真实结果**，确认成功则直接刷新资产，未扣费则恢复按钮，杜绝重复扣款或吞物。


2026-10-20整理规则已确认：先合并同模板、同绑定归属及其他堆叠条件一致的物品（每堆最多20），再按装备→消耗品→材料排列；装备按部位固定顺序、品质高到低、装等高到低，其他同类按模板稳定排序，同排序键保持稳定次序。支持正序/倒序切换：默认正序采用上述顺序、空格置末；倒序反转该排列并将空格置首。快捷栏模板绑定不变，装备不合并，不改变数量、属性、绑定或来源；仅整理当前背包，金库整理未确认。
