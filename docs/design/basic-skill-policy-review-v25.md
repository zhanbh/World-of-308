# 普攻穿插、技能频率与蓝耗对照 v25

日期：2026-10-21。接续[v23](spatial-growth-review-v23.md)/[v24](boss-counter-window-review-v24.md)。状态：离线设计对照，未修改武器公式、Boss HP、药品值或正式游戏配置；不表示数值定稿。

## 1. 复现与模型边界

Python 3.14.3，Windows使用UTF-8模式。运行：

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
python -X utf8 docs/design/analysis/basic_skill_policy_trial.py --seeds 12 --output docs/design/analysis/results/basic-skill-policy-v25.json
python -X utf8 docs/design/analysis/basic_skill_policy_trial.py --seeds 12 --policies mixed3_safe --output docs/design/analysis/results/basic-skill-policy-adaptive-v25.json
```

5个等级/配装情景×12种子×4策略，共240条；追加自适应60条，共300条。各组同种子场景，但动作改变会改变命中随机数消耗次序，不是所有策略共享同一命中随机序列，也不是实人成功率估计。

仅扩展分析目录的run可选策略及计数，默认burst不改变原策略。v23主程序与v24的96条对照已重跑通过；额外检查默认等价、固定重放、逐房耗蓝/药品合账、纯普攻不耗技能蓝及通关28怪。没有重跑全部历史41脚本，不声称新协议跨端确定性通过。回归证据见[结果](analysis/results/v23-v24-regression-2026-10-21.json)。

模型仍使用预期暴击、候选AI/几何/控制节点、每类8瓶携带库存；无付费复活、真实网络、掉落换装与材料库存。净金币是毛收益减模型修理及补回药品库存成本，不是真实购买现金流或完整长期收入。

## 2. 策略定义

- burst：原模型，技能可用且几何合适即按既有优先级施放，保留安全射程反击。
- mixed3/mixed6：每次技能后须启动3/6次普攻才能用下一技能；计启动而非完成/命中，受击取消也计，不能称完整三段连招策略。
- basic_only：纯普攻压力对照，不作为实际玩家推荐。
- mixed3_safe：mixed3基础上，HP≤50%或精英/Boss处于收招时允许立即用技能；50%只是脚本策略参数，不新增游戏规则。

所有策略仍为测试代理，不往游戏加入自动施法，不宣称已找到最优打法。首个技能不要求先打普攻，跨房保留策略计数；开始后节点/体力规则均沿原模型。

## 5. 结论与下一步

1. 有装备后，普攻穿插可在样本中明显省蓝，符合正常战斗并非必须一直技能的方向；不需要立即普遍降低技能蓝耗。
2. 仅保底武器的极低装备与全蓝是两端，不代表实际掉落成长路径。低装备硬性限技会失去输出/控制，增加受击和失败；自适应比机械计数更可用，但并未消除Boss时长和蓝耗缺口。
3. 继续保留武器公式与Boss HP，不用一次策略对照申请全局削HP、增AP或补蓝。下一步应增加合法中间配装，辨别防具/其他槽改善后是否自然落入合理区间，再与真实掉落供给衔接。
4. 1–30级目标、猎人、第二/特殊副本及高段材料经济仍未完成。当前完成的是公司续接点的第一项策略诊断，不把300条路径当完整数值验收。
