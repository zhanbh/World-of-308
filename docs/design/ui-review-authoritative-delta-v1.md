## 状态与接口约束

每个写面板至少设计ready/submitting/resultUnknown/success/rejected/versionConflict，禁用重复提交不能替代服务端幂等。关闭面板不撤销在途资产。resultUnknown先查原operation，旧响应版本低于当前视图只作历史结果，不回写旧背包/钱包。报价失效先刷新展示，不静默提高扣款。

战斗独立显示alive/deadAwaitChoice/reconnecting/loading/completedLooting/closed；死亡残留杀Boss转成功免费复活，不能被旧死亡弹窗覆盖。未确认预测最多1秒候选，超界暂停等待；连续失败按既定10秒提示重新进入，新launch回旅店而非续关。切房采用[两步握手](../backend/room-loading-handshake-v1.md)。

本合同消除“按图还是按规则做”的开发歧义，**未关闭图稿修正和真机验收**。图稿偏差作为正式评审已知项登记；进入coding前先确认这些修正约束，UI实现完成前更新相关图并按哈希复验。视觉参考不作为自动生成协议/业务代码的输入。
