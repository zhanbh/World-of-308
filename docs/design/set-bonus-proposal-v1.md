## 去重与实际汇总

用装备方案的30级蓝装基准AP257.24、HP5031.5、MP579作隔离对照，只叠加上述候选套装效果，先不计算紫装新增稀有属性和首饰待定副属性。不是完整紫装毕业配装。

三类套装全部成套：力量/敏捷/智力各3×8=24。战士力量增加24，按候选每点0.8AP和10HP提供19.2AP/240HP；敏捷24按候选换算再提供4.8个百分点暴击，智力24提供72MP。套装直接AP共10+12+10=32。最终AP=308.44，HP=5271.5，MP=651，暴击由34.3%变39.1%（尚未包含首饰统一副属性额度和紫装稀有词条）。不将三项全部再转成战士攻强，防具5件不重复发2件效果。

只凑防具2件：AP=257.24+8×0.8+10=273.64，HP=5111.5，MP=603，暴击=35.9%；尚无5件技能伤害/范围。拆掉一件至1件，整项2件效果移除；若从5件拆成4件，保留2件但移除5件增伤/范围。各套必须根据当前穿戴重算，不能反复穿脱叠加。

技能增伤12%只影响既定技能范围内的伤害，不提高普攻系数或自然恢复，不在流血施加和每跳重复乘。假设其他同类技能增伤为0、技能无固定伤害项，则AP变化与套装增伤合计为308.44/257.24×1.12≈1.34倍；含技能等级固定项时不能直接套此比值。流血释放时锁预算，后续拆套不回改已锁定预算，沿已确认规则。

## 范围与CD的候选计算

技能范围候选按长度维度乘倍率，而不是面积直接加百分比；30档1.15倍若同时扩大横向及纵深，矩形面积会成为1.3225倍，要按实际判定检查，不能宣称面积只加15%。画面与判定同步，圆形用半径、矩形用半宽/半高、扇形先保持角度而增半径；具体每技能规则待动作方案，不加角色移速/起跳距离，也不默认增加投射距离或段数。

候选CD=基础CD×(1−套装减CD)/(1＋最终急速)，同类套装减CD先相加且须限制有效范围，技能还需最小CD校验。急速不因此再次施加到已计算的剩余CD上。现有1.5动作倍率上限尚未确认，不在本表宣告定稿。

按装备方案均衡样例急速39.33%，一个10秒基础CD技能：无特殊套约7.18秒；30档特殊套10%减CD后约6.46秒。是冷却变短，不额外加快技能动作或DOT一遍；那些已由急速负责。药品固定CD不变。

用户最新纠正：特殊套减CD仅作用职业技能，主动饰品和药品均为独立固定CD，不受急速或套装减CD影响；15秒候选饰品持续仍必须小于实际CD。即使套装减CD成立，也不能绕过饰品冷却禁换、换装等待及回城/复活矩阵。
