# 实际配装下的Boss生命敏感性 v28

日期：2026-10-21。接续[v27连续供给](first-dungeon-supply-path-review-v27.md)。仅离线设计试算，未修改游戏代码或正式配置。

## 试验边界

取v27两种策略各12条成长路径中，首次以10/14级进入挑战前的实际穿戴：必须读取前一局回城后的worn，不能读取本局结束后的装备。每组比较Boss生命倍率1、0.90、0.85，其余敌人、武器公式与操作策略不变。共144次挑战。

**这是控制变量比较，不是v27原局重放**：入场经验统一为0，当前档血蓝药各8瓶；原路径的经验余量与实际药品库存没有继承。装备和耐久继承真实候选获取路径，不人为补蓝装。故基线与v27汇总不同，不能直接将两个报告的差值视为HP调整效果。

## 结论与下一步

1. 降低Boss生命确实减少战斗时长和药耗，但统一降低15%只让10级高频策略达到既有60～120秒候选区间；10级穿插约127秒，14级两策略约130/148秒。候选时长不是用户确认的硬性验收线。
2. 高频策略14级比10级仍慢，提示需继续拆解等级间怪物成长与实际配装输出，不能从两个等级推断全区间应统一削弱多少。下一轮先核对敌人参考曲线、持有武器档位及每段伤害/有效输出时间，再决定是否做分等级HP候选；不先扩大掉率或提高武器公式。
3. 保持正式参数不变，将0.90/0.85保留为敏感性证据。未模拟调整后的连续掉落、经验、钱包与材料支出，不能宣称经济或1至30级3～5小时目标达标。
