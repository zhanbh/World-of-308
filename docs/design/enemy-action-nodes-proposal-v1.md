# 首副本敌方招式节点提案 v1

2026-10-20。承接[技能位移v15](skill-displacement-review-v15.md)及[首副本组合规则](dungeon-first-proposal-v1.md)。本稿把已确认机制转成可审阅时间轴；秒数、范围及尚未确认的边界均为候选，不是正式动作配置，不修改游戏代码。

## 分层

每个技能分别记录正式起手、锁向、伤害段、范围结束、霸体开始/结束、动作结束和冷却截止。预警只是表现，不代替命中判定；冷却从正式起手计算，中断保留已流逝和剩余冷却，不退款。实际控制是否中断由技能配置决定，普通伤害不自动中断。

横扫、重槌施招霸体和收招恢复可控已确认；吼叫持续期间霸体已确认，起手/收招具体边界尚未确认。本稿用吼叫起手可控作为对照候选，不能因此改写主规格为“已经确定吼叫起手可打断”。

## 第一组可复算节点

单位秒，均从该招正式起手计算。范围与位移沿前轮几何候选单独配置，不把下表秒数推广成所有难度的统一预警下限。

| 技能 | 首次伤害/预警结束 | 后续伤害 | 范围/施招阶段结束 | 本次动作结束 | 冷却截止 | 霸体候选区间 |
| --- | --- | --- | --- | --- | --- | --- |
| 精英顺劈 | 0.60 | 无 | 0.70 | 1.30 | 3.00 | 无，合法控制可中断 |
| 精英横扫 | 1.00 | 无 | 1.15 | 2.00 | 6.00 | [0,1.15) |
| Boss重槌 | 1.00 | 无 | 1.15 | 2.00 | 4.00 | [0,1.15) |
| Boss吼叫 | 范围1.00起效，首跳1.50 | 2/2.5/3/3.5/4.00 | 4.00末跳后结束 | 4.80 | 12.00 | [1.00,4.00)，起手边界待审 |

吼叫范围起效与第一跳分开；若最终设计需要起效即伤害，应改显式段表和预算，不能额外多送一跳。末跳在范围结束节点结算，结束后不补跳。霸体区间当前半开，末跳恰逢结束时的控制/伤害顺序仍须正式事件规范，不能用浮点相等随意决定。

## 状态与中断对照

- 起手→伤害/持续段→收招→空闲；冷却独立存在，空闲时可选其他合法技能，不等于原地等待该招冷却。
- 普通伤害和流血仍可作用于霸体目标；霸体只拦截对应僵直/击退/倒地，不变成伤害免疫。
- 受到合法控制并且技能允许中断，取消尚未执行的本体攻击；不撤销已经结算伤害。脱手飞行物/独立地面效果仍按其生命周期继续，本轮未用统一清空代替。
- 吼叫候选归为依赖施法者持续维持的效果；施法者死亡取消未执行声波段。此效果所有权需与未来独立地面技能分别配置，不能把这个处理推广成所有残留效果死亡即清除。

## 半血阶段边界候选

已确认Boss到50%进入P2，当前招式先完成，不清技能冷却；死亡不允许被待切阶段覆盖。

本稿建议“完成本次动作”包含收招：重槌0.5秒时降至49%，仍完成该招，到2.0秒动作结束后进入P2，不在1.15秒霸体结束时强行切换。若当前可中断动作被合法中断，则在中断后结束本次动作并应用待切阶段；受控能否立即选新招仍由控制状态约束，不能切阶段清掉倒地/硬直。本轮参考类只检查交接，不模拟控制时长。

上述收招范围与合法中断后的交接是待审方案，主规格此前明确留待实现规格核对，本轮不标作用户已经确认。没有阶段无敌、回血、重置冷却或免费攻击。

## 验证

运行 `python3 -B docs/design/analysis/enemy_action_nodes_trial.py`。参考状态检查通过：

- 顺劈受到普通伤害不中断；合法控制取消未来攻击但不退冷却。
- 横扫/重槌施招中控制无效但能扣血，恢复阶段可受控。
- 半血等待当前招式完整结束，切阶段保留冷却。
- 候选吼叫起手被打断时交接待切阶段，仍保留12秒冷却。
- 吼叫6个候选伤害节点；施法者死亡停止未来本体持续段。
- 死亡优先于待切阶段，不发生死亡后P2复活。

这是Python参考状态模型；没有实际事件去重、同帧结算、怪物AI或客户端验证。未覆盖连续践踏、冲撞/撞墙虚弱、空间碰撞及多人扩展，不能取代首副本整局验收。

## 2026-10-21分析后的配置契约补充

以下为实现规格候选，整理已有“伤害、控制、中断分别判断”的规则，不赋予任何职业/怪物新增免控。每个技能配置应明确：

| 层 | 必需区分 | 校验 |
| --- | --- | --- |
| 命中效果 | 伤害、僵直、击退、普通阈值倒地、强制击倒 | 纯伤害不能隐式生成控制；流血不参与普通倒地累计 |
| 目标抗性 | 类型默认、单体覆盖、阶段/施招节点覆盖 | 每种控制分别判断；不能因Boss身份统一免控 |
| 施招中断 | 当前技能接受哪些已生效控制触发中断 | 可控但不可中断与控制免疫不同；不清已流逝CD |
| 本体/脱手效果 | 尚未执行的挥击、已发射飞行物、独立地面效果、依赖施法者维持的持续效果 | 中断/死亡分别配置生命周期，不统一删除所有效果 |
| 事件边界 | 同帧死亡、控制、末段伤害、阶段切换 | 统一确定顺序与去重键；死亡不得被阶段切换复活 |

分析模块`enemy_interrupt_policy_trial.py`已将接受控制后是否清招分离为可配置函数，None控制不触发中断；空间模型默认仍沿历史每个直接攻击附带候选僵直的口径，不能称为已完整实现上述效果系统。远程/冲锋仅倒地可中断是敏感性候选，效果有限，未采纳为正式怪物规则。精英顺劈可被合法控制中断、横扫施招霸体等已确认规则保持。

本轮不得仅为提高受伤统计而把普通近战/精英顺劈改成霸体。应保留熟练玩家的压制与打断收益，难度评估同时观察应对机会、输出窗口、站位成立与不同策略表现，而不要求玩家受伤必然随难度单调增加。具体压力阈值仍待更完整遭遇与真机验证。
